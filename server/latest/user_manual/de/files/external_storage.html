Externen Speicher verwenden

Mit der App „Externer Speicher“ kann Ihr Nextcloud-Server Verbindungen zu entfernten Dateisystemen herstellen – etwa Amazon S3, SFTP-Server, SMB/CIFS-Freigaben oder WebDAV-Server – und diese als Ordner in Ihrer Dateiansicht darstellen. Ihre Administration legt fest, welche Backends verfügbar sind und welche Einbindungen für Sie freigegeben werden.

Wenn Ihre Administration benutzerverwalteten externen Speicher aktiviert hat, können Sie unter „Persönliche Einstellungen“ auch eigene Verbindungen hinzufügen.

Auf externen Speicher zugreifen

Einbindungen externer Speicher erscheinen in Ihrer Dateiansicht als normale Ordner. Sie können darin Dateien durchsuchen, hochladen, herunterladen und löschen, genau wie in jedem anderen Ordner. Ob Teilen möglich ist, hängt davon ab, ob Ihre Administration es für die jeweilige Einbindung aktiviert hat.

Eine farbige Anzeige neben dem Ordnernamen zeigt den Verbindungsstatus:

  • Grün – der Speicher ist verbunden und einsatzbereit.

  • Gelb – der Speicher konnte nicht erreicht werden; Nextcloud versucht es automatisch erneut.

  • Rot – der Speicher ist nicht verfügbar. Wenden Sie sich an Ihre Administration, wenn dies anhält.

Wenn eine Einbindung nicht verfügbar ist, markiert Nextcloud sie für zehn Minuten als offline, bevor ein erneuter Versuch erfolgt. Durch Klicken auf die Statusanzeige können Sie eine manuelle Prüfung auslösen.

Bemerkung

Einige Einbindungen externer Speicher sind möglicherweise schreibgeschützt. Auf einer schreibgeschützten Einbindung können Sie keine Dateien hochladen oder löschen.

Teilen von Dateien aus externem Speicher

Das Teilen aus einer Einbindung externen Speichers funktioniert genauso wie das Teilen jeder anderen Datei oder jedes anderen Ordners – verwenden Sie das Teilen-Symbol in der Dateiansicht. Das Teilen muss von Ihrer Administration für jede Einbindung ausdrücklich aktiviert werden, daher ist das Teilen-Symbol möglicherweise nicht bei allen Einbindungen verfügbar.

Bemerkung

Serverseitige Verschlüsselung ist für externe Einbindungen, die auf andere Nextcloud-Instanzen verweisen, nicht verfügbar.

Hinzufügen eines eigenen externen Speichers

Wenn Ihre Administration benutzerverwalteten externen Speicher aktiviert hat, können Sie unter Persönliche Einstellungen → Externer Speicher Ihre eigenen Speicherdienste verbinden.

So fügen Sie einen neuen Einhängepunkt hinzu:

  1. Klicken Sie auf Ihr Profilsymbol und wählen Sie Persönliche Einstellungen.

  2. Externer Speicher aus der linken Seitenleiste auswählen.

  3. Wählen Sie im Auswahlfeld Speicher hinzufügen ein Backend aus.

  4. Füllen Sie die für das Backend erforderlichen Felder aus (Serveradresse, Pfad, Zugangsdaten usw.).

  5. Wählen Sie im Auswahlfeld Authentifizierung eine Authentifizierungsmethode aus.

Pflichtfelder sind mit einem roten Rahmen gekennzeichnet. Sobald alle Pflichtfelder ausgefüllt sind, wird die Einbindung automatisch gespeichert.

Ein grüner Punkt neben der Einbindung bestätigt eine erfolgreiche Verbindung. Ein rotes oder gelbes Symbol bedeutet, dass Nextcloud keine Verbindung herstellen konnte – überprüfen Sie Ihre Zugangsdaten und Netzwerkeinstellungen.

Um eine Einbindung zu entfernen, öffnen Sie das Drei-Punkte-Menü daneben und wählen Sie Löschen.

Bemerkung

Einbindungen, die Sie unter „Persönliche Einstellungen“ hinzufügen, sind nur für Ihr Konto sichtbar.

Unterstützte Backends

Je nachdem, was Ihre Administration aktiviert hat, können die folgenden Backends verfügbar sein:

  • Amazon S3 – Buckets von Amazon Simple Storage Service und S3-kompatibler Speicher.

  • FTP — FTP- und FTPS-Server.

  • Nextcloud / ownCloud – Eine andere Nextcloud- oder ownCloud-Instanz über WebDAV.

  • OpenStack-Objektspeicher — OpenStack Swift-Buckets.

  • SFTP — SSH-Dateiübertragungsprotokollserver.

  • SMB / CIFS – Windows-Dateifreigaben und Samba-Server.

  • WebDAV — Jeder WebDAV-kompatible Server.

Einzelheiten zur Konfiguration der einzelnen Backends finden Sie unter Configuring External Storage (GUI) im Administrationshandbuch.

Dateiänderungserkennung

Dateien, die Sie über Nextcloud hinzufügen oder ändern, werden sofort übernommen. Dateien, die direkt auf dem externen Speicher hinzugefügt oder geändert werden – ohne den Weg über Nextcloud –, erscheinen möglicherweise erst nach dem nächsten Hintergrund-Scan.

Wenn extern hinzugefügte Dateien nicht angezeigt werden, bitten Sie Ihre Administration, occ files:scan auszuführen oder einen regelmäßigen Hintergrund-Scan für die Einbindung einzurichten.
