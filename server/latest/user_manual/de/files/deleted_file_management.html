Gelöschte Dateien

Wenn Sie eine Datei oder einen Ordner in Nextcloud löschen, wird diese normalerweise in den Papierkorb verschoben, anstatt sofort gelöscht zu werden. So kann der Löschvorgang rückgängig gemacht werden.

Elemente im Papierkorb werden dauerhaft gelöscht, wenn einer der folgenden Fälle eintritt:

  • Sie wählen manuell Dauerhaft löschen aus.

  • Die App „Gelöschte Dateien“ entfernt Elemente entsprechend der eingerichteten Aufbewahrungsrichtlinie.

  • Die effektive Papierkorbgrößenbeschränkung wird überschritten und das Element wird entfernt werden, um freien Platz zu schaffen.

Sie finden ihre gelöschten Dateien indem Sie Gelöschte Dateien im Datei-Bereich der Nextcloud-Weboberfläche auswählen. Dort können Sie gelöschte Elemente wiederherstellen, sie auf Ihr Gerät herunterladen oder sie permanent löschen.

Wenn Sie ein Element wiederherstellen, versucht Nextcloud normalerweise, es am ursprünglichen Speicherort abzulegen. Falls der Speicherort nicht mehr existiert oder dort keine Schreibrechte bestehen, wird das Element im Hauptverzeichnis des Datei-Bereichs wiederhergestellt. Falls dort bereits ein Element mit demselben Namen existiert, gibt Nextcloud dem wiederhergestellten Element einen eindeutigen Namen.

Bemerkung

Wenn die App „Versionen“ aktiviert ist, werden die mit einer gelöschten Datei verknüpften Versionen in den Papierkorb verschoben und bei der Wiederherstellung der Datei ebenfalls wiederhergestellt.

Speicherkontingente

Dateien und Ordner in Ihrem Papierkorb werden nicht auf Ihr normales Speicherkontingent angerechnet.

Weitere Informationen zur Berechnung von Speicherquoten finden Sie unter Speicherkontingent.

Was passiert, wenn freigegebene Dateien gelöscht werden

Das Verhalten von gelöschten, geteilten Dateien hängt davon ab, wer das Element löscht und wem es gehört.

Beispielsweise gibt Benutzer1 einen Ordner namens DasProjekt/ für Benutzer2 und Benutzer3 frei:

  1. User2, ein Empfänger einer Freigabe (Share-Empfänger), löscht einen Ordner oder eine Datei namens Phase2 innerhalb von DasProjekt/.

    DasProjekt/Phase2 wird in den Papierkorb von User1 (dem Eigentümer) verschoben; zudem wird – sofern möglich – eine Kopie in den Papierkorb von User2 gelegt. Für User3 wird das Element aus dem freigegebenen Ordner entfernt, wobei User3 jedoch keine Kopie in seinem Papierkorb erhält.

  2. Benutzer1, der Besitzer, löscht „DasProjekt/Phase2“.

    Das Element wird in den Papierkorb von Benutzer1 verschoben und aus dem freigegebenen Ordner für Benutzer2 und Benutzer3 entfernt. Es wird nicht in deren Papierkörbe gelegt.

Das genaue Verhalten kann von der Art der Freigabe sowie den für diese Freigabe erteilten Berechtigungen abhängen. Je nach Berechtigung können andere Nutzer freigegebene Dateien kopieren, umbenennen, verschieben oder erneut freigeben. Diese Vorgänge können sich darauf auswirken, welches Konto als Eigentümer der resultierenden Dateien fungiert und in welchem ​​Papierkorb ein gelöschtes Element landet.

Bemerkung

Wenn eine Person, für die ein Element freigegeben wurde, dieses löscht, verschiebt Nextcloud das Element in den Papierkorb des Eigentümers. Zudem wird (in den meisten Fällen) eine Kopie im Papierkorb der Person erstellt, die das Element gelöscht hat – dies erfolgt jedoch nach dem Prinzip des bestmöglichen Bemühens (best-effort) und wird nicht garantiert.

So verwaltet die App „Gelöschte Dateien“ den Speicherplatz

Die Gelöschte-Dateien-App verwaltet den Inhalt des Papierkorbs nach zwei abhängigen Regeln:

  • Ein Speicherplatz-Limit legt fest, wie viel Speicher der Papierkorb nutzen darf.

  • Eine Aufbewahrungsrichtlinie legt fest, ab wann gelöschte Elemente für die dauerhafte Löschung infrage kommen.

Papierkorb Speichergrenze

Für Konten mit einem Speicherkontingent liegt das standardmäßige Speicherlimit des Papierkorbs bei 50% des verbleibenden Kontingents. Dieses wird berechnet, nachdem die aktiven Dateien des Kontos berücksichtigt wurden; es liegt nicht bei 50% des Speicherkontingents des Kontos.

Wenn Ihr Kontingent beispielsweise 10 GB beträgt und Ihre aktiven Dateien 8 GB beanspruchen, wird der standardmäßige Speicherplatz für den Papierkorb auf Basis der verbleibenden 2 GB berechnet.

Bei Konten ohne Speicherkontingent wird das Standardlimit stattdessen auf Basis des verfügbaren Speicherplatzes im Dateisystem berechnet. Ihr Administrator kann diese Standardwerte jeweils anpassen, indem er eine globale oder kontospezifische Größe für den Papierkorb festlegt.

Wenn das effektive Limit für den Papierkorb überschritten wird, entfernt Nextcloud entsprechende gelöschte Elemente – beginnend mit den ältesten –, bis das Limit wieder eingehalten wird.

Aufbewahrung und dauerhafte Löschung

Standardmäßig werden gelöschte Dateien mindestens 30 Tage lang aufbewahrt. Danach können entsprechende Elemente dauerhaft gelöscht werden, wenn Speicherplatz benötigt wird; sie werden also nicht zwangsläufig unmittelbar nach Ablauf der 30 Tage gelöscht.

Ihr Administrator kann unterschiedliche Mindest- und Höchstaufbewahrungsfristen konfigurieren. Je nach Konfiguration können Elemente nach Erreichen eines maximalen Alters dauerhaft gelöscht werden – auch dann, wenn aktuell kein Speicherplatz benötigt wird. Die automatische Löschung kann zudem deaktiviert werden.

Bei Richtlinien mit einer festgelegten Mindestaufbewahrungsfrist kann ein Element erst nach Ablauf dieser Frist im Rahmen einer speicherplatzbasierten Bereinigung entfernt werden. Richtlinien ohne Mindestaufbewahrungsfrist können eine speicherplatzbasierte Bereinigung unabhängig vom Alter des Elements zulassen. Elemente, deren festgelegte maximale Aufbewahrungsfrist überschritten wurde, können dauerhaft gelöscht werden – unabhängig davon, ob aktuell Speicherplatz benötigt wird.

Die entsprechende Konfigurationseinstellung lautet trashbin_retention_obligation. Einzelheiten zu den verfügbaren Werten sowie deren Zusammenspiel mit Quotas und der Größe des Papierkorbs finden Sie im Abschnitt Gelöschte Dateien des Administrator-Handbuchs: Deleted Files section of the Administrator Manual.

Bemerkung

Die App Gelöschte Dateien kann ein Element unter Umständen bereits vor Ablauf seiner maximalen Aufbewahrungsfrist endgültig löschen – nämlich dann, wenn das effektive Limit für den Papierkorb überschritten ist und die minimale Aufbewahrungsfrist für das Element abgelaufen ist.
