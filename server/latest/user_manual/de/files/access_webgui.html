Zugriff auf Ihre Dateien über die Nextcloud-Weboberfläche

Sie können über die Nextcloud-Weboberfläche auf Ihre Nextcloud-Dateien zugreifen und Dateien erstellen, in der Vorschau anzeigen, bearbeiten, löschen, freigeben und erneut freigeben. Ihre Nextcloud-Administration hat die Möglichkeit, diese Funktionen zu deaktivieren. Wenn eine dieser Funktionen auf Ihrem System fehlt, wenden Sie sich an Ihre Administration.

In Ihren Dateien navigieren

In der linken Seitenleiste können Sie zwischen verschiedenen Ansichten Ihrer Dateien wechseln. Klicken Sie auf einen Ordnernamen in der Dateiliste, um ihn zu öffnen, und verwenden Sie die Zurück-Schaltfläche Ihres Browsers oder die Breadcrumb-Leiste oben in der Dateiliste, um zu einer vorherigen Ebene zurückzukehren.

Die Seitenleiste enthält folgende Einträge:

Alle Dateien

Die Standardansicht, die alle Dateien und Ordner anzeigt, auf die Sie Zugriff haben.

Aktuell

Dateien, die Sie kürzlich angesehen oder geändert haben.

Favoriten

Dateien und Ordner, die Sie mit einem Stern gekennzeichnet haben

Freigaben

Dateien, die mit Ihnen, von Ihnen oder über einen öffentlichen Link geteilt wurden — alles in einer Ansicht.

Schlagworte

Durchsuchen Sie Dateien anhand von System-Tags. Weitere Informationen zum Zuweisen von Tags und zum Filtern deiner Dateien findest du unter System-Schlagworte.

Gelöschte Dateien

Von Ihnen gelöschte Dateien, die noch aus dem Papierkorb wiederhergestellt werden können.

Wenn Sie in einen Ordner navigieren, erscheint oberhalb der Dateiliste eine Navigationspfad-Anzeige (Breadcrumb-Leiste), über die Sie mit einem einzigen Klick zu einem beliebigen übergeordneten Ordner zurückspringen können:

Steuerelemente für Dateien

Nextcloud zeigt Vorschaubilder für Bilder, Textdateien und andere unterstützte Dateitypen an – die genaue Liste hängt von Ihrer Serverkonfiguration ab.

Jede Zeile für eine Datei oder einen Ordner enthält ein Aktionsmenü (dargestellt durch drei Punkte). Klicken Sie darauf, um das Element umzubenennen, zu verschieben, zu kopieren, herunterzuladen, zu löschen oder als Favorit zu markieren. Als Favorit markierte Dateien werden mit einem Sternsymbol gekennzeichnet:

Bemerkung

Über den Eintrag Favoriten in der linken Seitenleiste finden Sie schnell alle Ihre Favoriten.

Details-Seitenleiste.

Wählen Sie im Aktionsmenü (dargestellt durch drei Punkte) die Option Details aus, um die Detail-Seitenleiste zu öffnen. Die Seitenleiste zeigt Informationen zur ausgewählten Datei an und bietet über Registerkarten Zugriff auf deren Aktivitätshistorie, Freigabeoptionen sowie Versionshistorie:

Aktivität und Kommentare

Die Registerkarte Aktivität in der Details-Seitenleiste zeigt ein chronologisches Protokoll der Änderungen an der Datei — Uploads, Bearbeitungen, Freigaben und Kommentare. Sie können einen Kommentar direkt in dieser Registerkarte hinterlassen; Kommentare sind für jeden sichtbar, der Zugriff auf die Datei hat:

Suchen und Filtern

Verwenden Sie die Suchleiste oben auf der Seite, um Dateien nach Namen in allen Ihren Dateien zu finden, oder geben Sie das Suchfeld in der linken Seitenleiste ein, um die aktuelle Ansicht zu filtern:

Rasteransicht

Die Dateien-App verwendet standardmäßig eine Listenansicht. Klicken Sie auf die Schaltfläche oberhalb der Dateiliste, um zur Rasteransicht mit Vorschaubildern zu wechseln – dies ist besonders hilfreich beim Durchsuchen von Bildordnern:

Erneut auf die Schaltfläche klicken, um zur Listenansicht zurückzukehren.

Dateien hochladen und erstellen

Klicken Sie auf die Schaltfläche + oben in der Dateiliste, um Dateien von Ihrem Computer hochzuladen oder neue Elemente im aktuellen Ordner zu erstellen:

Dieses Menü bietet die folgenden Optionen:

Datei hochladen

Öffnet eine Dateiauswahl, um eine oder mehrere Dateien von Ihrem Computer hochzuladen. Sie können Dateien auch per Drag-and-Drop direkt aus Ihrem Dateimanager in die Dateiliste ziehen.

Hochladeordner

Lädt einen ganzen Ordner hoch und behält dabei dessen Struktur bei.

Neuer Ordner

Erstellt einen neuen, leeren Ordner am aktuellen Speicherort.

Neues Dokument / Neue Tabellenkalkulation / Neue Präsentation

Erstellt eine neue Datei mithilfe des integrierten Nextcloud-Text- oder Office-Editors, sofern dieser von Ihrem Administrator aktiviert wurde.

Dateien oder Verzeichnisse auswählen

Klicken Sie auf das Kontrollkästchen links neben einer Datei oder einem Ordner, um diese(n) auszuwählen. Um alle Elemente im aktuellen Ordner auszuwählen, klicken Sie auf das Kontrollkästchen in der Spaltenüberschrift.

Sobald ein oder mehrere Elemente ausgewählt sind, erscheinen am oberen Rand der Liste Aktionsschaltflächen. Sie können alle ausgewählten Elemente auf einmal löschen oder herunterladen. Beim Herunterladen mehrerer Elemente wird ein ZIP-Archiv erstellt.

Bemerkung

Wenn die Schaltfläche Herunterladen nicht sichtbar ist, hat Ihr Administrator diese Funktion deaktiviert.

Freigabe-Status-Symbole

Für Ordner und Dateien, die freigegeben wurden, wird auf deren Vorschaubild oder Symbol ein Hinweis (Freigegeben) angezeigt. Elemente, die über einen öffentlichen Link geteilt wurden, sind zudem mit einem Kettenglied-Symbol gekennzeichnet. Elemente, die nicht freigegeben wurden, weisen keine zusätzliche Kennzeichnung auf.

Siehe Dateifreigabe für Anleitungen zum Erstellen und Verwalten von Freigaben.

Dateien verschieben

Ziehen Sie eine beliebige Datei oder einen Ordner per Drag-and-Drop auf einen Zielordner, um sie bzw. ihn zu verschieben. Alternativ können Sie im Aktionsmenü (dargestellt durch drei Punkte) die Option Verschieben oder kopieren wählen, um Elemente in einen Ordner zu verschieben oder zu kopieren, den Sie über ein Auswahlfenster festlegen.

Dateivorschau

Klicken Sie auf einen Dateinamen, um eine Vorschau direkt in Nextcloud zu öffnen. Zu den unterstützten Formaten gehören Bilder, reiner Text, PDF sowie – je nach Server – Office-Dokumente und Audiodateien. Falls Nextcloud für ein Dateiformat keine Vorschau anzeigen kann, wird die Datei stattdessen auf Ihren Computer heruntergeladen.

Videoplayer

Sie können Videos direkt in Nextcloud abspielen, indem Sie auf die entsprechende Datei klicken. Die Wiedergabe hängt von Ihrem Browser und dem verwendeten Videocodec ab. Informationen zur Kompatibilität finden Sie unter MDN: Unterstützte Medienformate.

Zu einer Federated-Freigabe verbinden

Federated-Cloud-Freigaben ermöglicht es Ihnen, Dateifreigaben von externen Nextcloud-Servern einzubinden und diese genauso zu verwalten wie lokale Freigaben. Unter Federated-Freigaben verwenden erfahren Sie, wie Sie „Federated Cloud“-Freigaben erstellen und eine Verbindung zu ihnen herstellen können.
