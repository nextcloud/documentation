Die Weboberfläche von Nextcloud

Öffnen Sie die URL Ihres Nextcloud-Servers in einem beliebigen Webbrowser und melden Sie sich mit Ihrem Kontonamen (oder Ihrer E-Mail-Adresse) und Ihrem Passwort an:

Sie können sich auch mit einem Passkey oder Hardware-Sicherheitsschlüssel anmelden, indem Sie auf Mit einem Gerät anmelden klicken.

Anforderungen an den Webbrowser

Für das beste Erlebnis verwenden Sie die neueste Version eines dieser Browser:

  • Google Chrome / Chromium

  • Mozilla Firefox

  • Apple Safari

  • Microsoft Edge

Bemerkung

Nicht alle Versionen werden unterstützt. Nextcloud zielt auf Browser ab, die den Mindestnutzungsschwellenwert erreichen.

Das Dashboard

Nach der Anmeldung öffnet Nextcloud das Dashboard — eine anpassbare Übersicht Ihrer wichtigsten Aktivitäten: bevorstehende Kalenderereignisse, ungelesene Nachrichten, aktuelle Dateien und mehr.

Verwenden Sie die Schaltfläche Anpassen unten auf der Seite, um Widgets hinzuzufügen, zu entfernen oder neu anzuordnen, um diese an Ihren Workflow anzupassen.

Navigieren in der Benutzeroberfläche

Navigieren in der BenutzeroberflächeDie Navigationsleiste oben auf jeder Seite ist Ihr Hauptanlaufpunkt:

  • Das Nextcloud-Logo (oben links) führt Sie zurück zum Dashboard.

  • App-Verknüpfungen werden neben dem Logo angezeigt — klicken Sie auf ein beliebiges Symbol, um zu dieser App zu wechseln (Dateien, Kalender, Talk, usw.).

  • Das Suchsymbol auf der rechten Seite öffnet :ref:`einheitliche Suche `, die alle Ihre Apps auf einmal durchsucht.

  • Das Glockensymbol zeigt Ihre Benachrichtigungen an.

  • Mit dem Symbol Kontakte können Sie schnell nach anderen Benutzern auf Ihrem Server suchen und diese kontaktieren.

  • Ihr Profilbild (ganz rechts) öffnet das Einstellungsmenü.

Ihr Profilbild (ganz rechts) öffnet das Einstellungsmenü.

Einstellungen und Profile

Klicken Sie auf Ihr Profilbild, um auf Ihre Kontoeinstellungen zuzugreifen:

Aus diesem Menü heraus können Sie:

  • Ihr Profil ansehen und bearbeiten

  • Ihren Online-Status festlegen

  • Change appearance and accessibility settings

  • Öffnen Sie Ihre persönliche Seite Einstellungs Seite

  • Auf Hilfe und Datenschutzinformationen zugreifen

  • Abmelden

Einheitliche Suche

Klicken Sie auf das Suchsymbol in der Navigationsleiste (oder drücken Sie Strg+F), um das einheitliche Suchmodal zu öffnen:

Die einheitliche Suche durchsucht alle Ihre installierten Apps — Dateien, Kalenderereignisse, Nachrichten, Kontakte und mehr — auf einmal. Die Ergebnisse werden nach App gruppiert, sodass Sie schnell sehen können, wo Übereinstimmungen gefunden wurden.

Die Filterchips verwenden, um die Ergebnisse einzugrenzen:

  • Orte — Die Suche auf eine bestimmte App, z. B. Dateien oder Kalender beschränken.

  • Datum — Filtern nach Zeitraum (heute, letzte 7 Tage, letzte 30 Tage, dieses Jahr oder ein benutzerdefinierter Bereich).

  • Personen — Nur Ergebnisse anzeigen, die sich auf eine bestimmte Person beziehen.
