Nextcloud Office Desktop

Nextcloud Office Desktop lets you edit documents, spreadsheets, and presentations offline on your computer. The download links below always point to the latest stable release. Older versions are available from https://download.nextcloud.com/office/desktopeditors/.

Linux

Install from the Nextcloud Office package repository, so that updates arrive with regular system updates.

Debian and Ubuntu

sudo apt-get install -y ca-certificates curl
sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL https://download.nextcloud.com/office/repo/nextcloud-office.asc \
  -o /etc/apt/keyrings/nextcloud-office.asc
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/nextcloud-office.asc] \
https://download.nextcloud.com/office/repo/deb stable main" \
  | sudo tee /etc/apt/sources.list.d/nextcloud-office.list
sudo apt-get update

sudo apt-get install nextcloud-office-nextcloudoffice

The installation also offers the Microsoft core fonts, which improve how documents created in Microsoft Office are displayed. To install them, accept their license when prompted.

Fedora and RHEL

sudo tee /etc/yum.repos.d/nextcloud-office.repo <<'EOF'
[nextcloud-office]
name=Nextcloud Office
baseurl=https://download.nextcloud.com/office/repo/rpm/stable/$basearch
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://download.nextcloud.com/office/repo/nextcloud-office.asc
EOF
sudo dnf install nextcloud-office-nextcloudoffice

During the first installation, dnf asks you to confirm the repository signing key. Check that its fingerprint is C013 F0BE F968 00BB BC4D 93DD E6E7 0E5F A287 C3D0 before you accept it.
