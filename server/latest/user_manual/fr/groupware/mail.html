Utilisation de l’application Mail

Note

L’application Mail est installée avec Nextcloud Hub par défaut, mais elle peut être désactivée. Merci de demander à votre administrateur.

Gestion de vos comptes de courriel

Modifier la disposition

Ajouté dans la version 3.6: Nextcloud 26 or newer

  1. Rendez-vous dans les paramètres

  2. Choisissez parmi Liste, Séparation verticale et Séparation horizontale

Utiliser le mode compact

Ajouté dans la version 5.7: Nextcloud 32 or newer

Le mode compact permet de visualiser plus efficacement vos messages. Les avatars sont cachés, les cases à cocher sont toujours visibles et l’aperçu des messages est masqué. Une économie d’espace qui vous permet de voir d’avantage de messages à la fois.

  1. Rendez-vous dans les paramètres de Mail

  2. Allez à Apparence

  3. Activer/désactiver le mode compact

Affichage des messages groupés

Ajouté dans la version 5.2: Nextcloud 30 or newer

Mail a la possibilité de basculer entre deux modes différents de gestion et d’affichage des messages : Fil de discussion et Message unique.

In Threaded mode, messages are grouped by conversation. In the folder message list, related messages are stacked so only the most recent message is shown, and all relates messages are shown in message display panel after the stacked message is selected. This is useful for following discussions and understanding the context of replies. In this mode, message operation like move and delete apply to the entire thread, meaning that when you move or delete a thread, all messages within that thread are affected.

In Singleton mode, messages are displayed individually, in both the folder message list and message display panel and operation like move and delete apply to only the selected message. This mode is useful when you want to manage messages separately without affecting the entire conversation.

  1. Rendez-vous dans les paramètres

  2. Choisissez entre Fil de discussion, Message unique

Ajouter un nouveau compte courriel

  1. Activer l’application Courriel depuis le magasin d’application

  2. Cliquer sur l’icône de courriel dans le bandeau

  3. Compléter le formulaire de connexion (automatique ou manuel)

Modifier l’ordre de tri

Ajouté dans la version 3.5: Nextcloud 26 or newer

  1. Rendez-vous dans les paramètres

  2. Aller à Trier

  3. Vous pouvez choisir d’afficher en premier les messages Plus récent ou Plus ancien

Note

This change will apply across all your accounts and folders

Afficher les favoris d’abord

Ajouté dans la version 5.7: Nextcloud 31 ou plus récent

Ce paramètre vous permet d’afficher les messages définis comme favoris dans une section séparée au haut de la liste des messages.

  1. Rendez-vous dans les paramètres

  2. Allez à Apparence

  3. Activez l’affichage des favoris en premier

Messages planifiés

  1. Click the New message button

  2. Cliquez sur le menu d’action (…) sur le compositeur modal

  3. Cliquer sur Envoyer plus tard

Boite de réception prioritaire

La boîte de réception prioritaire comporte 2 sections Important et Autres. Les messages seront automatiquement marqués comme importants en fonction des messages avec lesquels vous avez interagi ou marqués comme importants. Au début, vous devrez peut-être modifier manuellement l’importance pour apprendre au système, mais cela s’améliorera avec le temps.

La classification automatique est facultative. Vous pouvez la désactiver lors de la configuration d’un compte. Elle peut être activée ou désactivée dans les paramètres du compte à tout moment.

Toutes les boites de réception

Tous les messages de tous vos comptes de messageries associés seront affichés ici par ordre chronologique.

Paramètres de compte

Les paramètres de votre compte tels que:

  1. Alias

  2. Signature

  3. Dossier par défaut

  4. Répondeur automatique

  5. Expéditeurs de confiance

  6. … et plus

Vous pouvez le trouver dans le menu d’action d’un compte de messagerie. Vous pouvez y modifier, ajouter ou supprimer des paramètres en fonction de vos besoins.

Déplacer le message dans le dossier de pourriels

Ajouté dans la version 3.4: Nextcloud 26 or newer

Mail peut déplacer un message vers un autre dossier lorsqu’il est marqué comme indésirable.

  1. Voir les paramètres du compte

  2. Aller aux répertoires par défaut

  3. Vérifiez qu’un dossier est sélectionné pour les messages indésirables

  4. Aller aux paramètres de pourriels

  5. Cliquez sur Déplacer les messages vers le dossier Courrier indésirable

Refresh folder

You can manually trigger a sync of your folder by clicking the refresh button located at the top of the folder list. Starting from version 5.7 triggering the sync will also refresh the list of folders for the selected account.

Recherche unifiée

L’application Mail intègre la fonctionnalité de recherche unifiée de Nextcloud (voir The Nextcloud web interface pour plus de détails). Vous pouvez rechercher des e-mails au sein de tous vos comptes en utilisant la barre de recherche dans l’entête de Nextcloud.

Mail searches email subjects and sender/recipient fields. To search email bodies, use the folder search feature in the app.

Search in folder

Ajouté dans la version 2.1: Nextcloud 25 or newer

En haut de la liste des enveloppes, quelle que soit la disposition d’affichage des e-mails, il y a un raccourci pour faire une recherche dans les objets des e-mails. À partir de la version 3.7, ce raccourci vous permet de faire une recherche par objet, destinataire (à), ou expéditeur (de) par défaut.

Advanced search in folder

Ajouté dans la version 3.4: Nextcloud 26 or newer

Vous pouvez accéder à notre fonctionnalité de recherche avancée via la fenêtre modale située après le raccourci de recherche.

Activer la recherche dans le corps des e-mails

Ajouté dans la version 3.5: Nextcloud 26 or newer

Il est possible à présent de faire des recherches dans le corps des e-mails. Cette fonctionnalité nécessite votre accord en raison de potentiels problèmes de performance.

Pour l’activer :

  1. Voir les paramètres du compte

  2. Go to Folder search

  3. Activer la recherche dans le corps des e-mails

Avertissement

If you want to also enable it for unified folders you have to do so in Mail settings

En l’activant, la boîte de recherche principale va à présent faire la recherche à la fois dans les objets et dans le corps des e-mails, et une option Corps distincte apparaîtra dans la recherche avancée.

Délégation de compte

The app supports two ways of letting one user act on behalf of another’s mail account.

Sending as another address (server alias)

This lets you send emails from the address of another account.

  1. La délégation doit être configurée sur le serveur de messagerie par un administrateur

  2. Ajoutez l’autre adresse e-mail comme alias comme votre propre adresse e-mail

  3. Lors de l’envoi d’un e-mail, sélectionnez l’alias comme expéditeur

Avertissement

The sent email might not be visible to the original account if it’s stored in your personal Sent folder.

Native account delegation

Ajouté dans la version 5.9: Nextcloud Mail

Native account delegation lets you grant other Nextcloud users access to one of your mail accounts directly from the app, without any server-side alias configuration. A delegate can do everything the account owner can — send, receive, and delete mail on your behalf — except deleting the account or updating its authentication information.

To delegate one of your accounts:

  1. Open the account’s three-dot menu and select Delegate account

  2. In the Delegation dialog, click Add delegate

  3. Use the Select a user field to choose the Nextcloud user you want to grant access to

  4. Confirm with Delegate access

The shared account then appears in the delegate’s account list, marked as delegated.

To remove access:

  1. Open the Delegate account dialog again

  2. Click Revoke next to the delegate you want to remove

  3. Confirm with Revoke access

Note

Provisioned accounts cannot be delegated.

Suppression automatique de la corbeille

Ajouté dans la version 3.4: Nextcloud 26 or newer

L’application Mail peut supprimer automatiquement les messages dans la corbeille après un certain nombre de jours.

  1. Voir les paramètres du compte

  2. Accédez à la Suppression automatique de la corbeille

  3. Entrez le nombre de jours après lequel les messages doivent être supprimés

Désactivez la conservation de la corbeille en laissant le champ vide ou en le définissant sur 0.

Note

Seuls les e-mails supprimés après l’activation de la conservation de la corbeille seront traités.

Compose messages

  1. Click the New message button

  2. Commencez à écrire votre message

Réduire le compositeur modal

Ajouté dans la version 3.2: Nextcloud 26 or newer

The composer modal can be minimized while writing a new message, editing an existing draft or a message from the outbox. Simply click the Minimize button on the modal or click anywhere outside the modal.

You can resume your minimized message by clicking anywhere on the minimized composer indicator.

Press the Close button on the modal or on the minimized composer indicator to stop editing a message. A draft will be saved automatically into your draft folder.

Informations du destinataire dans le compositeur

Ajouté dans la version 4.2: Nextcloud 30 or newer

When you add your first recipient or contact in the « To » field, a right pane will appear displaying the saved profile details of that contact. Adding a second contact will collapse the list, allowing you to select and expand any contact you added to view their details. If you prefer to focus solely on writing in the composer, you can hide the right pane by clicking the Expand icon in the composer toolbar. To show the right pane again, simply click the Minimize icon in the same toolbar.

Mentionner des contacts

Ajouté dans la version 4.2: Nextcloud 30 or newer

Vous pouvez mentionner des contacts dans votre message en tapant @ et en sélectionnant ensuite le contact à partir de la liste. En faisant ainsi, le contact sera automatiquement ajouté comme destinataire.

Note

Seuls les contacts dont l’adresse e-mail est valide peuvent être suggérés.

Blocs de texte

Ajouté dans la version 5.2: Nextcloud 30 or newer

Les blocs de texte sont des extraits de texte prédéfinis qui peuvent être insérés dans votre e-mail. Ils peuvent être créés et gérés dans les paramètres de Mail. Ils peuvent être insérés dans le compositeur en tapant ! et en choisissant ensuite le bloc à partir de la liste ou depuis les actions du compositeur. Les blocs de texte peuvent être partagés avec des utilisateurs et des groupes d’utilisateurs.

Boîte d’envoi

When a message has been composed and the « Send » button was clicked, the message is added to the Outbox, which appears at the bottom of the left sidebar.

Vous pouvez également définir la date et l’heure de l’opération d’envoi dans le futur (voir Messages planifiés)- le message sera conservé dans la boîte d’envoi jusqu’à ce que la date et l’heure choisies soient atteintes, il sera ensuite envoyé automatiquement.

La boîte d’envoi n’est visible que s’il y a un message en attente de traitement à l’intérieur.

You can reopen the composer for a message in the outbox any time before the send operation is triggered.

Note

Quand une erreur survient pendant l’envoi, trois messages d’erreur sont possibles :

Could not copy to « Sent » folder

The mail was sent but couldn’t be copied to the « Sent » folder. This error will be handled by the outbox and the copy operation will be tried again.

Erreur du serveur d’e-mail

Sending was unsuccessful with a state that can be retried (ex: the SMTP server couldn’t be reached). The outbox will retry sending the message.

Impossible d’envoyer le message

L’envoi peut ou non avoir échoué. Le serveur de messagerie ne peut pas nous dire le statut du message. Comme l’application Mail n’a aucun moyen de déterminer l’état du message (envoyé ou non envoyé), ce dernier va rester dans la boîte d’envoi et l’utilisateur du compte aura à décider de comment procéder.

Folder actions

Add a folder

  1. Ouvrir le menu d’actions d’un compte

  2. Click add folder

Add a subfolder

  1. Open the action menu of a folder

  2. Click add subfolder

Shared folder

If a folder was shared with you with some specific rights, that folder will show as a new folder with a shared icon as below:

Enveloppe d’Actions

Créer un évènement

Créez un événement pour un certain message/fil de discussion directement dans l’application Mail

  1. Ouvrez le menu d’action d’une enveloppe

  2. Cliquez sur Plus d’actions

  3. Cliquez sur Créer un événement

Note

An event title and agenda are created for you if the administrator has enabled it.

Créer une tâche

Ajouté dans la version 3.2: Nextcloud 26 or newer

Créez une tâche pour un certain message/fil de discussion directement dans l’application Mail

  1. Ouvrez le menu d’action d’une enveloppe

  2. Cliquez sur plus d’actions

  3. Cliquez sur créer une tâche

Note

Les tâches sont stockées dans des calendriers pris en charge. S’il n’existe pas de calendrier compatible, vous pouvez en créer un nouveau avec calendar app.

Éditer les étiquettes

  1. Ouvrez le menu d’action d’une enveloppe

  2. Cliquer sur Modifier les étiquettes

  3. Sur la fenêtre modale des étiquettes, activer/désactiver les étiquettes

Changer la couleur des étiquettes

Ajouté dans la version 3.5: Nextcloud 26 or newer

Au moment de la création d’une étiquette, une couleur attribuée au hasard est automatiquement sélectionnée. Une fois l’étiquette enregistrée, vous avez la liberté de personnaliser sa couleur en fonction de vos préférences. Cette fonctionnalité se trouve dans le menu d’action modal Étiquette.

Supprimer les étiquettes

Ajouté dans la version 3.5: Nextcloud 26 or newer

Vous avez désormais la possibilité de supprimer les étiquettes que vous avez créées précédemment. Pour accéder à cette fonctionnalité :

  1. Ouvrez le menu d’actions d’une enveloppe/fil de discussion.

  2. Sélectionnez Modifier les étiquettes.

  3. À l’intérieur de la fenêtre modale des étiquettes, ouvrez le menu d’actions spécifique à l’étiquette que vous souhaitez supprimer.

Note

Veuillez noter que les étiquettes par défaut telles que Travail, À faire, Personnel et Plus tard ne peuvent pas être supprimées, elles peuvent être uniquement renommées.

Résumé IA

Ajouté dans la version 4.2: Nextcloud 30 or newer

When looking through your folder you will see a short AI generated summary of your emails as a preview.

Note

Veuillez noter que cette fonctionnalité doit être activée par l’administrateur

Actions rapides

Ajouté dans la version 5.5: Nextcloud 30 or newer

Vous permettent de regrouper les différentes étapes des actions que vous feriez normalement sur les enveloppes, telles que l’étiquetage, le déplacement, le marquage comme lu… sous la forme d’actions rapides qui peuvent être exécutées en un seul clic. La portée des actions rapides se limite à un seul compte de messagerie et elles peuvent être créées et gérées dans les paramètres de messagerie dans « Actions rapides » ou directement à partir du menu d’action de l’enveloppe.

Note

Certaines étapes de l’action comme Marquer comme indésirable, Déplacer ce fil de discussion et Supprimer ce fil de discussion sont mutuellement exclusives et ne peuvent pas faire partie de la même action rapide. Elles ne peuvent pas non plus être réordonnées et elles seront toujours exécutées en dernier.

Note

Veuillez noter que les actions rapides seront exécutées sur tous les messages d’un fil de discussion lorsqu’elles sont lancées sur un seul d’entre eux.

Actions sur les messages

Se désinscrire de la liste d’envoi

Ajouté dans la version 3.1: Nextcloud 26 or newer

Certaines listes de diffusion et newsletters permettent de se désabonner facilement. Si l’application Mail détecte des messages provenant d’un tel expéditeur, elle affichera un bouton Se désabonner à côté des informations sur l’expéditeur. Cliquez et confirmez pour vous désabonner de la liste.

Mettre en attente

Ajouté dans la version 3.4: Nextcloud 26 or newer

Snoozing a message or thread moves it into a dedicated folder until the selected snooze date is reached and the message or thread is moved back to the original folder.

  1. Ouvrir le menu d’action d’une enveloppe ou d’un fil de discussion

  2. Cliquez sur Mettre en attente

  3. Sélectionnez la durée pendant laquelle le message ou le fil de discussion doit être mis en attente

Réponses intelligentes

Ajouté dans la version 3.6: Nextcloud 26 or newer

Lorsque vous ouvrez un message dans l’application Mail, des réponses générées par IA sont proposées. Il suffit de cliquer sur une réponse suggérée pour que le compositeur s’ouvre avec la réponse préremplie.

Note

Veuillez noter que cette fonctionnalité doit être activée par l’administrateur

Note

Les langues prises en charge dépendent du grand modèle de langage utilisé

Traduction d’e-mail

Ajouté dans la version 4.2: Nextcloud 30 or newer

Vous avez la possibilité de traduire les messages dans vos langues qui sont configurées, de manière similaire à Talk.

Note

Veuillez noter que les fonctionnalités de traduction doivent être activées sur le serveur

Note

Depuis la version 5.3, si un LLM est activé par l’administrateur, les traductions seront proposées

Résumé de fil de discussion

L’application Mail prend en charge le fait de résumer les fils de discussion qui contiennent 3 messages ou plus.

Ajouté dans la version 3.4: Nextcloud 26 or newer

Note

Veuillez noter que cette fonctionnalité doit être activée par l’administrateur

Note

Veuillez noter que cette fonctionnalité ne fonctionne bien qu’avec integration_openai. Les LLM locaux prennent trop de temps pour répondre et la demande de résumé risque de ne pas aboutir tout en ayant un impact significatif sur la charge système.

Filtrage et répondeur automatique

L’application Mail possède un éditeur pour des scripts Sieve, une interface pour configurer des répondeurs automatiques et une interface pour configurer les filtres. Sieve doit être activé dans les paramètres de compte.

Répondeurs automatiques

Ajouté dans la version 3.5: Nextcloud 26 or newer

Le répondeur automatique est désactivé par défaut. Il peut être configuré manuellement ou suivre les paramètres système. Suivre les paramètres système signifie que le long message d’absence entré dans la section des paramètres d’absence est appliqué automatiquement.

Filtre

Ajouté dans la version 4.1: Nextcloud 30 or newer

Mail 4.1 contient un éditeur simple pour configurer les règles de filtrage.

Note

L’importation de filtres existants n’est pas pris en charge. Cependant, tous les filtres existants resteront actifs et inchangés. Nous vous recommandons de sauvegarder votre script actuel depuis l’éditeur de script Sieve à titre de précaution.

Comment ajouter un nouveau filtre

  1. Ouvrez vos paramètres de compte.

  2. Vérifiez que Sieve est activé pour votre compte (voir les paramètres du serveur Sieve).

  3. Cliquez sur Filtres.

  4. Sélectionnez Nouveau filtre pour créer une nouvelle règle.

Comment supprimer un filtre

  1. Ouvrez vos paramètres de compte.

  2. Assurez-vous que Sieve est activé pour votre compte (voir les paramètres du serveur Sieve).

  3. Cliquez sur Filtres.

  4. Survolez le filtre que vous souhaitez supprimer, puis cliquez sur l’icône corbeille.

Conditions

Des conditions sont appliquées aux e-mails entrants sur votre serveur de messagerie, ciblant des champs tels que Objet, Expéditeur et Destinataire. Vous pouvez utiliser les opérateurs suivants pour définir des conditions pour ces champs :

  • est exactement : Une correspondance exacte. Le champ doit être identique à la valeur fournie.

  • contient : Une correspondance de sous-chaîne. Le champ correspond si la valeur fournie est contenue dans celui-ci. Par exemple, « rapport » correspondrait à « port ».

  • correspond : Une correspondance de modèle utilisant des caractères génériques. Le symbole « * » représente un nombre quelconque de caractères (y compris aucun), tandis que « ? » représente exactement un caractère. Par exemple, « rapport » correspondrait à « rapport d’activité 2024 ».

Actions

Les actions sont déclenchées quand les tests spécifiés sont vrais. Les actions suivantes sont disponibles :

  • fileinto : déplace le message vers un dossier spécifié.

  • addflag : ajoute un drapeau au message.

  • stop : interrompt l’exécution du script de filtrage. Aucun autre filtre ne sera traité après cette action.

Créer un filtre à partir d’un message

Ajouté dans la version 5.2: Nextcloud 30 or newer

Pour créer un filtre à partir d’un message donné, ouvrez le message puis ouvrez le menu en cliquant sur les trois points. Ensuite, cliquez sur « Plus d’actions » et enfin sur « Créer un filtre d’email ».

Dans la boîte de dialogue, sélectionnez les conditions auxquelles doivent correspondre les messages entrants puis continuez en cliquant sur « Créer un filtre d’email ».

Rappels de suivi

Ajouté dans la version 4.0: Nextcloud 30 or newer

L’application Mail vous fera un rappel automatiquement quand un e-mail sortant n’a pas obtenu de réponse. Chaque e-mail envoyé sera analysé par une IA pour vérifier si une réponse est attendue. Au bout de quatre jours, tous les e-mails concernés seront affichés dans votre boîte de réception prioritaire.

Quand vous cliquez sur un tel e-mail, un bouton s’affichera pour faire un suivi rapide avec tous les destinataires. Il est aussi possible de désactiver les rappels de suivi pour un e-mail envoyé.

Note

Veuillez noter que cette fonctionnalité doit être activée par l’administrateur.

Sécurité

Détection d’hameçonnage

Ajouté dans la version 4.0: Nextcloud 30 or newer

L’application Mail vérifiera les tentatives d’hameçonnage potentielles et affichera un avertissement à l’utilisateur.

Les contrôles sont les suivants :

  • L’adresse de l’expéditeur enregistrée dans le carnet d’adresses n’est pas la même que celle du compte de messagerie

  • L’expéditeur se sert d’une adresse e-mail personnalisée qui ne correspond pas à l’adresse du champ De

  • La date d’envoi est dans le futur

  • Les liens dans le corps du message ne pointent pas vers le texte affiché

  • L’adresse de réponse n’est pas la même que celle de l’expéditeur

Note

Veuillez noter que l’avertissement ne signifie pas que le message est une tentative d’hameçonnage. Il indique uniquement que l’application Mail a détecté une tentative d’hameçonnage potentielle.

Adresses internes

Ajouté dans la version 4.0: Nextcloud 30 or newer

L’application Mail permet l’ajout d’adresses et de domaines internes, et avertira l’utilisateur si l’adresse ne figure pas dans la liste, lors de l’envoi ou de la réception d’un message.

Pour ajouter une adresse interne :

  1. Ouvrez les paramètres de Mail

  2. Naviguez jusqu’à la section Confidentialité et sécurité

  3. Activez les adresses internes en cliquant sur la case à cocher

  4. Cliquez sur le bouton Ajouter une adresse interne

  5. Entrez l’adresse ou le domaine et cliquez sur Ajouter

Intégration au tableau de bord

Ajouté dans la version 1.8: Nextcloud 20 or newer

L’application Mail offre deux widgets conçus pour être intégrés dans le tableau de bord de Nextcloud :

  • E-mails non lus : Ce widget affiche les e-mails non lus.

  • E-mails importants : Ce widget montre les e-mails qui ont été marqués comme importants.

Ces widgets utilisent les e-mails issus des comptes de messagerie qui sont configurés sur votre compte.

Intégration dans l’Agenda

L’application Mail s’intègre à l’application Agenda pour vous aider à gérer vos invitations à des réunions et maintient votre agenda à jour.

Invitations aux réunions

Lorsque vous recevez un message contenant une invitation à une réunion, l’application Mail détecte automatiquement le fichier d’agenda en pièce jointe et affiche un paragraphe mis en forme proposant une action pour vous aider à répondre.

Vous pouvez :

  • Accepter l’invitation

  • Décliner l’invitation

  • Accepter provisoirement l’invitation

Votre réponse est envoyée directement par l’application Mail et l’événement est ajouté à votre calendrier principal en conséquence.

Vous pouvez aussi ajouter une invitation à une réunion dans un agenda spécifique :

  1. Ouvrez le message avec l’invitation à la réunion

  2. Faites défiler le message vers le bas, jusqu’à la section des pièces jointes

  3. Sélectionnez le fichier d’agenda (généralement avec l’extension .ics) puis cliquez sur le menu à trois points.

  4. Cliquez sur « Importer dans l’agenda » et choisissez l’agenda voulu.

Automatisation des invitations aux réunions

Quand l’organisateur d’une réunion envoie des mises à jour sur un événement existant (comme des modifications d’horaires ou un changement de salle), l’application Mail les traite automatiquement et actualise l’événement correspondant dans votre agenda.

Ajouté dans la version 5.7: Nextcloud 32 or newer

Vous pouvez également configurer Mail pour ajouter automatiquement toutes les nouvelles invitations de réunions à votre agenda sans avoir besoin de les accepter manuellement. Les invitations seront ajoutées à l’agenda comme étant provisoires.

Pour activer cette fonctionnalité :

  1. Rendez-vous dans les paramètres de compte d’un compte de messagerie spécifique

  2. Naviguez jusqu’à la section des paramètres de l’agenda

  3. Activez Créer des rendez-vous provisoires automatiquement dans le calendrier

Note

Avec ce réglage activé, les invitations apparaîtront toujours dans votre liste d’e-mails, mais elles seront automatiquement ajoutées à votre agenda.

Raccourcis clavier

L’application Mail implémente plusieurs raccourcis clavier pour vous faire gagner du temps à l’utilisation.

Pour trouver la liste complète des raccourcis clavier pris en charge, allez dans les paramètres de Mail sur votre instance.
