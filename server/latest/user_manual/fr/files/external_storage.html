Utilisation du stockage externe

L’application Stockage externe permet de connecter votre serveur Nextcloud à des systèmes de fichiers distants — tels qu’Amazon S3, des serveurs SFTP, des partages SMB/CIFS ou des serveurs WebDAV — et de les présenter sous forme de dossiers dans votre vue de Fichiers. Votre équipe d’administration configure quels sont les backends disponibles et les montages partagés avec vous.

Si votre administrateur a activé la gestion du stockage externe par les utilisateurs, vous pouvez également ajouter vos propres connexions dans les Paramètres personnels.

Accéder au stockage externe

Les montages de stockage externe apparaissent comme des dossiers classiques dans votre vue de Fichiers. Vous pouvez parcourir, téléverser, télécharger et supprimer des fichiers à l’intérieur tout comme pour n’importe quel autre dossier. Que la possibilité de partager soit disponible ou non dépend de la façon dont votre administrateur l’a activée pour chaque montage individuellement.

Un indicateur coloré situé à côté du nom de dossier montre l’état de la connexion :

  • Vert — le stockage est connecté et prêt à être utilisé.

  • Jaune — le stockage n’a pas pu être atteint ; Nextcloud réessaiera automatiquement.

  • Rouge — le stockage n’est pas disponible. Contactez votre administrateur si le problème persiste.

Quand un montage n’est pas disponible, Nextcloud le marque comme étant hors ligne pour une durée de dix minutes avant de réessayer. Vous pouvez déclencher une revérification manuelle en cliquant sur l’indicateur d’état.

Note

Certains montages de stockage externe peuvent n’être accessibles qu’en lecture seule. Il n’est pas possible de téléverser ou supprimer des fichiers sur un montage en lecture seule.

Partage de fichiers depuis le stockage externe

Créer un partage à partir d’un montage de stockage externe fonctionne de la même manière que le partage d’un fichier ou d’un dossier — utilisez l’icône de partage dans la vue Fichiers. Comme la possibilité de partager doit être explicitement activée par votre administrateur sur chaque montage, il est possible que l’icône de partage ne soit pas toujours disponible.

Note

Le chiffrement côté serveur n’est pas disponible pour les montages externes qui pointent vers d’autres instances Nextcloud.

Ajout de votre propre stockage externe

Si votre administrateur a activé la gestion du stockage externe par les utilisateurs, vous pouvez connecter votre propre stockage externe dans Paramètres personnels → Stockage externe.

Pour ajouter un nouveau montage :

  1. Cliquez sur votre icône de profil et sélectionnez Paramètres personnels.

  2. Sélectionnez Stockage externe dans la barre latérale de gauche.

  3. Choisissez un backend dans la liste déroulante Ajouter un stockage.

  4. Remplissez les champs requis du backend (adresse du serveur, chemin, identifiants etc.).

  5. Sélectionnez une méthode d’authentification dans la liste déroulante Authentification.

Les champs requis sont marqués avec une bordure rouge. Une fois que tous les champs requis sont remplis, le montage est enregistré automatiquement.

Un point vert à côté du montage confirme une connexion réussie. Une icône jaune ou rouge signifie que Nextcloud n’a pas pu se connecter — vérifiez vos identifiants et les paramètres réseau.

Pour enlever un montage, ouvrez le menu à trois points qui se trouve à côté de celui-ci puis sélectionnez Supprimer.

Note

Les montages que vous ajoutez depuis les Paramètres personnels ne sont visibles que pour votre compte.

Backends pris en charge

Les backends suivants peuvent être disponibles, en fonction de ceux qui ont été activés par votre administrateur :

  • Amazon S3 — Compartiments Amazon Simple Storage Service et stockage compatible S3.

  • FTP — Serveurs FTP et FTPS.

  • Nextcloud / ownCloud — Autre instance Nextcloud ou ownCloud utilisant WebDAV.

  • OpenStack Object Storage — Conteneurs OpenStack Swift.

  • SFTP — Serveurs SSH File Transfer Protocol.

  • SMB / CIFS — Partages de fichiers Windows et serveurs Samba.

  • WebDAV — Tout serveur compatible WebDAV.

Pour les détails de configuration spécifiques aux backends, consultez Configuration du stockage externe (GUI) dans le Manuel d’administration.

Détection de modification des fichiers

Les fichiers que vous ajoutez ou que vous modifiez via Nextcloud sont pris en compte aussitôt. Ceux que vous ajoutez ou modifiez directement sur le stockage externe — sans passer par Nextcloud — peuvent ne pas apparaître jusqu’à la prochaine analyse en arrière-plan.

Si des fichiers ajoutés depuis l’extérieur n’apparaissent pas, demandez à votre administrateur d’exécuter occ files:scan ou de configurer une analyse périodique en arrière-plan pour le montage.
