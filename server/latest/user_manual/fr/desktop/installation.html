Installation

Téléchargement

Vous pouvez télécharger la dernière version du client de synchronisation Nextcloud depuis la page de téléchargement de Nextcloud. Des clients sont disponibles pour Linux, macOS et Microsoft Windows.

Vous pouvez aussi trouver des liens vers les archives de code source et les anciennes versions sur la page de téléchargement.

Versions du serveur prises en charge

Chaque version du client de bureau prend en charge les trois dernières versions majeures stables du serveur Nextcloud au moment de sa publication. Voir le calendrier des sorties du serveur Nextcloud pour les versions majeures prises en charge.

Configuration requise

  • Windows 10+ (uniquement 64-bits)

  • macOS 12.0+ (uniquement 64-bits)

  • Linux (Ubuntu 24.04 ou openSUSE 15.5 ou Alma 8 ou…) (64 bits uniquement)

    Pour les distributions Linux, si cela est techniquement faisable, les versions à support étendu (LTS) actuelles sont prises en charge. Si cela est techniquement faisable, les systèmes BSD sont pris en charge mais ne sont pas testés.

Note

Nous ne prenons pas en charge Citrix.

  • Nous ferons tout notre possible pour conseiller les utilisateurs de Citrix du point de vue du client de bureau.

  • Nous corrigerons les problèmes qui peuvent aussi être reproduits sur les systèmes standards pris en charge.

  • Tout le reste est hors de notre portée.

Installation sur macOS et Windows

L’installation sur macOS et Windows est la même que pour tout autre application logicielle : télécharger le logiciel et ensuite double-cliquer dessus pour démarrer l’installation, puis suivre les instructions de l’installateur. Une fois le client de bureau installé et configuré, il se mettra automatiquement à jour. Voir L’agent de mise à jour automatique pour plus d’informations.

Pour les options de déploiement à destination des administrateurs, telles que la configuration Windows MSI avancée, le provisionnement de comptes non-interactif et la préconfiguration de l’assistant en ligne de commande, consultez le chapitre sur la configuration et le déploiement du client de bureau dans le Manuel d’administration.

Installation sur Linux

Pour Linux, Nextcloud fournit officiellement le client de bureau sous la forme d’une AppImage sur la page de téléchargement de Nextcloud.

Certaines distributions Linux proposent également le client de bureau Nextcloud depuis leur gestionnaire de paquets. Ces paquets sont maintenus par la distribution ou par la communauté et non par Nextcloud. Si vous préférez une gestion de l’installation à base de paquets, référez-vous à la documentation de votre distribution.

Les utilisateurs Linux doivent aussi avoir un gestionnaire de mots de passe activé, comme GNOME Keyring, ou KWallet, pour que le client de bureau puisse se connecter automatiquement.

Configuration initiale

Après l’installation, l’assistant de configuration s’ouvre. Saisissez l’adresse que vous utilisez pour accéder à votre serveur Nextcloud dans un navigateur puis cliquez sur Se connecter.

Pour les étapes restantes de l’assistant, dont l’autorisation du navigateur et les options de synchronisation, voir Ajouter un compte.
