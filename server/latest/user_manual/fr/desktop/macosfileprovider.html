Utilisation intégré aux gestionnaire de fichiers macOS

Sur macOS, notre client peut également intégrer facilement des fichiers Nextcloud dans macOS via une extension de Fournisseur de fichiers. Tout compte Nextcloud nouvellement configuré disposera de cette extension activée par défaut.

Fonctionnalités prises en charge

  • Disponibilité de fichiers ou de dossiers entiers maintenue hors connexion

  • Libération d’espace disque local par l’éviction de copies locales sans supprimer les éléments

  • Éviction intelligente et automatique de données locales

  • Prévisualisation des fichiers depuis le Finder pour les fichiers qui n’ont pas encore été téléchargés

  • Prise en charge des formats spécifiques à Apple, par exemple les paquets Pages, Numbers ou Keynote

  • Prise en charge du verrouillage de fichiers côté serveur (si cela est géré par le serveur connecté)

  • Prise en charge de « Modifier localement »

  • Partage avec d’autres utilisateurs

  • Actions côté serveur intégrées directement dans le menu contextuel du Finder

  • Découverte automatique des modifications côté serveur

Configuration

Les paramètres relatifs à l’extension Fournisseur de fichiers peuvent être ajustés, par compte, via la fenêtre des paramètres du client de bureau Nextcloud.

L’intégration dans le Finder peut être activée ou désactivée ici.

Quand l’extension Fournisseur de fichiers est désactivée alors qu’il y a encore des modifications non synchronisées, macOS enregistre les éléments non synchronisés dans un dossier qui est révélé automatiquement après la désactivation de l’intégration.

Intégration Finder

Sur macOS, le stockage distant comme un compte de fichiers Nextcloud apparaît comme un emplacement dédié dans la barre latérale du Finder. L’emplacement réel du contenu sur le disque est défini par macOS.

Note

Pour accélérer la détection des modifications côté serveur, nous conseillons l’activation de l’application notify_push sur votre serveur Nextcloud. Cette application notifiera au client de bureau les modifications du serveur dès qu’elles se produisent, ce qui réduira le temps pris pour que les modifications apparaissent dans le Finder. Sinon, le client a besoin d’interroger régulièrement le serveur, ce qui occasionne un délai plus important entre la modification sur le serveur et sa visibilité en local.

Indicateurs de l’état de synchronisation

À l’instar des dossiers de synchronisation classique, le Finder affiche des indicateurs d’état à côté des éléments. Mais contrairement aux indicateurs personnalisés des dossiers de synchronisation classique, ces indicateurs standardisés sont fournis par macOS pour garantir une apparence cohérente dans toutes les applications de stockage cloud que l’utilisateur est susceptible d’utiliser sur son système.

  • Nuage avec une flèche vers le bas : l’élément et ses descendants ne sont pas encore téléchargés. Ils pourraient l’être, à condition qu’une connexion réseau soit disponible.

  • Nuage surligné : l’élément n’a pas encore été téléversé en totalité par rapport à son état actuel en local.

  • Nuage barré : l’élément est exclu de la synchronisation.

  • Secteurs : l’élément est en cours de téléversement ou de téléchargement, et la progression est visualisée.

  • Cercle plein avec une épingle : l’élément est disponible hors connexion et sera conservé en local.

  • Pas d’icône : l’élément est à jour et disponible hors connexion.

Actions du menu contextuel

L’extension Fournisseur de fichiers apporte également des fonctionnalités Nextcloud spéciales dans le Finder par l’intermédiaire du menu contextuel.

Garder en Téléchargés

Les fichiers et les dossiers peuvent être marqués pour être conservés téléchargés et disponibles hors ligne en permanence. Si ce choix est fait sur des dossiers, cela s’applique aussi à la totalité de leur contenu. C’est particulièrement utile pour les utilisateurs qui disposent d’un accès réseau limité ou qui n’ont pas de réseau, car cela leur garantit la possibilité de toujours avoir accès à leurs fichiers importants sans se préoccuper de la connectivité réseau. macOS ne libérera pas l’espace disque local en évinçant les éléments qui sont marqués pour être conservés téléchargés, même s’ils n’ont pas été consultés depuis très longtemps.

Cela peut être annulé en sélectionnant « Autoriser la libération automatique de l’espace » sur les mêmes éléments.

Pour toujours tout conserver dans un compte disponible en local, vous pouvez sélectionner « Toujours conserver en local » sur la racine de l’emplacement dans la barre latérale du Finder.

Verrouillage

Si le serveur prend en charge le verrouillage de fichiers, le client offrira le verrouillage et le déverrouillage manuels des fichiers dans le Finder.

Partage

Quand le serveur prend en charge le partage et que l’élément est autorisé à être partagé, vous pouvez alors créer de nouveaux partages ou gérer ceux existants pour un élément directement depuis le menu contextuel du Finder, tout comme dans l’interface web de Nextcloud.

Actions sur les fichiers

Si le serveur dispose d’applications installées qui fournissent des actions de fichiers pour les types de fichiers sélectionnés, ces actions seront également disponibles dans le menu contextuel du Finder. Cela vous permet d’utiliser des fonctionnalités de votre instance Nextcloud côté serveur directement depuis le Finder.

Problèmes connus

Conflit entre extensions macOS

En raison de limitations techniques dans macOS, lesquelles sont imposées par Apple, il n’est pas possible de faire fonctionner l’intégration Finder pour les dossiers de synchronisation classique en parallèle avec une extension File Provider activée. Cela signifie que les décorations des éléments et les options du menu contextuel resteront indisponibles pour les dossiers de synchronisation classique tant que l’extension File Provider est activée.

Fichiers d’alias

Lorsqu’un fichier d’alias macOS stocké sur Nextcloud est ouvert pour la première fois sur un appareil sur lequel il n’a encore jamais été téléchargé, le fichier peut s’ouvrir dans un éditeur de texte en tant que document binaire au lieu de sauter vers sa cible. Cela arrive car macOS décide de quelle façon un fichier doit s’ouvrir avant de le télécharger, et les fichiers d’alias ne comportent pas d’informations de type ni d’extension de fichier reconnaissable sur le serveur — la seule façon de les identifier consiste à lire leur contenu. Une fois le fichier ouvert ou téléchargé une première fois, le Bureau Nextcloud se rend compte qu’il s’agit d’un alias et stocke cette information en local de manière à ce que toutes les ouvertures ultérieures fonctionnent correctement. Pour complètement éviter ce problème, faites un clic droit sur le fichier d’alias dans le Finder et choisissez Garder en Téléchargés avant de l’ouvrir pour la première fois.

Modifier localement

L’action Modifier localement offerte par l’interface web de Nextcloud ne peut pas ouvrir les fichiers qui sont gérés par l’extension File Provider. Elle peut seulement les révéler dans le Finder.

Il s’agit d’une restriction de macOS lui-même et non de la faute du client. Pour votre protection, macOS n’autorise que certaines applications spécifiques à ouvrir un fichier donné, et il ne donne pas à une application le droit de s’accorder cette permission à elle-même. La composante du client qui est autorisée à gérer ces fichiers a l’interdiction de lancer d’autres applications et celle qui pourrait lancer l’exécution de votre éditeur n’a pas le droit d’ouvrir le fichier.

Accorder l’Accès complet au disque n’est d’aucun secours car une partie différente du système de sécurité de macOS en est responsable.

Dépannage

Journalisation de niveau débogage

Les entrées de journal de niveau débogage de l’extension Fournisseur de fichiers sont désactivées par défaut. Si vous voulez signaler un problème concernant le Fournisseur de fichiers, il peut être utile de les activer pour obtenir des informations plus détaillées sur ce qui se passe sous le capot. Pour les activer, vous devez entrer la commande suivante dans le Terminal :

defaults write com.nextcloud.desktopclient.FileProviderExt debugLoggingEnabled -bool YES

La modification prend effet en quelques secondes ; aucun redémarrage de l’extension ni du Mac n’est nécessaire. Il est conseillé de revenir à l’état par défaut en supprimant la valeur explicite une fois que vous avez résolu le problème qui était en cours d’investigation :

defaults delete com.nextcloud.desktopclient.FileProviderExt debugLoggingEnabled
