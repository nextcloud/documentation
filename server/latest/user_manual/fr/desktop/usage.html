Utilisation du Client

Le client de bureau Nextcloud fonctionne en arrière-plan. Accédez à ses paramètres depuis son icône dans la zone de notification système sur Windows et Linux, ou depuis la barre de menu sur macOS.

Ajouter un compte

Pour connecter un autre compte Nextcloud, ouvrez la boîte de dialogue des paramètres et cliquez sur Ajouter un compte dans la barre latérale. Entrez l’adresse que vous utilisez pour accéder à votre serveur Nextcloud dans un navigateur puis cliquez sur Se connecter.

Si votre réseau nécessite un serveur mandataire, cliquez sur Paramètres du proxy avant de vous connecter. Choisissez le proxy du système ou saisissez manuellement ses paramètres, puis cliquez sur Terminer.

Si la connexion sécurisée échoue, vérifiez l’adresse du serveur et contactez l’administrateur de celui-ci. L’assistant peut proposer de se connecter sans TLS ou d’utiliser un certificat client. Employez Utiliser un certificat client seulement si votre serveur en nécessite un.

Si un certificat client est demandé, choisissez le fichier PKCS#12 fourni par votre administrateur, saisissez son mot de passe puis cliquez sur Se connecter.

L’assistant vous demande de basculer vers votre navigateur. Cliquez sur Ouvrir si celui-ci ne s’est pas ouvert automatiquement. Connectez-vous et accordez l’accès au client de bureau quand cela est demandé. Retournez ensuite sur l’assistant.

Choisissez la façon de synchroniser vos fichiers. Avec la synchronisation classique, choisissez Synchroniser tout ou Choisir les éléments à synchroniser. Utilisez Choisir à côté de Dossier local de synchronisation pour changer l’emplacement de stockage des fichiers, puis cliquez sur Terminé.

Vous pouvez choisir File Provider pour télécharger des fichiers à la demande. Cliquez sur Terminé pour achever l’ajout du compte. Sur macOS, consultez Utilisation intégré aux gestionnaire de fichiers macOS pour les détails sur l’intégration dans le Finder.

Avant de terminer la configuration de la synchronisation classique, cliquez sur Avancé si vous voulez une confirmation avant de synchroniser des dossiers volumineux ou du stockage externe. Définissez vos préférences dans Options avancées puis cliquez sur Terminé pour retourner à l’assistant.

Boîte de dialogue des paramètres

Sélectionnez un compte dans la barre latérale pour voir son statut de synchronisation, son dossier local, son utilisation du stockage et les paramètres de connexion. Utilisez Ajouter une connexion de synchronisation de dossier pour configurer un autre dossier de synchronisation classique pour ce compte. Vous pouvez vous déconnecter ou supprimer le compte depuis cette même page.

Dans Général, indiquez si vous voulez ou non lancer le client au démarrage, utiliser les icônes monochromes et afficher les notifications. Sur macOS, vous pouvez aussi activer File Provider pour tous les comptes. Ce paramètre remplace les dossiers de synchronisation classique et leur intégration dans le Finder.

Dans Avancé, définissez les seuils de confirmation pour les dossiers volumineux et les stockages externes. Vous pouvez également ajuster l’intervalle d’interrogation du serveur, décider si les fichiers supprimés vont à la corbeille, modifier les fichiers ignorés ou créer une archive de débogage.

Pour exclure des fichiers ou des dossiers de la synchronisation, cliquez sur Modifier les fichiers ignorés dans Avancé. Ajoutez un modèle pour chaque élément que vous voulez ignorer. Un astérisque (*) remplace tout nombre de caractères, un point d’interrogation (?) remplace un unique caractère et une barre oblique finale (/) limite un modèle aux dossiers. Sélectionnez Autoriser la suppression seulement pour les éléments ignorés que le client peut supprimer s’ils empêchent la suppression d’un dossier. Cliquez sur OK pour enregistrer.

Dans Informations, vous pouvez consulter la version du client de bureau et ouvrir sa documentation d’utilisation ou les mentions légales.

Icône de la zone de notification système

Le client de bureau affiche une icône de statut dans la zone de notification système sur Windows et Linux ou dans la barre de menu sur macOS. Les icônes de statut en couleur, et celles en couleur ou monochrome dans la zone de notification, sont disponibles pour les mêmes états de synchronisation. Vous pouvez opter pour les icônes monochromes dans la boîte de dialogue des paramètres, dans Général.

Ouvrez l’icône de la zone de notification système ou de la barre de menu pour voir le client et les actions disponibles, telles que la mise en pause ou la reprise de la synchronisation.

Icônes superposées du gestionnaire de fichiers

Pour les dossiers de synchronisation classique, le client de bureau superpose des icônes sur les fichiers dans le gestionnaire de fichiers. Une marque de validation verte signifie que le fichier est à jour. Une icône d’avertissement peut signifier qu’un fichier est ignoré ; un X rouge indique une erreur de synchronisation. Une icône bleue indique un fichier dont la synchronisation est en cours ou en attente. Quand le client est hors ligne, il n’affiche pas d’icône superposée pour le statut actuel de synchronisation des dossiers.

L’icône superposée sur un dossier reflète les erreurs de synchronisation de son contenu. Les fichiers ignorés ne changent pas le statut du dossier parent. Sur macOS, File Provider utilise les indicateurs de statut standards du Finder décrits dans Utilisation intégré aux gestionnaire de fichiers macOS.

Partage

Le client de bureau intègre des actions de partage dans le Finder sur macOS et dans l’Explorateur sur Windows. Sur Linux, installez le paquet d’intégration pour votre gestionnaire de fichiers, comme nautilus-nextcloud ou dolphin-nextcloud.

Dans votre gestionnaire de fichiers, faites un clic droit sur un fichier et sélectionnez Nextcloud > Options de partage pour ouvrir la boîte de dialogue de partage.

Utilisez Rechercher des destinataires pour partager le fichier avec des personnes ou des groupes. Les partages et liens de partage existants apparaissent sous le champ de recherche. Utilisez le bouton de copie pour copier un lien interne ou un lien de partage. Utilisez le menu à trois points pour modifier un partage, ou le bouton X pour le supprimer.

Quand vous modifiez un partage, choisissez la permission du destinataire dans le menu déroulant. Vous pouvez également ajouter une note pour les destinataires. Les modifications sont appliquées immédiatement.

Ouvrez Paramètres de partage avec le bouton engrenage pour définir une date d’expiration ou protéger le partage avec un mot de passe. Les modifications sont appliquées immédiatement.
