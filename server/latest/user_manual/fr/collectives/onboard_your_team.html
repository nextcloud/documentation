Comment intégrer votre équipe

Notre premier projet : Présentations

Étape 1 : Créer une page parente « Présentations » 📃

  1. Cliquez sur le bouton ➕ à côté du nom du collectif dans la barre latérale côté gauche dans Collectifs.

  2. Une nouvelle page est créée. Nous pouvons utiliser cette page comme page parente pour nos présentations ! Remplissons-la avec quelques mots de présentation pour accueillir les visiteurs et donnons-lui le titre Présentations.

Étape 2 : Créer ensemble un modèle “Présentation” 👥

  1. Il serait bien et plus accessible que toutes les présentations aient le même format ! Chacun pourrait ajouter une image, une brève description et expliquer ce qu’il apprécie dans l’organisation du collectif. Collectifs rend cela très simple. Nous créons rapidement un modèle avec exactement ce contenu afin que chaque nouvel arrivant puisse répondre facilement.

  2. Cliquez sur le bouton … à côté de votre collectif. Choisissez « Gérer les modèles » puis « Ajouter un modèle ». Collectifs ajoute à présent une page pour que vous la remplissiez, afin qu’elle puisse être plus tard retrouvée facilement et copiée par chaque personne qui souhaite créer une présentation.

  3. Donnez à votre modèle le titre Présentation. Ajoutez maintenant vos champs sous forme de texte simple dans votre document - n’oubliez pas de prendre ces décisions collectivement ! En appuyant sur le bouton Tt dans la barre d’outils de formatage, vous pouvez mettre en forme votre nouveau texte pour en faire des titres !

  4. Lorsque vous avez terminé, appuyez simplement sur le bouton Fermer - votre modèle sera automatiquement enregistré et vous serez renvoyé dans votre gestionnaire de modèles.

  5. Pour finir, ajoutons un émoji amusant à notre nouveau modèle. Cliquez sur le bouton … à côté de votre nouveau modèle puis sur Sélectionner un émoji… Après cela, vous pouvez fermer le gestionnaire de modèles.

Étape 3 : Chacun crée la sienne ! 💫

  1. C’est là où la magie va opérer 🪄! À présent, chacun sur son propre ordinateur ! Cliquez sur le bouton ➕ à côté de votre page « Présentations » que nous avons créée à la première étape. Sélectionnez le modèle « Présentations ». Utilisez votre nom ou votre pseudo comme titre pour la page et remplissez les champs que vous avez définis !

  2. Wow! We just quickly created a cohesive and unifying « Introductions » page in our collective. Becoming part of your collective will be much less scary now for new members! Congratulations! 🎉
