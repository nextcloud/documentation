Interagir avec des messages

Éditer des messages

Vous pouvez modifier les messages et les légendes des fichiers partagés jusqu’à 6 heures après leur envoi.

Épingler des messages

Un modérateur peut épingler les messages importants d’une conversation pendant une durée déterminée ou jusqu’à ce qu’ils ne soient plus pertinents.

Les messages épinglés sont mis en évidence et accessibles au-dessus de la conversation ou dans l’onglet « Éléments partagés » de la barre latérale. Si vous n’avez plus besoin d’un message épinglé, vous pouvez le désépingler pour tout le monde ou uniquement pour vous depuis les actions rapides.

Définition de rappels pour les messages

Vous pouvez définir des rappels pour certains messages. Pour être averti ultérieurement d’un message important, survolez-le, puis cliquez sur l’icône de rappel.

Dans le sous-menu, vous pouvez sélectionner l’heure à laquelle vous souhaitez recevoir une notification.

Vous pouvez également transférer un message vers une autre conversation à l’aide du menu « … », ou l’envoyer dans votre conversation Notes personnelles pour le conserver à titre de référence.

Recherche de messages dans une conversation

En plus de la recherche unifiée globale, vous pouvez rechercher des messages dans une conversation donnée. Dans la barre latérale de la conversation, cliquez sur l’icône de recherche pour ouvrir l’onglet de recherche.

Vous pouvez affiner votre recherche à l’aide de filtres, tels qu’un intervalle de dates et l’expéditeur.

Messages organisés en fils de discussion

Vous pouvez créer des fils de discussion dans les conversations afin de mieux organiser les échanges. L’option permettant de créer un fil est disponible dans les actions supplémentaires lors de la rédaction d’un nouveau message.

Vous pouvez ensuite ajouter un titre et une description au fil de discussion, puis démarrer les échanges.

Vous pouvez consulter toutes les réponses d’un fil de discussion à l’aide du bouton des réponses associé au message ou depuis l’onglet « Éléments partagés » de la barre latérale.

Vous pouvez vous abonner à un fil de discussion afin de recevoir des notifications lors de nouvelles réponses. Vous pouvez le faire directement depuis le fil ou depuis la barre latérale.

Les fils de discussion auxquels vous êtes abonné sont facilement accessibles depuis la section « Fils de discussion » de la barre de navigation.

Vous pouvez modifier le titre du fil de discussion directement depuis celui-ci ou depuis la barre latérale.

Réponses privées

Les réponses privées sont des messages qui sont envoyés directement dans une conversation en tête à tête entre vous et l’auteur d’un message spécifique dans le but de maintenir la confidentialité quand elle est nécessaire.

  1. Dans des conversations publiques ou de groupe, sélectionnez un message auquel vous voulez répondre en privé

  2. Dans les actions du message, sélectionnez Répondre en privé

  3. Une fenêtre de conversation en tête à tête s’ouvre avec la citation du message d’origine

  4. Ajoutez votre réponse et envoyez un message

La réponse fournit le contexte complet d’un message cité — incluant le nom de l’expéditeur original, le contexte de la conversation d’origine et un lien retour.

Réactions aux messages

Réagissez aux messages avec des émojis pour rapidement exprimer votre accord, féliciter ou partager des émotions sans taper des réponses complètes.

  1. Survolez un message dans la discussion

  2. Cliquez sur le bouton Ajouter une réaction à partir des actions du message

  3. Sélectionnez un émoji dans la liste de ceux fréquemment utilisés ou dans le sélecteur complet

Vous pouvez survoler une réaction pour voir les autres utilisateurs qui ont réagi de cette manière. Cliquez sur une des réactions existantes pour réagir avec le même émoji ! Vous pouvez cliquer à nouveau dessus pour enlever votre réaction du message.
