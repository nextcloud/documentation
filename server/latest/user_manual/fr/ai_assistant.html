Assistant IA

L’Assistant IA de Nextcloud vous donne accès à des outils d’IA directement depuis l’interface web. Vous pouvez lancer des tâches telles que la création d’un résumé de texte, la génération d’images ou la transcription de la parole, avoir des dialogues interactifs avec un modèle de langage connecté ou encore insérer du contenu généré par IA dans des documents et des messages en utilisant des sélecteurs intelligents.

Note

L’Assistant IA nécessite au minimum une application de backend IA installée et configurée par votre administrateur. Voir la documentation d’administration de l’assistant IA pour plus de détails.

Paramètres personnels

Les paramètres personnels de l’assistant sont dans la section Intelligence artificielle des Paramètres personnels. Vous pouvez y désactiver l’entrée de l’assistant du menu supérieur, activer ou désactiver les sélecteurs intelligents relatifs à l’IA et changer le nom du dossier dans lequel l’assistant enregistre ce qu’il génère.

Où est enregistré le contenu généré

Le contenu que l’assistant génère pour vous, telles que les images générées et les sorties de synthèse vocale, est enregistré dans un dossier dans vos Fichiers. Il est appelé Assistant à moins que votre administrateur ait choisi un nom différent pour l’instance.

Vous pouvez lui attribuer un nom spécifique dans Dossier des données dans les paramètres personnels de l’assistant. Laissez le champ vide pour conserver le nom que votre administrateur a défini ; l’emplacement réservé affiche ce qui est configuré.

Note

Changer le nom ne renomme pas et ne déplace pas le dossier que vous avez déjà. Cela sera appliqué la prochaine fois qu’un dossier aura besoin d’être créé. Ainsi, tout ce qui a été généré avant la modification reste où c’était.

Exécution d’une tâche

Pour ouvrir l’assistant, cliquez sur son icône en haut à droite dans la barre de navigation.

Choisissez un type de tâche en haut du panneau de l’assistant, remplissez le formulaire de saisie puis cliquez sur le bouton d’envoi en bas à droite.

Votre tâche sera lancée immédiatement si possible, ou programmée pour être exécutée plus tard.

Notifications

Si une tâche a été programmée, vous pouvez demander à recevoir une notification lorsqu’elle finit. Cliquez sur le bouton Afficher les résultats dans la notification pour afficher ce que la tâche a produit.

Historique des tâches

Le panneau de gauche de l’assistant montre l’historique des tâches dans une liste filtrée sur le type de tâche actuellement sélectionné. Vous pouvez relancer, supprimer ou annuler les anciennes tâches depuis cette liste.

Discuter avec l’IA

L’onglet Discuter avec l’IA de l’assistant vous permet d’avoir une conversation faite d’échanges avec l’IA connectée. Tapez un message dans le champ de texte situé en bas et appuyez sur Entrée pour l’envoyer. Cliquez sur Nouvelle conversation pour lancer un fil de conversation séparé.

Chaque conversation a son propre contexte. Activer Se souvenir de cela sur une conversation l’ajoute à la mémoire à long terme de l’IA, ce qui rend son contexte disponible dans toute conversation future. Désactiver l’option supprime la conversation de la mémoire.

Dans la section Assistant IA de vos Paramètres personnels, vous pouvez consulter toutes vos conversations mémorisées.

Agent contextuel

Quand l’administrateur installe l’application Agent contextuel, l’Assistant IA obtient automatiquement la capacité d’interagir avec vos applications Nextcloud. Aucune configuration supplémentaire n’est nécessaire de votre part, les outils de l’agent devenant disponibles dans la même interface Discuter avec l’IA décrite plus haut.

Avec l’Agent contextuel activé, vous pouvez demander à l’assistant d’effectuer des actions au sein de Nextcloud en tapant des instructions en langage naturel dans la discussion. L’assistant utilise des « outils » en coulisses pour répondre à vos demandes.

Note

Les outils disponibles dépendent des applications installées sur votre instance et des groupes d’outils activés par votre administrateur. Certains des exemples ci-dessous nécessitent des applications spécifiques telles que Deck, Talk ou Mail.

Exemples de prompts

Vous trouverez ci-dessous des exemples de ce que vous pouvez demander à l’assistant de faire. Combinez plusieurs instructions dans un message unique et l’agent enchaînera automatiquement les outils nécessaires.

Outils d’intelligence artificielle

  • Poser une question dans le contexte de discussion (nécessite Contexte de discussion)

    • Exemple de prompt : « Quelle est la procédure de l’entreprise pour les arrêts maladie ? »

  • Transcrire un fichier multimédia (nécessite l’activation des tâches de type Transcription audio)

    • Exemple de prompt : « Peux-tu transcrire le fichier suivant ? https://moncloud.com/f/9825679 » (Peut être sélectionné via le sélecteur intelligent.)

  • Générer des documents (nécessite Nextcloud Office)

    • Exemple de prompt : « Peux-tu me générer un jeu de diapositives pour ma présentation sur les chats ? »

    • Exemple de prompt : « Peux-tu me générer une feuille de calcul avec des valeurs plausibles pour des pays et leurs populations ? »

    • Exemple de prompt : « Peux-tu me générer un PDF avec ce qu’il y a d’intéressant à voir à Berlin ? »

  • Générer des images (nécessite l’activation des tâches de type Génération d’images)

    • Exemple de prompt : « Peux-tu me générer une image de style dessin animé représentant un soldat romain en train de taper quelque chose sur un ordinateur portable ? »

Outils d’Agenda

  • Programmer un événement dans l’agenda d’un utilisateur

  • Trouver des créneaux libres dans l’agenda d’un utilisateur

Ces outils peuvent aussi être combinés par les agents pour remplir des tâches telles que :

  • « Quel temps fait-il où vit André ? »

  • « Quel temps fait-il où j’habite ? »

    • Recherche l’adresse de l’utilisateur actuel et consulte ensuite la météo

  • « Envoie un e-mail à André à partir de carry@societe.com »

    • Utilise les contacts pour rechercher l’adresse e-mail d’André et envoie ensuite un e-mail

  • « Lesquels de mes fichiers viennent d’Anne ? »

    • Recherche l’ID utilisateur d’Anne puis les fichiers qui lui appartiennent

  • « Envoie le contenu de mon fichier brouillon.md à André dans Talk »

    • Récupère le contenu du fichier et l’envoie dans une conversation Talk 1-1 avec André

Skills

Les Skills vous permettent d’apprendre à l’Agent contextuel des instructions réutilisables qu’il peut suivre chaque fois qu’elles sont pertinentes. Une Skill est un petit fichier Markdown qui décrit une procédure, un ensemble de règles ou des connaissances spécifiques à un domaine. Une fois une Skill enregistrée, l’agent va la chercher automatiquement et l’appliquer dans les futures conversations sans que vous ayez à les répéter vous-même.

Note

Les Skills nécessitent l’application Agent contextuel version 2.8.0 ou plus récente, et l’application Assistant version 3.5.0 ou plus récente.
Vous pouvez demander à votre administrateur si ces conditions sont remplies ou directement à l’agent s’il est en mesure d’utiliser les Skills.

Où sont stockées les Skills

Vos Skills personnelles résident dans vos Fichiers sur Nextcloud sous Context Agent/Skills/, à l’intérieur du dossier de données de l’assistant. Ainsi, avec le nom par défaut du dossier, il s’agit de Assistant/Context Agent/Skills/.

Chaque Skill est un sous-dossier contenant un fichier nommé SKILL.md. Ce fichier SKILL.md commence par un bloc de métadonnées d’entête YAML qui définit le nom et la description de la Skill, suivi par le contenu de la Skill en Markdown :

---
name: weekly-report-format
description: Formatting rules for my weekly status reports
---

When I ask you to write a weekly report, use the following structure:
1. Summary (2-3 sentences)
2. Completed tasks (bullet list)
3. Blockers
4. Plan for next week

Par exemple, une Skill nommée « formater-rapport-hebdomadaire » sera stockée dans Assistant/Context Agent/Skills/formater-rapport-hebdomadaire/SKILL.md.

La structure typique d’un dossier de Skills ressemble à ceci :

Assistant/
└── Context Agent/
    └── Skills/
        ├── email-tone/
        │   └── SKILL.md
        ├── weekly-report-format/
        │   └── SKILL.md
        └── meeting-notes/
            └── SKILL.md

Création d’une Skill

Vous pouvez créer une Skill de deux façons :

  • Manuellement : créez un sous-dossier sous Assistant/Context Agent/Skills/ dans votre application Fichiers, puis ajoutez un fichier SKILL.md avec les métadonnées d’entête et le contenu indiqués plus haut.

  • Via la discussion : demandez à l’agent de vous créer une Skill. Par exemple :

    • « Crée une Skill nommée “ton-email” pour vous rappeler de toujours rédiger des e-mails avec un ton professionnel et amical. »

    • « Enregistre une Skill pour créer le résumé des notes de la réunion avec des éléments d’action et les personnes désignées. »

    L’agent va automatiquement créer le dossier et le fichier SKILL.md à votre place.

Affichage et utilisation des Skills

Pour voir les Skills disponibles, demandez à l’agent :

  • « Liste mes Skills. »

Vous n’avez pas besoin d’invoquer une Skill de manière explicite. L’agent lit les descriptions de toutes les Skills disponibles et applique celles qui sont pertinentes en fonction du contexte de votre conversation.

Skills fournies par l’administrateur

Votre administrateur peut configurer un dossier de Skills global pour offrir des Skills à tous les utilisateurs de l’instance. Ces Skills globales apparaissent aux côtés de vos Skills personnelles.

Si une Skill globale a le même nom que l’une de vos Skills personnelles, votre version personnelle a la priorité sur celle globale.

Utilisation de Nextcloud comme serveur MCP

L’application Agent contextuel expose votre Nextcloud en tant que serveur Model Context Protocol (MCP). Cela signifie que vous pouvez connecter votre instance Nextcloud à des agents ou des outils d’IA externes tels que Pi Agent, Claude Code, Hermes, OpenCode ou tout autre client compatible MCP et les laisser utiliser les mêmes outils que ceux disponibles dans le chat de l’Assistant.

Le point de terminaison du serveur MCP est:

https://your-nextcloud-domain.com/index.php/apps/app_api/proxy/context_agent/mcp/

L’authentification est réalisée avec un mot de passe d’application. Vous pouvez en créer un dans « Paramètres personnels -> Sécurité -> Appareils & sessions ».

Connexion de clients MCP

Tout client compatible MCP qui prend en charge le transport streamable_http peut se connecter au serveur MCP Nextcloud. Faites pointer le client vers l’URL du point de terminaison affiché ci-dessus et passez le mot de passe d’application dans l’entête Authorization: Bearer <app-password>.

Une fois connecté, le client externe peut utiliser l’ensemble des mêmes outils de l’Agent contextuel, gérant les fichiers, agendas, tâches, contacts, conversations Talk et plus encore, directement d’en dehors de Nextcloud.
