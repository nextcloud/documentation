Etiquetas do sistema

As etiquetas do sistema são rótulos válidos para todo o servidor que você pode atribuir a arquivos e pastas para organizá-los, filtrar sua lista de arquivos e acionar fluxos de trabalho automatizados, como regras de retenção e controle de acesso.

As etiquetas aparecem diretamente nas linhas dos arquivos e pastas no aplicativo Arquivos, para que você possa ver rapidamente quais rótulos estão atribuídos:

As etiquetas são criadas pelos administradores nas configurações do servidor. Dependendo da configuração do seu servidor, os usuários comuns também podem criar etiquetas — o administrador pode restringir a criação de etiquetas apenas aos administradores.

Níveis de acesso às etiquetas

Cada etiqueta possui um dos três níveis de acesso que controlam o que os usuários comuns podem ver e fazer:

Nível

Visível para os usuários

Usuários podem atribuir / remover

Pública

Sim

Sim

Restrita

Sim

Não

Invisível

Não

Não

As etiquetas restritas e invisíveis são utilizadas pelos administradores para fluxos de trabalho automatizados. Não é possível contornar essa restrição removendo a etiqueta por conta própria.

Navegar pelos arquivos por etiqueta

Clique no ícone de navegação (≡) no canto superior esquerdo do aplicativo Arquivos para abrir o painel de navegação e, em seguida, clique em Etiquetas. A visualização exibe todas as etiquetas visíveis para você. Clique no nome de uma etiquetas para ver todos os arquivos e pastas aos quais essa etiquetas foi atribuída.

Atribuir etiquetas aos arquivos

Você pode atribuir ou remover etiquetas de um arquivo por vez ou de uma seleção de arquivos de uma só vez.

Único arquivo

  1. Clique no menu de ações com três pontos (…) ao lado de um arquivo ou pasta e selecione Detalhes para abrir a barra lateral de detalhes.

  2. Na barra lateral de detalhes, clique em Adicionar etiquetas.

  3. Digite o nome de uma etiqueta no campo de pesquisa e selecione a etiqueta na lista.

  4. Clique fora do seletor para fechá-lo. As alterações são salvas imediatamente.

Para remover uma etiqueta, abra o mesmo seletor e clique no × ao lado do nome da etiqueta.

Nota

Apenas as etiquetas públicas aparecem no seletor para usuários comuns. As etiquetas restritas e invisíveis só podem ser atribuídas por administradores.

Vários arquivos

  1. Selecione dois ou mais arquivos clicando na caixa de seleção à esquerda de cada linha.

  2. Clique em ··· Ações na barra de ferramentas acima da lista de arquivos e, em seguida, selecione Gerenciar etiquetas.

  3. Marque ou desmarque as etiquetas na caixa de diálogo exibida. Uma linha de informação mostra como a alteração será aplicada aos arquivos selecionados.

  4. Clique em Aplicar.

Criar e gerenciar etiquetas

Se o seu administrador não tiver restringido a criação de etiquetas, você poderá criar uma nova etiqueta diretamente na caixa de diálogo Gerenciar etiquetas ou no seletor de etiquetas de arquivo único: digite um novo nome no campo Pesquisar ou criar etiqueta e selecione a opção Criar etiqueta que aparecerá.

Os administradores criam, renomeiam e excluem etiquetas em Configurações de administração ‣ Servidor. Para obter detalhes sobre o gerenciamento de etiquetas e as ferramentas de linha de comando, consulte a seção Automated tagging do manual de administração.
