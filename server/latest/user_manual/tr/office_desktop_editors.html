Nextcloud Office Desktop

Nextcloud Office Desktop, belgeleri, elektronik tabloları ve sunumları bilgisayarınızda çevrim dışı düzenlemenizi sağlar. Aşağıdaki indirme bağlantıları her zaman son kararlı sürüme gider. Eski sürümler https://download.nextcloud.com/office/desktopeditors/ adresinden edinilebilir.

Linux

Güncellemelerin düzenli sistem güncellemeleriyle gelmesi için Nextcloud Office paket deposundan yükleyin.

Debian ve Ubuntu

sudo apt-get install -y ca-certificates curl
sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL https://download.nextcloud.com/office/repo/nextcloud-office.asc \
  -o /etc/apt/keyrings/nextcloud-office.asc
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/nextcloud-office.asc] \
https://download.nextcloud.com/office/repo/deb stable main" \
  | sudo tee /etc/apt/sources.list.d/nextcloud-office.list
sudo apt-get update

sudo apt-get install nextcloud-office-nextcloudoffice

Kurulum ayrıca, Microsoft Office ile oluşturulan belgelerin görüntülenme şeklini iyileştiren Microsoft çekirdek yazı tiplerini de sunar. Bunları kurmak için, sorulduğunda lisanslarını kabul edin.

Fedora ve RHEL

sudo tee /etc/yum.repos.d/nextcloud-office.repo <<'EOF'
[nextcloud-office]
name=Nextcloud Office
baseurl=https://download.nextcloud.com/office/repo/rpm/stable/$basearch
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://download.nextcloud.com/office/repo/nextcloud-office.asc
EOF
sudo dnf install nextcloud-office-nextcloudoffice

İlk kurulum sırasında, dnf sizden depo imzalama anahtarını kabul etmenizi ister. Kabul etmeden önce parmak izinin C013 F0BE F968 00BB BC4D 93DD E6E7 0E5F A287 C3D0 olduğundan emin olun.
