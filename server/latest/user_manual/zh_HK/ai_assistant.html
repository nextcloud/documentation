AI 助理

Nextcloud AI 助理讓你直接透過網頁介面使用人工智能工具。你可以執行文字摘要、圖像生成及語音轉錄等工作，與已連接的語言模型進行多輪對話，並透過智能選擇器將 AI 生成的內容插入文件及訊息。

Note

AI 助理需要管理員安裝並設定至少一個 AI 後端應用程式。詳情請參閱 AI 助理管理文件。

個人設定

助理的個人設定位於 個人設定 的 人工智能 部分。你可以在此停用頂部選單中的助理入口、啟用或停用 AI 相關的智能選擇器，以及更改助理儲存輸出內容的資料夾名稱。

生成內容的儲存位置

助理為你生成的內容，例如圖像及語音轉文字結果，會儲存在「檔案」中的一個資料夾。除非管理員為此執行個體指定了其他名稱，否則該資料夾會命名為 Assistant。

你可以在助理個人設定的 資料資料夾 中自行指定名稱。留空即可沿用管理員設定的名稱；輸入欄位的提示文字會顯示該名稱。

Note

更改名稱不會重新命名或移動現有資料夾。新名稱只會在下次需要建立資料夾時生效，因此更改前生成的內容仍會保留在原來位置。

執行工作

如要開啟助理，請按一下右上角導覽列中的助理圖示。

在助理面板頂部選擇工作類型，填寫輸入表單，然後按一下右下角的提交按鈕。

如情況允許，工作會立即執行，否則會安排稍後執行。

通知

如果工作已安排稍後執行，你可以選擇在完成時接收通知。按一下通知中的 檢視結果 按鈕，即可查看工作輸出。

工作記錄

助理左側面板會顯示按目前所選工作類型篩選的工作記錄。你可以從清單中重新執行、刪除或取消先前的工作。

與 AI 對話

助理中的 與 AI 對話 分頁讓你與已連接的 AI 進行多輪對話。在底部文字欄位輸入訊息，然後按 Enter 傳送。按一下 新增對話 可開始另一段對話。

每段對話都有獨立的上下文。開啟對話中的 記住此對話，即可將其加入 AI 的長期記憶，讓往後的對話也能使用相關上下文。再次關閉即可從記憶中移除該對話。

你可以在個人設定的 AI 助理 部分檢視所有已記住的對話。

Context Agent

管理員安裝 Context Agent 應用程式後，AI 助理便會自動獲得與 Nextcloud 應用程式互動的能力。你無須進行其他設定；代理工具會出現在上述的 與 AI 對話 介面中。

啟用 Context Agent 後，你可以在聊天中輸入自然語言指示，要求助理跨 Nextcloud 應用程式執行操作。助理會在背景使用「工具」完成你的要求。

Note

可用工具取決於 Nextcloud 執行個體安裝了哪些應用程式，以及管理員啟用了哪些工具群組。以下部分例子需要 Deck、Talk 或 Mail 等特定應用程式。

提示詞範例

以下是你可以要求助理執行的操作範例。你可以在同一則訊息中結合多項指示，代理便會自動串連所需工具。

人工智能工具

  • 向情境聊天提問（需要 Context Chat）

    • 提示詞範例：「公司的病假申請程序是甚麼？」

  • 轉錄媒體檔案（需要啟用音訊轉錄工作類型）

    • 提示詞範例：*「可以轉錄這個檔案嗎？https://mycloud.com/f/9825679」*（可透過智能選擇器選取。）

  • 生成文件（需要 Nextcloud Office）

    • 提示詞範例：「可以幫我製作一份關於貓的簡報嗎？」

    • 提示詞範例：「可以幫我製作一份試算表，填入各國及其人口的合理估算數字嗎？」

    • 提示詞範例：「可以生成一份 PDF，概述柏林值得參觀的景點嗎？」

  • 生成圖像（需要啟用圖像生成工作類型）

    • 提示詞範例：「可以生成一張卡通圖，畫一名羅馬士兵正在手提電腦上打字嗎？」

  • 尋找用戶日曆中的空閒時段

    • 提示詞範例：「找出下星期我和 Marco 都有空的一小時會議時段。」

    • 提示詞範例：「顯示快速意粉食譜的搜尋結果。」

  • 查詢公共交通路線

    • 提示詞範例：「如何從維爾茨堡中央車站前往柏林中央車站？」

  • 列出 OpenProject 中的所有專案（需要 OpenProject 整合）

    • 提示詞範例：「請列出我在 OpenProject 中的所有專案。」

  • 列出 OpenProject 專案中所有可獲指派工作的用戶（需要 OpenProject 整合）

    • 提示詞範例：「列出 OpenProject 中『產品發佈』專案所有可獲指派工作的人員。」

  • 在 OpenProject 的指定專案中建立新工作套件（需要 OpenProject 整合）

    • 提示詞範例：「在 OpenProject 的『產品發佈』專案中建立名為『發佈產品影片』的工作套件。」

組合使用工具

代理亦可以組合使用這些工具，完成以下工作：

  • 「Andrew 居住的地方天氣如何？」

    • 使用聯絡人資料查找 Andrew 的地址，然後查詢天氣

  • 「我住的地方天氣如何？」

    • 查找目前用戶的地址，然後查詢天氣

  • 「從 carry@company.com 傳送電郵給 Andrew」

    • 使用聯絡人資料查找 Andrew 的電郵地址，然後傳送電郵

  • 「我的哪些檔案來自 Anna？」

    • 查找 Anna 的用戶 ID，然後搜尋屬於她的檔案

  • 「在 Talk 中將 draft.md 檔案的內容傳送給 Andrew」

    • 取得檔案內容，然後在與 Andrew 的一對一 Talk 對話中傳送

技能

技能讓你向 Context Agent 提供可重複使用的指示，供代理在相關情況下遵循。技能是一個小型 Markdown 檔案，用來描述程序、規則或特定領域的知識。

Note

技能需要 Context Agent 應用程式 2.8.0 或更新版本，以及 Assistant 應用程式 3.5.0 或更新版本。
你可以向管理員查詢是否符合這些要求，或直接詢問代理能否使用技能。

技能的儲存位置

你的個人技能儲存在 Nextcloud 檔案中助理資料夾內的 Context Agent/Skills/。如果使用默認資料夾名稱，路徑便是 Assistant/Context Agent/Skills/。

每項技能都是一個子資料夾，內含名為 SKILL.md 的檔案。SKILL.md 檔案以 YAML frontmatter 區塊開頭，用來定義技能的名稱和描述，其後是以 Markdown 編寫的技能內容。

---
name: weekly-report-format
description: Formatting rules for my weekly status reports
---

When I ask you to write a weekly report, use the following structure:
1. Summary (2-3 sentences)
2. Completed tasks (bullet list)
3. Blockers
4. Plan for next week

例如，名為「weekly-report-format」的技能會儲存在 Assistant/Context Agent/Skills/weekly-report-format/SKILL.md。

典型的技能資料夾結構如下：

Assistant/
└── Context Agent/
    └── Skills/
        ├── email-tone/
        │   └── SKILL.md
        ├── weekly-report-format/
        │   └── SKILL.md
        └── meeting-notes/
            └── SKILL.md

建立技能

你可以透過兩種方式建立技能：

  • 手動建立：在「檔案」中的 Assistant/Context Agent/Skills/ 下建立子資料夾，然後新增包含上述 frontmatter 及內容的 SKILL.md 檔案。

  • 透過聊天建立：要求代理為你建立技能。例如：

    • 「建立一項名為『email-tone』的技能，提醒你撰寫電郵時保持友善及專業的語氣。」

    • 「儲存一項技能，用來總結會議記錄並列出行動項目及負責人。」

    代理會自動為你建立資料夾及 SKILL.md 檔案。

列出及使用技能

如要查看可用技能，可以詢問代理：

  • 「列出我的技能。」

你無須明確指定使用某項技能。代理會讀取所有可用技能的描述，並根據對話內容套用相關技能。

管理員提供的技能

管理員可以設定全域技能資料夾，為執行個體上的所有用戶提供技能。這些全域技能會與你的個人技能一同顯示。

如果全域技能與你的個人技能名稱相同，系統會優先使用你的個人版本。

將 Nextcloud 用作 MCP 伺服器

Context Agent 應用程式會將你的 Nextcloud 公開為 `模型上下文協定（MCP）<https://modelcontextprotocol.io>`_ 伺服器。這表示你可以將 Nextcloud 執行個體連接至外部 AI 工具及代理，例如支援 MCP 的用戶端。

MCP 伺服器端點如下：：

https://your-nextcloud-domain.com/index.php/apps/app_api/proxy/context_agent/mcp/

使用應用程式密碼進行身分驗證。你可以在「個人設定 → 安全性 → 裝置與工作階段」中建立應用程式密碼。

連接 MCP 用戶端

任何支援 streamable_http 傳輸方式的 MCP 相容用戶端，都可以連接 Nextcloud MCP 伺服器。將用戶端指向上述端點網址，並在 Authorization 標頭中提供應用程式密碼。

連接後，外部用戶端便可使用與 Context Agent 相同的工具，直接從 Nextcloud 外部管理檔案、日曆、工作、聯絡人及 Talk 對話等。
