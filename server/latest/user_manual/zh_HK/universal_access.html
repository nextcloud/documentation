普遍存取

我們十分重視通用無障礙存取。我們遵循網頁標準，確保所有功能均可透過鍵盤及屏幕閱讀器等輔助軟件操作。我們力求符合 《網頁內容無障礙指引》2.1 的 AA 級要求，而高對比度主題更以 AAA 級為目標。我們亦遵循德國的 BITV 2.0 指引。

如果您發現任何問題，請隨時在 我們的問題追蹤器 上報告。如果您想參與，歡迎 加入我們的設計團隊！

縮放與反應性

Nextcloud 介面完全響應，適用於任何大小的螢幕。您可以進行縮放，以符合您的文本和元素大小。導航和側邊欄可以展開或折疊。

透過鍵盤導航

你可以像使用滑鼠一樣，以鍵盤操作網頁介面。

  • 按 Tab 或 Shift+Tab，在介面元素之間移動。

  • 按 Enter 或 Space 啟用或開啟元素，視乎元素類型而定。

  • 按 Escape 關閉強制回應視窗、彈出式選單及檔案檢視器。

  • 按 Left arrow 或 Right arrow，在檢視器中切換相片。

  • 按 Ctrl+F，將焦點移至搜尋欄。

  • 在 Nextcloud Text 等編輯器中，按 Ctrl+S 儲存變更。

為方便快速瀏覽，我們在文件開首提供兩條「跳過」連結，讓你執行以下操作。

  • 跳到主要內容

  • 跳到應用的導航

Nextcloud Talk 有快捷鍵，這些快捷鍵也在應用的設置中有記錄：

  • 按 C，將焦點移至訊息輸入欄。

  • 按 Escape，將焦點移離訊息輸入欄，以便使用快捷鍵。

  • 按 F，以全屏顯示聊天或通話。

  • 通話中：

    • 按 M，開啟或關閉咪高峰。

    • 按 V，開啟或關閉視像。

    • 按住 Space 說話或暫時靜音。

    • 按 R 舉手或放下手。

Nextcloud Mail 也有快捷鍵，這些快捷鍵在應用的設置中有記錄：

  • 按 C 撰寫新郵件。

  • 按 Left arrow 切換至較新的郵件。

  • 按 Right arrow 切換至較舊的郵件。

  • 按 S，將郵件標記為最愛或取消標記。

  • 按 U，切換郵件的已讀或未讀狀態。

  • 按 Del 刪除郵件。

  • 按 Ctrl+Enter 傳送郵件。

  • 按 R 重新整理並載入新郵件。

包含的主題

我們提供幾個可以啟動的主題，以幫助提升可及性：

  • 高對比度主題： 一種高對比度模式，方便您的導航。視覺質量將降低，但清晰度將提高。

  • 黑暗主題： 一種黑暗主題，通過降低整體亮度來保護您的眼睛。此主題仍在開發中，請報告任何您可能發現的問題。

  • 閱讀障礙字體： OpenDyslexic 是一種免費字體，旨在減少由閱讀障礙引起的一些常見閱讀錯誤。

要進入無障礙設置：

  1. 打開標題末尾的設置選項單

  2. 選擇 設置

  3. 在導航中選擇 無障礙性

Note

元素的對比度可能會根據自定義主題而有所不同。例如，主題顏色用作標題、登錄頁面和主要按鈕的背景顏色。如果這造成對比問題，請聯繫您的管理員以獲取幫助。
