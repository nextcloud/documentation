使用外部儲存空間

「外部儲存空間」應用程式讓你的 Nextcloud 伺服器連接遠端檔案系統，例如 Amazon S3、SFTP 伺服器、SMB/CIFS 共用資料夾或 WebDAV 伺服器，並在「檔案」檢視中以資料夾形式顯示。管理團隊會設定可用的後端，以及與你共用的掛載點。

如果管理員已啟用由使用者管理的外部儲存空間，你亦可在「個人設定」中新增自己的連線。

存取外部儲存空間

外部儲存空間掛載點會在「檔案」檢視中顯示為一般資料夾。你可以像操作其他資料夾一樣瀏覽、上載、下載及刪除其中的檔案。能否分享檔案，取決於管理員有否為個別掛載點啟用分享功能。

資料夾名稱旁的彩色指示燈會顯示連線狀態：

  • 綠色 — 儲存空間已連線，可以使用。

  • 黃色 — 無法連接儲存空間；Nextcloud 會自動重試。

  • 紅色 — 儲存空間無法使用。如問題持續，請聯絡管理員。

掛載點無法使用時，Nextcloud 會將其標記為離線，並在十分鐘後重試。你可以按一下狀態指示燈，手動重新檢查。

Note

部分外部儲存空間掛載點可能設為唯讀。你無法在唯讀掛載點上載或刪除檔案。

分享外部儲存空間中的檔案

分享外部儲存空間中的檔案，方法與分享其他檔案或資料夾相同：在「檔案」檢視中使用分享圖示。管理員必須為每個掛載點明確啟用分享功能，因此部分掛載點可能不會顯示分享圖示。

Note

指向其他 Nextcloud 執行個體的外部掛載點不支援伺服器端加密。

新增自己的外部儲存空間

如果管理員已啟用由使用者管理的外部儲存空間，你可以在 個人設定 → 外部儲存空間 中連接自己的儲存服務。

新增掛載點：

  1. 按一下個人資料圖示，然後選擇 個人設定。

  2. 在左側邊欄選擇 外部儲存空間。

  3. 從 新增儲存空間 下拉式選單中選擇後端。

  4. 填寫該後端所需的欄位（伺服器位址、路徑、登入憑證等）。

  5. 從 驗證 下拉式選單中選擇驗證方式。

必填欄位會以紅色邊框標示。填妥所有必填欄位後，掛載點便會自動儲存。

掛載點旁的綠點表示連線成功。紅色或黃色圖示表示 Nextcloud 無法連線，請檢查登入憑證及網絡設定。

如要移除掛載點，請開啟旁邊的三點選單，然後選擇 刪除。

Note

你在「個人設定」中新增的掛載點只有你的帳戶可以看到。

支援的後端

視乎管理員啟用的設定，以下後端可能可供使用：

  • Amazon S3 — Amazon Simple Storage Service 儲存貯體及與 S3 相容的儲存空間。

  • FTP — FTP 及 FTPS 伺服器。

  • Nextcloud / ownCloud — 透過 WebDAV 連接另一個 Nextcloud 或 ownCloud 執行個體。

  • OpenStack Object Storage — OpenStack Swift 儲存貯體。

  • SFTP — SSH 檔案傳輸協定伺服器。

  • SMB / CIFS — Windows 共用檔案及 Samba 伺服器。

  • WebDAV — 任何與 WebDAV 相容的伺服器。

有關個別後端的設定詳情，請參閱管理員手冊中的 設定外部儲存空間（圖形介面）。

偵測檔案變更

透過 Nextcloud 新增或修改的檔案會即時反映。直接在外部儲存空間新增或修改的檔案（未經 Nextcloud 操作），則可能要等到下一次背景掃描才會顯示。

如果外部新增的檔案未有顯示，請管理員執行 occ files:scan，或為該掛載點設定定期背景掃描。
