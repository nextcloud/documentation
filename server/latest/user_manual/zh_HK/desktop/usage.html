使用桌面客戶端

Nextcloud 桌面客戶端會在背景執行。在 Windows 和 Linux 上，可從系統匣開啟設定；在 macOS 上，則可從選單列開啟。

新增帳戶

要連接另一個 Nextcloud 帳戶，請開啟設定對話框，然後在側邊欄按一下 新增帳戶。輸入你在瀏覽器中存取 Nextcloud 伺服器時使用的網址，然後按一下 登入。

如果你的網絡需要使用代理伺服器，請在登入前按一下 代理伺服器設定。選擇使用系統代理伺服器，或手動輸入代理伺服器設定，然後按一下 完成。

如果安全連線失敗，請檢查伺服器網址並聯絡伺服器管理員。精靈可能會提供不使用 TLS 連線或使用客戶端憑證的選項。只有伺服器要求使用客戶端憑證時，才應選擇 使用客戶端憑證。

如果系統要求提供客戶端憑證，請選擇管理員提供的 PKCS#12 檔案、輸入密碼，然後按一下 連接。

精靈會要求你切換至瀏覽器。如果瀏覽器沒有自動開啟，請按一下 開啟。登入後，依提示授權桌面客戶端存取帳戶，再返回精靈。

選擇檔案同步方式。使用傳統同步時，請選擇 同步所有內容 或 選擇要同步的內容。如要更改檔案儲存位置，請按一下 本機同步資料夾 旁的 選擇，然後按一下 完成。

你亦可選擇 檔案供應者，按需要下載檔案。按一下 完成 以完成新增帳戶。在 macOS 上，有關 Finder 整合的詳情，請參閱 Using the macOS File Provider。

完成傳統同步設定前，如希望在同步大型資料夾或外部儲存空間前先確認，請按一下 進階。在 進階選項 中設定偏好，然後按一下 完成 返回精靈。

設定對話框

在側邊欄選擇帳戶，即可查看其同步狀態、本機資料夾、儲存空間使用量及連線設定。按一下 新增資料夾同步連線，可為該帳戶設定另一個傳統同步資料夾。你亦可在同一頁登出或移除帳戶。

在 一般 下，你可選擇是否在啟動電腦時執行客戶端、使用單色圖示，以及顯示通知。在 macOS 上，你亦可為所有帳戶啟用檔案供應者。此設定會取代傳統同步資料夾及其 Finder 整合功能。

在 進階 下，你可設定同步大型資料夾及外部儲存空間前的確認門檻，亦可調整伺服器輪詢間隔、決定是否將已移除的檔案移至垃圾桶、編輯忽略檔案規則，或建立偵錯封存檔。

如要排除不需同步的檔案或資料夾，請在 進階 下按一下 編輯忽略檔案，並為每個要忽略的項目新增一個模式。星號（*）可配對任意數量的字元，問號（?）可配對一個字元，而結尾的斜線（/）則表示模式只適用於資料夾。只有當客戶端可能需要刪除某些被忽略項目，以免其妨礙刪除資料夾時，才應為這些項目勾選 允許刪除。按一下 確定 儲存。

在 資訊 下，你可查看桌面客戶端版本，並開啟使用說明文件或法律聲明。

系統匣圖示

桌面客戶端會在 Windows 和 Linux 的系統匣或 macOS 的選單列顯示狀態圖示。相同的同步狀態可使用彩色狀態圖示，以及彩色或單色系統匣圖示。你可在設定對話框的 一般 下選擇單色圖示。

檔案管理員覆蓋圖示

對於傳統同步資料夾，桌面客戶端會在檔案管理員中的檔案上顯示覆蓋圖示。綠色剔號表示檔案已同步至最新狀態。警告圖示可能表示檔案已被忽略；紅色叉號表示同步錯誤。藍色圖示表示檔案正等待同步或正在同步。當客戶端離線時，不會顯示資料夾目前同步狀態的覆蓋圖示。

資料夾的覆蓋圖示會反映其內容中的同步錯誤。被忽略的檔案不會改變上層資料夾的狀態。在 macOS 上，檔案供應者使用標準 Finder 狀態指示圖示，詳見 Using the macOS File Provider。

分享

桌面客戶端將分享操作整合至 macOS 的 Finder 及 Windows 的檔案總管。在 Linux 上，請安裝適用於所用檔案管理員的整合套件，例如 nautilus-nextcloud 或 dolphin-nextcloud。

在檔案管理員中，於檔案上按右鍵並選擇 Nextcloud > 分享選項，以開啟分享對話框。

使用 搜尋收件者，將檔案分享給個人或群組。現有分享及分享連結會顯示在搜尋欄下方。按一下複製按鈕可複製內部連結或分享連結。使用三點選單編輯分享，或按 X 按鈕移除分享。

編輯分享時，請從下拉式選單選擇收件者的權限。你亦可新增給收件者的備註。變更會即時生效。

按一下齒輪按鈕開啟 分享設定，即可設定到期日或以密碼保護分享。變更會即時生效。
