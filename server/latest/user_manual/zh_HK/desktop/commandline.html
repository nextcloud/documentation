命令列用戶端

nextcloudcmd 會將本機目錄與 Nextcloud 伺服器同步，然後結束。它可在有需要時執行後續同步，但不會像桌面應用程式一樣持續監察本機檔案或輪詢伺服器變更。如需了解傳遞至桌面應用程式 nextcloud 指令的選項，請參閱 命令列選項。

安裝

安裝提供 nextcloudcmd 的套件。是否提供取決於你的作業系統及套件：

作業系統

套件來源

Alpine Linux

nextcloud-client

Debian

nextcloud-desktop-cmd

Fedora

nextcloud-client

Ubuntu

nextcloud-desktop-cmd

Ubuntu PPA

Windows

Nextcloud 下載頁面

使用方法

使用現有的本機目錄及 Nextcloud 伺服器的基礎 URL：

nextcloudcmd [options] local_directory server_url

例如，將遠端 Music 資料夾同步至現有的本機資料夾：

nextcloudcmd --user carla --path /Music "$HOME/media/music" https://cloud.example.com

用戶端會提示你輸入密碼。你可以使用 Nextcloud 帳戶安全設定中的應用程式密碼。請勿在伺服器 URL 後附加 WebDAV 端點；如要指定遠端子資料夾，請使用 --path。

執行不帶參數的 nextcloudcmd 可顯示說明，或執行 nextcloudcmd --version 顯示版本。接受值的選項同時支援 --option value 和 --option=value 格式。

選項

參數

默認值

說明

--path <path>

伺服器根目錄

同步遠端子資料夾，例如 /Documents。

--user <user>、-u <user>

請參閱下方的憑證說明

登入名稱。覆蓋伺服器 URL 中的用戶名稱。

--password <password>、-p <password>

請參閱下方的憑證說明

密碼或應用程式密碼。覆蓋伺服器 URL 中的密碼。命令列中的密碼可能會顯示於程序清單及 Shell 歷史記錄。

-n

未設定

從符合主機的項目或 .netrc 中的默認項目讀取登入憑證。這些憑證會取代 URL 或 --user 及 --password 所提供的憑證。

--non-interactive

未設定

不提示輸入登入憑證。從 NC_USER 及 NC_PASSWORD 讀取缺少的憑證。

--silent、-s

未設定

隱藏 Qt 日誌訊息，但不會隱藏所有主控台訊息。

--trust

未設定

接受不受信任的 TLS 憑證。只應在受控的診斷作業中使用；一般情況下應修正憑證信任設定。

--httpproxy <url>

不明確指定代理伺服器

使用 http://hostname:port 設定 HTTP 代理伺服器。此選項不會解析 URL 中的代理伺服器登入憑證。

--exclude <file>

系統排除清單

新增排除清單。檔案必須存在。模式的錨定方式取決於檔案名稱；請參閱 排除清單。

--exclude-anchored <file>

未設定

新增排除清單，並將模式固定以同步根目錄為基準，不受檔案名稱影響。

--unsyncedfolders <file>

未設定

讀取要排除同步的遠端資料夾，每行一個相對路徑。空白行及以 # 開頭的行會被忽略。

--max-sync-retries <number>

3

當同步引擎要求再次同步時，最多執行多少次後續同步。這並非所有失敗請求的一般重試次數。

--uplimit <number>

0 KB/s

上載速度限制，以 KB/s 計算（每秒 1000 位元組）。零代表不設限制。

--downlimit <number>

0 KB/s

下載速度限制，以 KB/s 計算（每秒 1000 位元組）。零代表不設限制。

-h

包含隱藏檔案

包含隱藏檔案。這本來就是默認行為；-h 不會顯示說明。

--logdebug

未設定

啟用 Nextcloud 偵錯日誌，並將日誌輸出至標準輸出。

--confdir <directory>

標準位置

使用其他設定目錄。這不代表單次同步會繼承桌面同步的所有設定。

--version、-v

未要求

顯示版本資訊並結束。執行此選項時不要提供目錄及伺服器參數。

登入憑證處理

登入憑證會按以下順序讀取：

  1. 伺服器 URL 中的用戶名稱及密碼（如有提供）。

  2. --user 及 --password，取代 URL 中相應的值。

  3. 使用 -n 時，符合主機的項目或 .netrc 中的默認項目會取代上述兩個值。

  4. 提示輸入任何缺少的值；使用 --non-interactive 時，則讀取下列環境變數。

建議使用密碼輸入提示或受保護的 .netrc 檔案，而非將密碼直接放在指令或 URL 中。

參數

默認值

說明

NC_USER

未設定

配合 --non-interactive 進行單次同步時的備用用戶名稱。只有在上述方法均未提供用戶名稱時才會使用。

NC_PASSWORD

未設定

配合 --non-interactive 進行單次同步時的備用密碼。只有在上述方法均未提供密碼時才會使用。

這些變數不會為下述帳戶設定模式提供登入憑證。如需了解與桌面同步引擎共用的傳輸覆蓋設定，請參閱 環境變數。除非這些變數另有指定，否則 nextcloudcmd 使用的初始區塊大小為 100 MiB、最小為 5 MB、最大為 5 GB，並同時執行 6 個工作。它不會從 nextcloud.cfg 讀取桌面應用程式的區塊大小設定。

排除清單

用戶端會在系統排除清單可用時載入該清單。你可以使用 --exclude 或 --exclude-anchored 加入自己的清單。若明確指定的檔案不存在，便會發生錯誤。

使用 --exclude 時，名為 sync-exclude.lst 的檔案會以同步根目錄作為模式比對基準。其他檔案名稱則可能以排除清單檔案所在目錄作為基準。如果不希望檔案名稱及位置影響比對，請使用 --exclude-anchored。

每行輸入一個模式。支援萬用字元，例如：

*.tmp
._*
Thumbs.db

帳戶設定

nextcloudcmd 亦可儲存帳戶，供桌面應用程式使用。加入 --userid 即會選擇此模式；請勿提供單次同步所用的本機目錄及伺服器 URL 位置參數。設定完成後，指令便會結束。

參數

默認值

說明

--userid <user>

必填

要建立的帳戶之用戶 ID。

--serverurl <url>

必填

Nextcloud 伺服器的基礎 URL，例如 https://cloud.example.com。

--apppassword <password>

未設定

帳戶的應用程式密碼。如未提供，帳戶仍會儲存，但你需要稍後從桌面應用程式登入。

--localdirpath <path>

建議的資料夾

本機同步資料夾。如未提供，會使用設定精靈建議的資料夾。現有資料夾必須為空。啟用 macOS File Provider 模式時會忽略此選項。

--remotedirpath <path>

/

新傳統同步連線的遠端資料夾。建立本機同步資料夾時適用。

--isvfsenabled <0|1>

0

在支援的情況下，使用 1 為新的傳統同步資料夾啟用虛擬檔案，或使用 0 下載檔案。這不會啟用 macOS File Provider 模式。

例如，儲存帳戶，然後從桌面應用程式登入：

nextcloudcmd --userid carla --serverurl https://cloud.example.com --localdirpath "$HOME/Nextcloud"
