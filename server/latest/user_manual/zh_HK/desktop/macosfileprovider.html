使用 macOS 檔案供應器

在 macOS 上，Nextcloud 客戶端也可以透過檔案供應器延伸功能，將 Nextcloud 檔案直接整合到系統中。新設定的 Nextcloud 帳戶均會默認啟用這項整合功能。

支援的功能

  • 保留檔案或整個資料夾供離線使用

  • 移除本機副本以釋放本機磁碟空間，同時保留原有項目

  • 智能自動移除本機資料副本

  • 在 Finder 預覽尚未下載的檔案

  • 支援 Apple 專用格式，例如 Pages、Numbers 或 Keynote 的套件檔案

  • 支援伺服器端檔案鎖定（須由所連接的伺服器支援）

  • 支援「在本機編輯」

  • 與其他用戶共用

  • 直接在 Finder 的快捷選單執行伺服器端操作

  • 自動偵測伺服器端的變更

設定

你可以在 Nextcloud 桌面客戶端的設定視窗中，分別為各個帳戶調整檔案供應器延伸功能的設定。

你可以在這裏啟用或停用 Finder 整合功能。

如果停用檔案供應器延伸功能時仍有尚未同步的變更，macOS 會將尚未同步的項目儲存到一個資料夾，並在整合功能停用後自動顯示該資料夾。

Finder 整合

在 macOS 上，Nextcloud 檔案帳戶等遠端儲存空間會在 Finder 側邊欄中顯示為獨立的位置。內容在磁碟上的實際位置由 macOS 決定。

Note

要加快偵測伺服器端的變更，建議在 Nextcloud 伺服器上啟用 notify_push 應用程式。伺服器一有變更，這個應用程式便會通知桌面客戶端，縮短變更在 Finder 顯示所需的時間。否則，客戶端須定期查詢伺服器，變更便要等更久才會在本機顯示。

同步狀態圖示

與傳統同步資料夾一樣，Finder 會在項目旁顯示狀態圖示。傳統同步資料夾使用自訂圖示，而這裏的標準圖示由 macOS 提供，讓用戶在同一部 Mac 上使用不同的雲端儲存應用程式時，都能看到一致的圖示。

  • 帶向下箭嘴的雲朵 表示項目及其下所有項目尚未下載。有網絡連線時即可下載。

  • 只有輪廓的雲朵 表示項目的本機版本尚未完全上載。

  • 帶刪除線的雲朵 表示該項目已排除在同步範圍之外。

  • 圓形進度圖 表示項目正在上載或下載，圖示會顯示傳輸進度。

  • 內有圖釘的實心圓形 表示項目可離線使用，並會保留在本機。

  • 沒有圖示 表示項目可離線使用，並已更新至最新版本。

快捷選單操作

檔案供應器延伸功能也會在 Finder 的快捷選單中提供 Nextcloud 專有功能。

保留已下載項目

你可以將檔案和資料夾標記為保留已下載項目，讓它們長期可供離線使用。對資料夾使用此選項時，設定也會套用至資料夾內的所有項目。對於網絡連線受限或無法連線的用戶，這可確保他們隨時存取重要檔案。即使這些項目長時間未被存取，macOS 也 不會 為了釋放本機磁碟空間而移除其本機副本。

要取消這項設定，請在同一批項目上選擇「允許自動釋放空間」。

若要讓帳戶內的所有項目一律可在本機使用，可在 Finder 側邊欄對該帳戶的根位置選擇「一律保留已下載項目」。

鎖定

如果伺服器支援檔案鎖定，客戶端便會在 Finder 提供手動鎖定和解鎖檔案的選項。

共用

如果伺服器支援共用，而且該項目可供共用，你便可像在 Nextcloud 網頁介面一樣，直接在 Finder 的快捷選單中為項目新增共用設定，或管理現有設定。

檔案操作

如果伺服器已安裝為所選檔案類型提供操作的應用程式，這些操作也會出現在 Finder 的快捷選單中。這樣，你便可以直接從 Finder 使用你的 Nextcloud 伺服器所提供的功能。

已知問題

macOS 延伸功能衝突

受 Apple 對 macOS 的技術限制所限，啟用檔案供應器延伸功能時，傳統同步資料夾的 Finder 整合功能無法同時運作。在此期間，傳統同步資料夾中的項目將無法使用附加圖示和快捷選單選項。

替身檔案

如果你在尚未下載某個 macOS 替身檔案的裝置上，首次開啟儲存在 Nextcloud 的該檔案，系統可能會在文字編輯器中將它當作二進位檔案開啟，而無法跳轉至它指向的項目。這是因為 macOS 會在下載前決定如何開啟檔案，而伺服器上的替身檔案缺乏可供辨識的副檔名或類型資料，必須讀取檔案內容才能辨識。檔案首次開啟或下載後，Nextcloud 桌面客戶端便會辨識出這是替身，並將相關資料儲存在本機，其後即可正常開啟。要避免這個問題，請在首次開啟前，在 Finder 中以滑鼠右鍵按一下替身檔案，然後選擇 保留已下載項目。

在本機編輯

Nextcloud 網頁介面的 在本機編輯 操作只可在 Finder 顯示由檔案供應器延伸功能管理的檔案。

這項限制源於 macOS 本身，即使客戶端正常運作也會遇到。為保障你的安全，macOS 只允許特定應用程式開啟個別檔案，並禁止應用程式自行授予這項權限。客戶端中獲准管理這些檔案的部分無權啟動其他應用程式，而能啟動編輯器的部分則無權開啟該檔案。

授予「完整磁碟存取權」也無法解除這項限制，因為它由 macOS 保安系統的另一部分管理。

疑難排解

除錯級別記錄

檔案供應器延伸功能的除錯級別記錄默認停用。如果你想回報檔案供應器的問題，可以啟用這些記錄，以取得更詳盡的運作資料。要啟用記錄，請在「終端機」執行以下指令。

defaults write com.nextcloud.desktopclient.FileProviderExt debugLoggingEnabled -bool YES

變更會在幾秒內生效，毋須重新啟動延伸功能或 Mac。調查的問題解決後，建議按以下方式刪除明確設定的值，以恢復默認值。

defaults delete com.nextcloud.desktopclient.FileProviderExt debugLoggingEnabled
