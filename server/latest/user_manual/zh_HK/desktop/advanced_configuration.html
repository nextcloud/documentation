進階設定

你可以透過命令列選項、nextcloud.cfg 及環境變數設定桌面應用程式。一般選項請使用應用程式的「設定」視窗；本頁介紹進階設定及覆寫方式。有關只執行一次同步的獨立工具，請參閱 命令列用戶端。

以下默認值適用於標準 Nextcloud 用戶端。品牌版本、伺服器功能及作業系統政策可能會改變部分默認值。同步引擎設定適用於傳統同步，包括 Windows 虛擬檔案。macOS File Provider 擴充功能自行處理檔案傳輸，這些設定不會影響其傳輸引擎。請參閱 使用 macOS 檔案供應器。

命令列選項

使用 nextcloud [options] 啟動桌面應用程式。執行 nextcloud --help 可查看已安裝版本的選項。帶有值的選項同時接受 --option value 及 --option=value 格式。

套用啟動選項或環境變數前，請先結束正在執行的用戶端。啟動另一個執行個體時，命令可能會轉交給現有程序，而非以指定環境啟動新程序。

帳戶設定選項

這些選項會建立並儲存帳戶，然後結束。請重新啟動桌面應用程式以使用該帳戶。

參數

默認值

說明

--userid <user>

必填

要建立的帳戶的用戶 ID。

--serverurl <url>

必填

Nextcloud 伺服器的基本 URL，例如 https://cloud.example.com。

--apppassword <password>

未設定

帳戶的應用程式密碼。如省略，帳戶仍會儲存，但你須稍後在桌面應用程式登入。

--localdirpath <path>

建議資料夾

本機同步資料夾。如省略，會使用設定精靈建議的資料夾。現有資料夾必須為空。啟用 macOS File Provider 模式時會忽略此設定。

--remotedirpath <path>

/

新傳統同步連線的遠端資料夾。建立本機同步資料夾時適用。

--isvfsenabled <0|1>

0

在支援的情況下，使用 1 為新的傳統同步資料夾啟用虛擬檔案，或使用 0 下載檔案。此選項不會啟用 macOS File Provider 模式。

例如，建立帳戶後再從桌面應用程式登入：

nextcloud --userid carla --serverurl https://cloud.example.com --localdirpath "$HOME/Nextcloud"

設定檔案

用戶端以 INI 格式將設定儲存在 nextcloud.cfg。編輯前請結束用戶端並備份檔案，然後重新啟動。應用程式「設定」視窗中的變更可能覆寫檔案內相應的值。

標準位置如下：

  • Linux：$HOME/.config/Nextcloud/nextcloud.cfg。如已設定 XDG_CONFIG_HOME，則使用 $XDG_CONFIG_HOME/Nextcloud/nextcloud.cfg。

  • Windows：%APPDATA%\Nextcloud\nextcloud.cfg。

  • macOS（用戶端 33.0.0 或更新版本）：$HOME/Library/Containers/com.nextcloud.desktopclient/Data/Library/Preferences/Nextcloud/nextcloud.cfg。

  • 舊版 macOS 用戶端：$HOME/Library/Preferences/Nextcloud/nextcloud.cfg。

--confdir 可覆寫設定目錄。品牌用戶端可能使用其他目錄及檔案名稱。在 Citrix 等使用漫遊設定檔的環境中，請在工作階段之間保留用戶設定，以保存帳戶設定。

下列表格列出每項設定所屬的 INI 區段。例如：

[Nextcloud]
remotePollInterval=30000

[General]
logDebug=true
logExpire=48

帳戶身分、憑證、同步資料夾狀態、視窗尺寸與位置、快取、遷移標記及更新程式狀態均由用戶端管理。請使用設定精靈及「設定」視窗更改這些值。

優先次序視乎設定而定。以下環境變數覆寫只適用於對應設定。對於 skipUpdateCheck 和 autoUpdateCheck，[General] 中的值優先於 [Nextcloud]。在 Windows 上，管理員政策可覆寫這些更新設定，以及資料夾大小和外部儲存空間設定。更新政策詳情請參閱 在 Windows 環境中防止自動更新。

參數

remotePollInterval

30000 ms

輪詢伺服器變更的間隔。低於 5000 毫秒的值會恢復為 30000 毫秒。伺服器推送可減少輪詢需要。

forceSyncInterval

7200000 ms

自上次同步後經過此時間（2 小時）便排程同步。低於 remotePollInterval 的值會提高至該間隔。

fullLocalDiscoveryInterval

3600000 ms

經過此間隔（1 小時）後，下次符合條件的同步會完整掃描本機檔案系統。使用 -1 停用定期完整掃描。可由 OWNCLOUD_FULL_LOCAL_DISCOVERY_INTERVAL 覆寫。

notificationRefreshInterval

60000 ms

輪詢伺服器通知的間隔。低於 60000 毫秒的值會提高至 60000 毫秒。

skipUpdateCheck

false

停用更新檢查並隱藏更新介面。

autoUpdateCheck

true

在 skipUpdateCheck 為 false 時啟用自動更新檢查。

updateCheckInterval

36000000 ms

自動更新檢查間隔（默認：10 小時）。低於 300000 毫秒（5 分鐘）的值會提高至此下限。

useNewBigFolderSizeLimit

true

true

false

stopSyncingExistingFoldersOverLimit

來自 notifyExistingFoldersOverLimit

同時停止同步這些資料夾，直到你選擇繼續同步為止。必須啟用 notifyExistingFoldersOverLimit 及資料夾大小限制。

環境變數

啟動用戶端前請先設定環境變數。在終端機設定的變數只適用於從該終端機啟動的程序；已在執行的用戶端或從桌面啟動的用戶端不會自動繼承。例如，在 Linux 上暫時更改網絡閒置逾時時間：

OWNCLOUD_TIMEOUT=600 nextcloud

Nextcloud 用戶端仍使用歷史沿用的 OWNCLOUD_ 前綴。請依照各項說明的值格式操作：部分開關需要 0 或 1，另一些則會對任何非空白值（包括 0）作出反應。「默認值」表示未設定變數時的行為。

傳輸設定

在桌面傳統同步中，區塊大小及平行工作覆寫會在設定值和伺服器功能之後套用。nextcloudcmd 亦會讀取這些變數，但會使用同步引擎的默認值，而非桌面應用程式的區塊設定。

參數

默認值

說明

OWNCLOUD_CHUNK_SIZE

實際區塊大小

初始區塊大小（位元組）。桌面同步從 chunkSize 或伺服器提供的大小開始。nextcloudcmd 默認為 104857600 位元組（100 MiB）。

OWNCLOUD_MIN_CHUNK_SIZE

實際最小值

最小區塊大小（位元組）。桌面同步從 minChunkSize 開始；nextcloudcmd 默認為 5000000 位元組（5 MB）。

OWNCLOUD_MAX_CHUNK_SIZE

實際最大值

最大區塊大小（位元組）。桌面同步從 maxChunkSize 或伺服器提供的最大值開始；nextcloudcmd 默認為 5000000000 位元組（5 GB）。

OWNCLOUD_TARGET_CHUNK_UPLOAD_DURATION

60000 ms

動態調整區塊大小的目標時間（1 分鐘）。使用 0 停用動態調整。設定檔案中名稱相似的鍵不會生效。

OWNCLOUD_MAX_PARALLEL

視乎伺服器及通訊協定而定

平行同步工作的最大正整數數量。桌面同步會優先使用伺服器提供的值；否則 HTTP/2 使用 20，HTTP/1 使用 6。nextcloudcmd 默認為 6。這並非同時傳輸的檔案數量。

OWNCLOUD_TIMEOUT

timeout 或 300 秒

網絡閒置逾時時間。非零整數會覆寫桌面應用程式中的 timeout。nextcloudcmd 默認為 300 秒。零或無效值會使用正常默認值。

OWNCLOUD_HTTP2_ENABLED

已停用

設為 1 可允許 HTTPS 請求使用 HTTP/2。其他值會停用此功能。實際使用仍取決於伺服器及網絡連線。

OWNCLOUD_CHUNKING_NG

伺服器功能

設為 0 可停用較新的分塊上載協定，設為 1 則強制使用。其他值會依照伺服器功能決定。只有伺服器支援時才應強制啟用。

NEXTCLOUD_BULK_UPLOAD

伺服器功能

設為 0 可停用批量上載，設為 1 則強制啟用。其他值會依照伺服器功能決定。只有伺服器支援時才應強制啟用。

OWNCLOUD_PARALLEL_CHUNK

視乎伺服器而定

僅適用於舊版分塊上載方式：0 或 false 會停用平行區塊。除非伺服器停用，否則其他非空白值會啟用。

OWNCLOUD_LAZYOPS

已停用

非零整數會在上載請求中加入 OC-LazyOps: true 標頭。效果取決於伺服器支援情況。

區塊大小必須為正數。用戶端會調整最小值和最大值以涵蓋初始區塊大小。環境變數解析器對三項區塊大小覆寫接受 32 位元無符號整數，因此請勿使用超過 4294967295 位元組的值。

OWNCLOUD_FULL_LOCAL_DISCOVERY_INTERVAL

fullLocalDiscoveryInterval

僅適用於桌面傳統同步。覆寫本機完整掃描間隔（毫秒）。使用 -1 停用定期完整掃描。

512000000 bytes

OWNCLOUD_FREE_SPACE_BYTES

1000000000 bytes

25 seconds

同步失敗檔案的最短重試延遲。低於 25 的值會提高至 25。

OWNCLOUD_BLACKLIST_TIME_MAX

86400 seconds

同步失敗檔案的最長重試延遲（1 天）。只有正數會覆寫默認值。

OWNCLOUD_UPLOAD_CONFLICT_FILES

伺服器功能

設為 1 可上載衝突副本，設為 0 則阻止上載。非空白值會覆寫伺服器設定。請參閱 衝突。

因可用空間門檻而略過的下載，會在往後同步時重試。臨界門檻則會停止整個資料夾同步。這些限制與伺服器儲存配額互不相關。
