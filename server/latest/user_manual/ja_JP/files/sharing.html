File sharing

Nextcloud のユーザはファイルやフォルダを共有できます。共有先として可能なのは次の通りです:

  • 公開リンク

  • ユーザ

  • グループ

  • サークル

  • Talk の会話

  • フェデレーションされた Nextcloud サーバ上のユーザまたはグループ

注釈

一部のオプションは管理者の設定によりご利用いただけない場合があります。詳しくは administrator documentation をご覧ください。

公開リンクによる共有

ファイルやフォルダは公開リンク経由でも共有できます。

ランダムな15文字のトークンが生成され、リンクは https://cloud.example.com/s/yxcFKRWBJqYYzp4 のような形式になります。

公開 フォルダ 共有ではさまざまなオプションが利用可能です:

  • 閲覧のみ: 閲覧やダウンロードのみ許可します

  • アップロードと編集を許可

  • **ファイルドロップ**を有効にすると、共有先は既存のファイルを閲覧せずにファイルのアップロードだけが可能です。

  • ダウンロードを非表示: 共有先でダウンロードボタンやデフォルトブラウザの右クリックオプションを隠し、ダウンロードを難しくします

  • パスワード保護

  • 有効期限を設定 すると、期限到来時に共有が自動的に無効になります

  • 受信者へのメモ

  • 共有の解除: 共有を元に戻します

  • 別のリンクを追加: 権限の異なる複数の公開リンクを作成できます

公開 ファイル 共有では、Nextcloud の共同編集ソリューションのいずれかでファイル編集を許可できます。

注釈

Password protection and file expiration are also propagated using Federated File Sharing since Nextcloud 22.

ユーザ・グループとの内部共有

ユーザやグループ、サークル、または Talk 会話メンバーと共有する場合、ファイルやフォルダの権限を調整できます。

共有を受け取る側は、すべての新しい共有を自動的に受け入れてルートフォルダに追加するか、毎回受け入れるか拒否するか確認するかを設定できます。

受け入れ設定を調整するには 設定 > 個人 > 共有 へ進んでください:

警告

共有ファイルやフォルダの所有者が名前を変更しても、新しい名前は共有先には反映されません。これは、受信側に既存のファイルやフォルダが上書きされるのを防ぐためです。

アクセス権を持つ他のユーザ

上位のフォルダ階層で共有されていることで他のユーザがファイルやフォルダにアクセスできるか確かめるには、共有タブの アクセス権を持つ他のユーザ をクリックしてください:

このリストには、上位のフォルダの共有によって現在のファイルやフォルダにアクセスできるすべてのユーザ・グループ・チャット等が表示されます:

三点リーダをクリックすると次の操作ができます:

  • 誰が共有を開始したか確認できます

  • どの場所で共有されたかを確認できます（クリックすると、そのフォルダにアクセス権がある場合は移動できます）

  • 元の共有を解除します（この操作は共有の所有者のみ可能です）

注釈

この情報はファイル・フォルダの所有者、または再共有権限をもつ共有先だけが確認できます。

Federated shares

フェデレーション共有を使うと、リモートの Nextcloud サーバからのファイル共有をマウントでき、独自の Nextcloud クラウドを構築できます。他の Nextcloud サーバ上のユーザと直接共有リンクを作成することも可能です。

Creating a new federation share

フェデレーション共有はデフォルトで有効になっています。他の Nextcloud または ownCloud サーバと新しい共有を作成するには、次の手順に従ってください:

Files ページで共有したいファイルやディレクトリの共有アイコンをクリックします。サイドバーでリモートユーザのユーザ名と URL を <username>@<nc-server-url> の形で入力します。例: bob@cloud.example.com

共有先ユーザは自分の Nextcloud で通知を受け取り、共有を承認するか拒否するかを選択できます。
