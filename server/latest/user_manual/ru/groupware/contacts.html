Использование приложения «Контакты»

Приложение «Контакты» не включено по умолчанию в Nextcloud 36, его нужно отдельно установить из магазина приложений.

Приложение «Контакты» Nextcloud похоже на другие мобильные приложения для работы с контактами, но обладает более широкими возможностями. Рассмотрим основные функции, которые помогут вести адресную книгу в приложении.

Далее рассказано, как добавлять, изменять и удалять контакты, загружать изображение контакта и управлять адресными книгами.

Добавление контактов

При первом входе в приложение «Контакты» доступны системная адресная книга, в которой собраны все видимые вам пользователи сервера, и пустая адресная книга по умолчанию:

Контакты в адресную книгу можно добавить одним из следующих способов:

  • Импорт контактов из файла виртуального контакта (VCF/vCard)

  • Добавление контактов вручную

Самый быстрый способ добавить контакт — использовать файл виртуального контакта (VCF/vCard).

Импорт виртуальных контактов

Чтобы импортировать контакты из файла VCF/vCard:

  1. Кнопка Импортировать контакты показывается, если контактов ещё нет.

  2. Внизу левой боковой панели рядом со значком шестерёнки найдите «Параметры»:

  3. Нажмите значок шестерёнки. Появится кнопка «Импортировать» приложения «Контакты»:

Примечание

Приложение «Контакты» поддерживает импорт только vCard версий 3.0 и 4.0.

  1. Нажмите кнопку «Импортировать» и загрузите файл VCF/vCard.

После завершения импорта новый контакт появится в адресной книге.

Добавление контактов вручную

Если импортировать виртуальные контакты не получается, в приложении «Контакты» можно добавить контакты вручную.

Чтобы создать новый контакт:

  1. Нажмите кнопку + Создать контакт.

    В области просмотра приложения откроется форма редактирования:

  1. Введите данные нового контакта и нажмите «Сохранить».

  2. Режим просмотра покажет добавленные вами данные

Изменение и удаление сведений о контакте

В приложении «Контакты» можно изменять и удалять сведения о контактах.

Чтобы изменить или удалить контактную информацию:

  1. Перейдите к контакту, который нужно изменить.

  2. Выберите данные в поле, которое нужно изменить или удалить.

  3. Внесите изменения или нажмите значок корзины.

Изменения и удаления сведений о контакте применяются сразу.

Не все контакты можно изменять. Системная адресная книга не позволяет менять чужие данные, только свои. Свои данные также можно изменить в личных параметрах.

Если администратор разрешил обновление из социальных сетей в параметрах сервера, в разделе «Приложения для совместной работы», пользователи также могут получать изображения контактов непосредственно из социальных сетей. Для этого в контакте должно быть указано имя пользователя в разделе социальных сетей. Каждая запись поддерживаемой социальной сети добавляет соответствующий пункт скачивания. Сейчас поддерживаются следующие социальные сети:

  • Instagram

  • Mastodon

  • Tumblr

  • Diaspora

  • Xing

  • Telegram

  • Gravatar

Аватары из социальных сетей загружаются, только если они общедоступны и для их просмотра не нужно входить в соответствующую сеть. В параметрах пользователя на странице контактов можно включить автоматическое обновление из социальных сетей: аватары будут раз в неделю обновляться по данным социальных профилей. Социальные сети проверяются в порядке, указанном выше.

Одновременная работа с несколькими контактами

В приложении «Контакты» можно выбрать несколько контактов и выполнить над ними пакетные действия. Чтобы выбрать несколько контактов, нажимайте на изображение профиля каждого из них по очереди либо нажмите на изображение профиля первого контакта, а затем, удерживая клавишу Shift, нажмите на другой контакт в списке — будут выбраны все контакты между ними.

Над списком контактов появится меню с различными действиями, которые можно выполнить над выбранными контактами:

В пакетном режиме кнопка со значком крестика снимает выбор со всех выбранных контактов, а кнопка со значком корзины удаляет их.

Примечание

Некоторые контакты могут быть недоступны для изменения или удаления, например если они находятся в адресной книге только для чтения. В этом случае соответствующие действия отключены.

Объединение повторяющихся контактов

Чтобы объединить контакты, выберите два контакта и нажмите кнопку со значком «Объединить контакты» над списком контактов. Откроется диалог, который поможет объединить повторяющиеся контакты. В нём рядом показаны сведения об обоих контактах, и можно выбрать, какие данные сохранить в объединённом контакте.

Свойства с переключателем (круглая кнопка) могут иметь только одно значение, поэтому нужно выбрать одно из двух (например, имя контакта — оно может быть только одно). Флажки (квадратные кнопки) позволяют при желании оставить оба значения (например, номера телефонов или адреса эл. почты, которых может быть несколько).

Если один из контактов или оба входят в какие-либо группы, объединённый контакт по умолчанию войдёт во все группы, в которых состояли оба контакта. Если объединённый контакт не должен входить в какие-то группы, при объединении снимите флажки с этих групп.

Примечание

Сейчас можно объединять только два контакта за раз, и, разумеется, только те, которые вы можете изменять. Если действие объединения отключено, проверьте, что выбранные контакты соответствуют этим условиям.

Отметка контактов как избранных

Добавлено в версии 8.4.

Теперь контакты можно отмечать как избранные, чтобы всегда находить их в начале списка контактов, без поиска и фильтрации.

Чтобы отметить контакт как избранный, наведите указатель на контакт — справа появится звезда. Нажмите на звезду, и на изображении контакта появится жёлтая звезда, подтверждающая, что контакт отмечен как избранный.

Чтобы убрать контакт из избранного, наведите указатель на контакт в избранном и нажмите на звезду справа. Звезда исчезнет, и контакт вернётся на своё место в списке в алфавитном порядке.

Организация контактов с помощью групп

Группы контактов помогают организовать контакты.

Чтобы создать группу контактов, нажмите знак плюса рядом с надписью «Группы контактов» на левой боковой панели.

Примечание

Чтобы группу контактов можно было сохранить, в ней должен быть хотя бы один участник. В группы можно добавлять только контакты из адресных книг, доступных для записи. Контакты из адресных книг только для чтения, например из системной, добавить нельзя.

Добавление адресных книг и управление ими

Кнопка «Параметры» (шестерёнка) внизу левой боковой панели открывает параметры приложения «Контакты». Здесь показаны все доступные адресные книги и некоторые параметры для каждой из них, а новую адресную книгу можно создать, просто указав её имя:

В параметрах контактов можно также поделиться адресными книгами, экспортировать и удалять их. Там же находятся адреса CardDAV.

Примечание

Контакты из отключённых адресных книг не показываются в приложении «Контакты» и в меню «Контакты».

Подробнее о синхронизации адресных книг с iOS, macOS, Thunderbird и другими клиентами CardDAV см. в разделе Приложения для совместной работы.

Команды

Неформальное сотрудничество возникает внутри организаций: мероприятие, которое нужно подготовить за несколько недель, короткая встреча для обмена идеями между сотрудниками разных подразделений, семинары, место для шуток и сплочения коллектива или просто очень гибкие организации с минимумом формальной структуры.

Поэтому в Nextcloud есть команды: каждый пользователь может создать собственную команду — определяемую пользователем совокупность учётных записей. Команды можно использовать, чтобы делиться файлами и папками, а также добавлять их в обсуждения приложения «Конференции» наравне с обычными группами.

Примечание

Команды управляются в приложении Команды, у которого есть собственный пункт в панели навигации приложений. Приложение «Контакты» управляет командами только на серверах, где собственный интерфейс приложения «Команды» отключён; в этом случае описанные ниже представления команд появляются в «Контактах».

Создать команду

В левом меню нажмите + рядом с пунктом «Команды». Задайте название команды. На экране настройки команды можно:

  • добавлять участников в команду

  • изменять роль пользователя в команде, нажав на меню с тремя точками рядом с ним.

Роли в команде

В командах есть 4 роли:

  • Участник

  • Модератор

  • Администратор может настраивать параметры команды (и обладает правами модератора).

  • Владелец

Участник

Участник — роль с наименьшими правами. Участник может получать доступ только к ресурсам, которыми поделились с командой, и просматривать список участников команды.

Модератор

Помимо прав участника, модератор может приглашать, подтверждать приглашения и управлять участниками команды.

Администратор

Помимо прав модератора, администратор может настраивать параметры команды.

Владелец

Помимо прав администратора, владелец может передать право владения командой другому участнику. У команды может быть только один владелец.

Добавить участников в команду

В качестве участников в команду можно добавить локальные учётные записи, группы, адреса эл. почты или другие команды. Роль, назначенная группе или команде, действует для всех её участников.

Параметры команды

Для настройки команды есть несколько понятных параметров: приглашения и членство, видимость команды, разрешение входить в другие команды и защита паролем.

Запретить командам входить в состав другой команды

Если параметр включён, команду больше нельзя напрямую добавить в другую команду. Однако это ограничение действует только для новых прямых добавлений. Существующее членство сохраняется, а унаследованное остаётся возможным, если эта команда входит в родительскую команду, которую добавляют в другое место.

Общие элементы

Добавлено в версии 5.5: Nextcloud 25 или новее

Элементы, общие для двух контактов, показываются в приложении «Контакты». К ним относятся медиафайлы, события календаря, чаты и общие карточки приложения «Карточки»; все они видны в сведениях о контакте. Эта возможность работает только для контактов из системной адресной книги и пока поддерживает только общие элементы между двумя контактами.
