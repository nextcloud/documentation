Синхронизация с Thunderbird

Thunderbird — это многофункциональный и зрелый почтовый клиент, который можно превратить в полноценный менеджер личной информации (PIM). Начиная с версии 102, он поддерживает синхронизацию адресных книг через CardDAV и автоматическое обнаружение календарей и адресных книг, доступных на сервере.

Рекомендуемый метод

Начиная с Thunderbird 102, протоколы CardDAV и CalDAV поддерживаются изначально.

Контакты

  1. В представлении адресной книги нажмите стрелку вниз рядом с кнопкой Добавить адресную книгу и выберите Добавить адресную книгу CardDAV.

  2. В следующем окне введите Имя пользователя и Адрес (URL-адрес сервера).

  3. В следующем окне нужно будет ввести имя пользователя и пароль для этой учётной записи.

  4. Предыдущее окно обновится и предложит выбрать адресные книги для синхронизации.

  5. Сделайте выбор и нажмите Продолжить.

Чтобы позже добавить новую адресную книгу, повторите все эти шаги: будут предложены только те книги, которые ещё не синхронизируются.

Примечание

Если в вашей учётной записи включена двухфакторная аутентификация, для входа нужен специальный пароль приложения, а не обычный пароль.

Календари

  1. Перейдите в представление календаря в Thunderbird и нажмите кнопку Новый календарь… в нижней части левой боковой панели.

  2. Выберите В сети:

  3. Введите Имя пользователя и Расположение (URL-адрес сервера), затем нажмите Найти календари.

  4. Выберите календари, которые вы хотите добавить, и нажмите Подписаться

Здесь то же самое: чтобы позже добавить другие календари, просто повторите процедуру.

Альтернатива: использование надстройки CardBook (только для контактов)

CardBook — это продвинутая альтернатива адресной книге Thunderbird с поддержкой CardDAV.

  1. Нажмите значок CardBook в правом верхнем углу Thunderbird:

  2. В CardBook:

    • Выберите Адресная книга > Новая адресная книга Удалённая > Далее

    • Выберите CardDAV, введите адрес сервера Nextcloud, имя пользователя и пароль

  3. Нажмите «Подтвердить», затем «Далее», выберите имя адресной книги и снова нажмите «Далее»:

  4. По завершении CardBook синхронизирует адресные книги. Синхронизацию всегда можно запустить вручную, нажав кнопку Синхронизировать в CardBook:
