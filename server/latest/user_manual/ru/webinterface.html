Веб-интерфейс Nextcloud

Откройте URL своего сервера Nextcloud в любом веб-браузере и войдите, указав имя учётной записи (или адрес эл. почты) и пароль:

Войти также можно с помощью ключа доступа или аппаратного ключа безопасности, нажав Войти с устройства.

Требования к веб-браузеру

Для наилучшей работы используйте последнюю версию одного из этих браузеров:

  • Google Chrome / Chromium

  • Mozilla Firefox

  • Apple Safari

  • Microsoft Edge

Примечание

Поддерживаются не все версии: Nextcloud ориентируется на браузеры, соответствующие минимальному порогу использования.

Виджеты

После входа Nextcloud открывает страницу Виджеты — настраиваемый обзор самых важных событий: предстоящие события календаря, непрочитанные сообщения, последние файлы и другое.

Чтобы добавить, удалить или переставить виджеты под свой рабочий процесс, используйте кнопку Настроить внизу страницы.

Навигация по интерфейсу

Панель навигации в верхней части каждой страницы — основной способ доступа:

  • Логотип Nextcloud (слева вверху) возвращает на страницу «Виджеты».

  • Рядом с логотипом показаны ярлыки приложений — нажмите любой значок, чтобы перейти в нужное приложение (Файлы, Календарь, Конференции и так далее).

  • Значок поиска справа открывает объединённый поиск, который ищет сразу по всем приложениям.

  • Значок колокольчика показывает уведомления.

  • Значок контактов позволяет быстро найти других пользователей на сервере и связаться с ними.

  • Изображение профиля (справа) открывает меню параметров.

У каждого приложения также есть своя боковая панель слева с фильтрами и действиями, относящимися к этому приложению.

Параметры и профиль

Чтобы открыть параметры учётной записи, нажмите изображение профиля:

В этом меню можно:

  • Просмотреть и изменить профиль

  • Задать статус в сети

  • Изменить параметры внешнего вида и доступности

  • Открыть страницу личных параметров

  • Открыть справку и сведения о конфиденциальности

  • Выйти

Единый поиск

Чтобы открыть окно объединённого поиска, нажмите значок поиска на панели навигации (или воспользуйтесь комбинацией клавиш Ctrl+F):

Объединённый поиск одновременно охватывает все установленные приложения — файлы, события календаря, сообщения, контакты и другое. Результаты группируются по приложениям, чтобы сразу было видно, где найдено совпадение.

Чтобы сузить результаты, используйте фильтры:

  • Места — ограничить поиск определённым приложением, например «Файлы» или «Календарь».

  • Дата — фильтровать по периоду времени (сегодня, последние 7 дней, последние 30 дней, этот год или произвольный диапазон).

  • Люди — показывать только результаты, связанные с определённым человеком.
