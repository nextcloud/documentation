Доступ к файлам Nextcloud через WebDAV

Nextcloud полностью поддерживает протокол WebDAV, так что подключаться к файлам Nextcloud и синхронизировать их можно через WebDAV. Из этой главы вы узнаете, как подключить к серверу Nextcloud устройства под управлением Linux, macOS и Windows, а также мобильные устройства.

WebDAV расшифровывается как Distributed Authoring and Versioning («распределённая разработка и управление версиями»). Это расширение HTTP, упрощающее создание, чтение и редактирование файлов на удалённых веб-серверах. С помощью клиента WebDAV можно получать доступ к файлам Nextcloud (включая общие ресурсы) в Linux, macOS и Windows так же, как к любому удалённому сетевому ресурсу, и поддерживать их синхронизацию.

Прежде чем перейти к настройке WebDAV, ознакомьтесь с рекомендуемым способом подключения клиентских устройств к Nextcloud.

Официальные клиенты Nextcloud для ПК и мобильных устройств

Для синхронизации компьютера с сервером Nextcloud рекомендуется использовать официальные клиенты синхронизации Nextcloud. Клиент можно настроить на сохранение файлов в любую локальную папку и выбрать, какие папки на сервере Nextcloud синхронизировать. Клиент показывает текущее состояние соединения и ведёт журнал всех действий, поэтому вы всегда знаете, какие удалённые файлы скачаны на ваш компьютер, и можете убедиться, что файлы, созданные и изменённые на локальном компьютере, правильно синхронизируются с сервером.

Для синхронизации устройств Android и Apple iOS рекомендуется использовать официальные мобильные приложения Nextcloud.

Чтобы подключить официальные приложения Nextcloud к серверу, используйте тот же URL, который вы вводите в браузере для доступа к Nextcloud, например:

https://cloud.example.com

Если Nextcloud установлен в подпапке «nextcloud»:

https://example.com/nextcloud

Сторонние клиенты WebDAV

При желании компьютер можно подключить к серверу Nextcloud через любой сторонний клиент с поддержкой протокола WebDAV (в том числе встроенный в операционную систему).

Для подключения мобильного устройства к Nextcloud тоже можно использовать сторонние приложения с поддержкой WebDAV.

Учтите, что сторонние клиенты могут быть не оптимизированы для работы с Nextcloud или не поддерживать возможности, важные для ваших задач.

Участники сообщества Nextcloud сообщали об использовании следующих мобильных клиентов:

  • FolderSync (Android)

  • WebDAV Navigator (iPhone)

URL для настройки сторонних приложений для подключения к Nextcloud немного длиннее, чем для официальных клиентов:

https://cloud.example.com/remote.php/dav/files/USERNAME/

Если Nextcloud установлен в подпапке «nextcloud»:

https://example.com/nextcloud/remote.php/dav/files/USERNAME/

Примечание

Для входа через сторонний клиент WebDAV (в том числе встроенный в операционную систему) используйте пароль приложения, а не обычный пароль. Это не только безопаснее, но и значительно ускоряет работу. Чтобы создать пароль приложения, войдите в веб-интерфейс Nextcloud, нажмите на аватар и выберите Личные параметры. Затем выберите Безопасность на боковой панели слева и прокрутите страницу до самого низа. Там можно создать пароль приложения (его можно в любой момент отозвать, не меняя основной пароль).

Примечание

В следующих примерах замените example.com/nextcloud на URL вашего сервера Nextcloud (если Nextcloud установлен в корне домена, часть с папкой опустите), а USERNAME — на имя подключающегося пользователя.

URL WebDAV можно найти в параметрах «Файлы» в разделе WebDAV вашей учётной записи Nextcloud.

Доступ к файлам с помощью Linux

В операционных системах Linux доступ к файлам можно получить следующими способами.

Файловый менеджер Nautilus

Если вы настроили учётную запись Nextcloud в Центре управления GNOME, файлы будут автоматически подключены в Nautilus как общий ресурс WebDAV, если не снять флажок доступа к файлам.

Файлы Nextcloud можно подключить и вручную. Чтобы подключить файловый менеджер Nautilus к общему ресурсу Nextcloud, используйте протокол davs://:

davs://example.com/nextcloud/remote.php/dav/files/USERNAME/

Примечание

Если соединение с сервером не защищено HTTPS, используйте dav:// вместо davs://:

Примечание

Тот же способ работает и в других файловых менеджерах, использующих GVFS, например в Caja из MATE и Nemo из Cinnamon.

Доступ к файлам в KDE и файловом менеджере Dolphin

  1. Откройте «Параметры системы» → «Сеть и связь» → «Учётные записи в Интернете»

  2. Нажмите «Добавить учётную запись…»

  3. Нажмите Nextcloud

  4. Введите адрес сервера

  5. Следуйте инструкциям на экране, чтобы войти в учётную запись

  6. После входа убедитесь, что в разделе «Использовать ресурсы учётной записи:» включён пункт «Хранение файлов»

  7. Теперь файлы доступны в Dolphin в разделе «Сеть» на боковой панели

  8. (Необязательно) Чтобы добавить это расположение ярлыком на боковую панель, щёлкните правой кнопкой мыши «Nextcloud Storage» и выберите «Добавить в точки входа»

  9. (Необязательно) Чтобы настроить ярлык, щёлкните его на боковой панели правой кнопкой мыши, выберите «Изменить…» и задайте значок и название по своему усмотрению

Подключение WebDAV из командной строки Linux

WebDAV можно подключить из командной строки Linux. Это удобно, если вы хотите работать с Nextcloud так же, как с любым другим удалённым монтируемым ресурсом. В примере ниже показано, как создать личную точку монтирования и подключать её автоматически при каждом входе в систему на компьютере с Linux.

  1. Установите драйвер файловой системы WebDAV davfs2, который позволяет монтировать ресурсы WebDAV так же, как любую другую удалённую файловую систему. В Debian/Ubuntu он устанавливается командой:

    apt-get install davfs2

  2. В CentOS, Fedora и openSUSE используйте команду:

    yum install davfs2

  3. Добавьте себя в группу davfs2:

    usermod -aG davfs2 <username>

Примечание

Если после установки пакета группа davfs2 отсутствует, возможно, потребуется создать её самостоятельно, а затем изменить файл конфигурации davfs, чтобы использовать эту группу.

  1. Затем создайте в домашней папке папку nextcloud для точки монтирования и папку .davfs2/ для личного файла конфигурации:

    mkdir ~/nextcloud
mkdir ~/.davfs2

  2. Скопируйте /etc/davfs2/secrets в ~/.davfs2:

    cp  /etc/davfs2/secrets ~/.davfs2/secrets

  3. Назначьте себя владельцем и разрешите чтение и запись только владельцу:

    chown <linux_username>:<linux_username> ~/.davfs2/secrets
chmod 600 ~/.davfs2/secrets

  4. Добавьте учётные данные Nextcloud в конец файла secrets, указав URL вашего сервера Nextcloud, имя пользователя и пароль:

    https://example.com/nextcloud/remote.php/dav/files/USERNAME/ <username> <password>
or
$PathToMountPoint $USERNAME $PASSWORD
for example
/home/user/nextcloud john 1234

  5. Добавьте информацию о монтировании в /etc/fstab:

    https://example.com/nextcloud/remote.php/dav/files/USERNAME/ /home/<linux_username>/nextcloud davfs user,rw,auto 0 0

  6. Затем проверьте, что ресурс монтируется и аутентификация проходит, выполнив следующую команду. Если всё настроено правильно, права root не понадобятся:

    mount ~/nextcloud

  7. Вы также должны иметь возможность размонтировать его:

    umount ~/nextcloud

Теперь при каждом входе в систему Linux ваш общий ресурс Nextcloud будет автоматически монтироваться через WebDAV в папку ~/nextcloud. Если вы хотите монтировать его вручную, замените auto на noauto в /etc/fstab.

Известные проблемы

Проблема

Ресурс временно недоступен

Решение

Если при создании файла в папке возникают проблемы, отредактируйте /etc/davfs2/davfs2.conf и добавьте:

use_locks 0

Проблема

Предупреждения о сертификате

Решение

Если используется самоподписанный сертификат, появится предупреждение. Чтобы его убрать, настройте davfs2 на распознавание вашего сертификата. Скопируйте mycertificate.pem в /etc/davfs2/certs/. Затем отредактируйте /etc/davfs2/davfs2.conf и раскомментируйте строку servercert. Теперь добавьте путь к сертификату, как в этом примере:

servercert /etc/davfs2/certs/mycertificate.pem

Доступ к файлам в macOS

Чтобы получить доступ к файлам через Finder в macOS:

  1. В строке меню Finder выберите Переход > Подключиться к серверу…:

  2. Когда откроется окно Подключение к серверу, введите адрес WebDAV вашего сервера Nextcloud в поле Адрес сервера:, например:

    https://cloud.YOURDOMAIN.com/remote.php/dav/files/USERNAME/

  3. Нажмите Подключить. Сервер WebDAV появится на рабочем столе как общий диск.

Доступ к файлам с помощью Microsoft Windows

Если вы используете встроенную в Windows реализацию WebDAV, Nextcloud можно подключить как новый сетевой диск с помощью Проводника Windows. После этого файлы на сервере Nextcloud можно просматривать так же, как файлы на любом подключённом сетевом диске.

Для этого нужно подключение к сети. Чтобы работать с файлами без подключения к сети, используйте клиент для ПК, чтобы синхронизировать все файлы Nextcloud с одной или несколькими папками на локальном жёстком диске.

Примечание

В Windows 10 обычная аутентификация (Basic Authentication) по умолчанию разрешена, если до подключения диска включён HTTPS.

В более старых версиях Windows использование обычной проверки подлинности (Basic Authentication) нужно разрешить в реестре Windows:

  • запустите regedit и перейдите к HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\WebClient\Parameters.

  • Создайте или измените параметр BasicAuthLevel (Windows Vista, 7 и 8) либо UseBasicAuth (Windows XP и Windows Server 2003) типа DWORD и задайте ему значение 1 для SSL-соединений. Значение 0 означает, что Basic Authentication отключена, а 2 разрешает как SSL-, так и обычные соединения (не рекомендуется).

  • Затем закройте редактор реестра и перезагрузите компьютер.

Подключение дисков из командной строки

В примере ниже показано, как подключить диск из командной строки. Для этого:

  1. Откройте командную строку Windows.

  2. Введите в командной строке следующую команду, чтобы подключить диск Z:

    net use Z: https://<drive_path>/remote.php/dav/files/USERNAME/ /user:youruser yourpassword

    где <drive_path> — URL вашего сервера Nextcloud. Например:

    net use Z: https://example.com/nextcloud/remote.php/dav/files/USERNAME/ /user:youruser yourpassword

    Файлы вашей учётной записи Nextcloud будут доступны на диске Z.

Ошибка

Если появляется сообщение об ошибке Системная ошибка 67. Не найдено сетевое имя. или соединение часто разрывается, откройте приложение Службы и убедитесь, что служба WebClient запущена и настроена на автоматический запуск.

Примечание

Подключить сервер Nextcloud можно и по HTTP, оставив соединение незашифрованным, но делать так не рекомендуется.

Если вы собираетесь подключаться по HTTP в общественных местах, настоятельно рекомендуем защитить соединение VPN-туннелем.

Альтернативный синтаксис команды:

net use Z: \\example.com@ssl\nextcloud\remote.php\dav /user:youruser
yourpassword

Подключение дисков с помощью Проводника Windows

Чтобы подключить диск с помощью Проводника Windows:

  1. Откройте Проводник Windows на компьютере с MS Windows.

  2. Щёлкните правой кнопкой мыши пункт Компьютер и выберите в раскрывающемся меню Подключить сетевой диск…

  3. Выберите букву локального диска, под которой нужно подключить Nextcloud.

  4. Укажите адрес вашего сервера Nextcloud, а после него — /remote.php/dav/files/USERNAME/.

    Например:

    https://example.com/nextcloud/remote.php/dav/files/USERNAME/

    Примечание

    Для серверов, защищённых SSL, установите флажок Повторное подключение при входе в систему, чтобы диск оставался подключённым после перезагрузки. Если вы хотите подключиться к серверу Nextcloud от имени другого пользователя, установите флажок Использовать другие учётные данные.

  5. Нажмите кнопку Готово.

Проводник Windows подключит сетевой диск, и ваш сервер Nextcloud станет доступен.

Доступ к файлам с помощью Cyberduck

Cyberduck — программа с открытым исходным кодом для работы с FTP, SFTP, WebDAV, OpenStack Swift и Amazon S3, предназначенная для передачи файлов в macOS и Windows.

Примечание

В этом примере используется Cyberduck версии 4.2.1.

Порядок работы с Cyberduck:

  1. Укажите сервер без префикса протокола.

    Например: example.com

  2. Укажите соответствующий порт.

    Какой порт выбрать, зависит от того, поддерживает ли сервер Nextcloud SSL. Если вы собираетесь использовать SSL, в Cyberduck нужно выбрать другой тип подключения.

    Пример:

    • 80 для незашифрованного WebDAV

    • 443 для защищённого WebDAV (HTTPS/SSL)

  3. В раскрывающемся меню «Дополнительные параметры» добавьте остальную часть URL WebDAV в поле «Путь».

    Например: remote.php/dav/files/USERNAME/

Теперь Cyberduck обеспечивает доступ к файлам на сервере Nextcloud.

Доступ к общим ресурсам по ссылке через WebDAV

Nextcloud позволяет получать анонимный доступ к общим ресурсам по ссылке через WebDAV.

Чтобы получить доступ к общему ресурсу по ссылке, откройте адрес:

https://example.com/nextcloud/public.php/dav/files/USERNAME

в клиенте WebDAV; в качестве имени пользователя используйте токен общего ресурса, а в качестве пароля — пароль общего ресурса (если он задан). Например, для ссылки https://example.com/s/kFy9Lek5sm928xP имя пользователя будет kFy9Lek5sm928xP.

Примечание

Параметры → Параметры сервера → Общий доступ → Разрешить пользователям этого сервера отправлять общие ресурсы на другие серверы. Этот параметр также разрешает доступ к общим ресурсам по ссылке через WebDAV и должен быть включён, чтобы эта функция работала, кроме случая использования cURL (см. ниже).

Известные проблемы

Проблема

Доступ по WebDAV очень медленный или время ожидания истекает.

Решение

При использовании стороннего клиента WebDAV (в том числе встроенного в операционную систему) для аутентификации следует применять пароль приложения, а не обычный пароль учётной записи. При использовании обычного пароля быстродействие значительно снижается, так как Nextcloud вынужден выполнять дополнительную работу для его проверки при каждом запросе. Пароль приложения устраняет эти накладные расходы и может существенно повысить скорость передачи.

Чтобы создать пароль приложения, войдите в веб-интерфейс Nextcloud, нажмите на аватар, выберите Личные параметры, затем откройте раздел Безопасность в левой боковой панели и прокрутите страницу до конца. Создайте там пароль приложения и используйте его в клиенте WebDAV вместо основного пароля.

Проблема

Windows не подключается по HTTPS.

Решение 1

Клиент WebDAV в Windows может не поддерживать расширение Server Name Indication (SNI) в зашифрованных соединениях. Если при подключении сервера Nextcloud с SSL-шифрованием возникает ошибка, попросите провайдера выделить вашему SSL-серверу отдельный IP-адрес.

Решение 2

Клиент WebDAV в Windows может не поддерживать соединения TLSv1.1 и TLSv1.2. Если вы настроили сервер так, что он принимает только TLSv1.1 и выше, подключение к нему может завершиться ошибкой. Подробнее см. в документации WinHTTP.

Проблема

Появляется сообщение об ошибке: Ошибка 0x800700DF: Размер файла превышает установленное ограничение, сохранение файла невозможно.

Решение

Windows ограничивает максимальный размер файла, передаваемого на ресурс WebDAV или с него. Увеличить значение FileSizeLimitInBytes можно в HKEY_LOCAL_MACHINE\\SYSTEM\\CurrentControlSet\\Services\\WebClient\\Parameters, нажав Изменить.

Чтобы увеличить лимит до максимального значения 4 ГБ, выберите Десятичная, введите значение 4294967295 и перезагрузите Windows или перезапустите службу WebClient.

Проблема

Если добавить диск WebDAV в Windows описанным выше способом, показывается не реальный объём доступного места в Nextcloud, а размер диска C: и его свободное место.

Ответ

К сожалению, это ограничение самого WebDAV: он не позволяет клиенту узнать у сервера объём свободного места. Windows автоматически использует вместо него размер и свободное место диска C:. Прямого решения этой проблемы нет.

Проблема

Не удаётся получить доступ к файлам из Microsoft Office через WebDAV.

Решение

Известные проблемы и способы их решения описаны в статье KB2123563.

Проблема

Невозможно подключить Nextcloud как диск WebDAV в Windows, если используется самоподписанный сертификат.

Решение

  1. Откройте сервер Nextcloud в предпочитаемом веб-браузере.

  2. Пропускайте предупреждения, пока в строке состояния браузера не появится ошибка сертификата.

  3. Просмотрите сертификат, затем на вкладке «Состав» выберите «Копировать в файл».

  4. Сохраните файл на рабочий стол под любым именем, например myNextcloud.pem.

  5. Выберите «Пуск» → «Выполнить», введите MMC и нажмите «ОК», чтобы открыть консоль управления Microsoft.

  6. Выберите «Файл» → «Добавить или удалить оснастку».

  7. Выберите «Сертификаты», нажмите «Добавить», выберите «Моей учётной записи», затем «Готово» и наконец «ОК».

  8. Раскройте «Доверенные корневые центры сертификации» → «Сертификаты».

  9. Щёлкните «Сертификаты» правой кнопкой мыши и выберите «Все задачи» → «Импорт».

  10. Выберите сертификат, сохранённый на рабочем столе.

  11. Выберите «Поместить все сертификаты в следующее хранилище» и нажмите «Обзор».

  12. Установите флажок «Показывать физические хранилища», разверните «Доверенные корневые центры сертификации», выберите «Локальный компьютер», нажмите «ОК» и завершите импорт.

  13. Проверьте, что сертификат появился в списке. Возможно, понадобится нажать «Обновить».

  14. Закройте консоль MMC.

Для пользователей Firefox:

  1. Запустите браузер и выберите меню приложения → «История» → «Удалить недавнюю историю…»

  2. В раскрывающемся меню «Удалить» выберите «Всё».

  3. Установите флажок «Активные сеансы».

  4. Нажмите кнопку «Удалить сейчас».

  5. Закройте браузер, затем откройте его снова и проверьте подключение.

Для пользователей браузеров на базе Chrome (Chrome, Chromium, Microsoft Edge):

  1. Откройте панель управления Windows и перейдите в раздел «Свойства браузера».

  2. На вкладке «Содержимое» нажмите кнопку «Очистить состояние SSL».

  3. Закройте браузер, затем откройте его снова и проверьте подключение.

Доступ к файлам с помощью cURL

Поскольку WebDAV — расширение HTTP, с помощью cURL можно писать сценарии для работы с файлами.

Примечание

Параметры → Параметры сервера → Общий доступ → Разрешить пользователям этого сервера отправлять общие ресурсы на другие серверы. Если этот параметр выключен, cURL нужно передать параметр --header "X-Requested-With: XMLHttpRequest".

Чтобы создать папку с текущей датой в качестве имени:

$ curl -u user:pass -X MKCOL "https://example.com/nextcloud/remote.php/dav/files/USERNAME/$(date '+%d-%b-%Y')"

Чтобы загрузить файл error.log в эту папку:

$ curl -u user:pass -T error.log "https://example.com/nextcloud/remote.php/dav/files/USERNAME/$(date '+%d-%b-%Y')/error.log"

Чтобы переместить файл:

$ curl -u user:pass -X MOVE --header 'Destination: https://example.com/nextcloud/remote.php/dav/files/USERNAME/target.jpg' https://example.com/nextcloud/remote.php/dav/files/USERNAME/source.jpg

Чтобы получить свойства файлов в корневой папке:

$ curl -X PROPFIND -H "Depth: 1" -u user:pass https://example.com/nextcloud/remote.php/dav/files/USERNAME/ | xml_pp

Доступ к файлам с помощью WinSCP

WinSCP — свободный клиент SFTP, FTP, WebDAV, S3 и SCP с открытым исходным кодом для Windows. Его основная функция — передача файлов между локальным и удалённым компьютером. Кроме того, WinSCP поддерживает сценарии и базовые функции управления файлами.

Переносную версию WinSCP можно скачать и запустить в Linux через Wine.

Чтобы запустить WinSCP в Linux, установите Wine с помощью менеджера пакетов дистрибутива, а затем запустите программу командой wine WinSCP.exe.

Чтобы подключиться к Nextcloud:

  • Запустите WinSCP.

  • Выберите в меню «Сеанс».

  • Выберите пункт меню «Новый сеанс».

  • В раскрывающемся списке «Протокол передачи» выберите WebDAV.

  • В раскрывающемся списке «Шифрование» выберите «Неявное TLS/SSL-шифрование».

  • Заполните поле «Имя хоста»: example.com

  • Заполните поле «Имя пользователя»: NEXTCLOUDUSERNAME

  • Заполните поле «Пароль»: NEXTCLOUDPASSWORD

  • Нажмите кнопку «Дополнительно…»

  • Слева перейдите в раздел «Среда» → «Папки».

  • В поле «Удалённый каталог» укажите: /nextcloud/remote.php/dav/files/NEXTCLOUDUSERNAME/

  • Нажмите кнопку «ОК».

  • Нажмите кнопку «Сохранить».

  • Выберите нужные параметры и нажмите кнопку «ОК».

  • Нажмите кнопку «Войти», чтобы подключиться к Nextcloud.

Примечание

Если используется TOTP, применяйте пароль приложения. На момент написания (2022-11-07) WinSCP не поддерживает TOTP при работе с Nextcloud.
