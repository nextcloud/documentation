Системные метки

Системные метки — это метки в пределах всего сервера, которые можно назначать файлам и папкам, чтобы упорядочивать их, фильтровать список файлов и запускать автоматизированные рабочие процессы, например правила хранения и управление доступом.

Метки показываются прямо в строках файлов и папок в приложении Файлы, так что сразу видно, какие метки назначены:

Метки создают администраторы в параметрах сервера. В зависимости от конфигурации сервера обычные пользователи тоже могут создавать метки — администратор может разрешить создание меток только администраторам.

Уровни доступа к меткам

Каждая метка имеет один из трёх уровней доступа, которые определяют, что обычные пользователи могут видеть и делать:

Уровень

Видна пользователям

Да

Ограниченные и невидимые метки используются администраторами для автоматизированных рабочих процессов. Обойти их, сняв метку самостоятельно, нельзя.

Просмотр файлов по меткам

Нажмите значок навигации (≡) в левом верхнем углу приложения Файлы, чтобы открыть панель навигации, затем нажмите Метки. В этом представлении перечислены все видимые вам метки. Нажмите название метки, чтобы увидеть все файлы и папки с этой меткой.

Назначение меток файлам

Метки можно назначать или удалять как для одного файла, так и сразу для нескольких выбранных файлов.

Один файл

  1. Нажмите меню действий с тремя точками (…) рядом с файлом или папкой и выберите Подробности, чтобы открыть боковую панель сведений.

  2. В боковой панели сведений нажмите Добавить метки.

  3. Введите название метки в поле поиска и выберите метку из списка.

  4. Чтобы закрыть окно выбора меток, нажмите вне его. Изменения сохраняются сразу.

Чтобы удалить метку, откройте то же окно выбора и нажмите × рядом с названием метки.

Примечание

Обычным пользователям в окне выбора показываются только общие метки. Ограниченные и невидимые метки может назначать только администратор.

Несколько файлов

  1. Выберите два или более файлов, установив флажок слева от каждой строки.

  2. Нажмите ··· Действия на панели инструментов над списком файлов, затем выберите Управление метками.

  3. Установите или снимите флажки меток в открывшемся диалоговом окне. Строка сведений показывает, как изменение будет применено к выбранным файлам.

  4. Нажмите Применить.

Создание меток и управление ими

Если администратор не ограничил создание меток, новую метку можно создать прямо в диалоговом окне Управление метками или в окне выбора меток для одного файла: введите новое название в поле Найти или создать метку и выберите появившийся пункт Создать метку.

Администраторы создают, переименовывают и удаляют метки в разделе Параметры сервера ‣ Сервер. Подробнее об управлении метками и инструментах командной строки см. раздел Автоматическое назначение меток руководства администратора.
