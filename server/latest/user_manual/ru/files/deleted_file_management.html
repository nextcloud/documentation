Удалённые файлы

При удалении файла или папки в Nextcloud они обычно перемещаются в корзину, а не удаляются сразу. Это позволяет восстановить их позже.

Элементы в корзине удаляются безвозвратно в одном из следующих случаев:

  • Вы вручную выбираете Удалить навсегда.

  • Приложение «Удалённые файлы» удаляет элемент в соответствии с настроенной политикой хранения.

  • Превышен действующий лимит размера корзины, и элемент может быть удалён для освобождения места.

Чтобы найти удалённые файлы, выберите Удалённые файлы в разделе «Файлы» веб-интерфейса Nextcloud. Оттуда можно восстановить элементы, скачать их на устройство или удалить навсегда.

При восстановлении элемента Nextcloud обычно пытается вернуть его в исходное расположение. Если это расположение больше не существует или недоступно для записи, элемент восстанавливается в корень вашей области «Файлы». Если элемент с таким же именем уже существует, Nextcloud присваивает восстановленному элементу уникальное имя.

Примечание

Если приложение «Версии» включено, версии, связанные с удалённым файлом, перемещаются в корзину и восстанавливаются вместе с файлом.

Квоты

Файлы и папки в корзине не учитываются в обычной квоте хранилища.

Дополнительные сведения о расчёте квот хранилища см. в разделе Квота хранилища.

Что происходит при удалении общих файлов

Поведение удалённых общих файлов зависит от того, кто удаляет элемент и кому он принадлежит.

Например, User1 делится папкой TheProject/ с User2 и User3:

  1. User2, получатель общего ресурса (sharee), удаляет папку или файл Phase2 в папке TheProject/.

    TheProject/Phase2 перемещается в корзину владельца User1, а копия, когда это возможно, помещается в корзину User2. Для User3 элемент удаляется из общей папки, но копия в корзину User3 не попадает.

  2. Владелец User1 удаляет TheProject/Phase2.

    Когда User1 удаляет элемент, он перемещается в корзину User1. У User2 и User3 он удаляется, но в их корзины не попадает.

Точное поведение зависит от типа общего ресурса и предоставленных в нём разрешений. В зависимости от этих разрешений другие пользователи могут копировать, переименовывать, перемещать общие файлы или делиться ими повторно. Эти операции влияют на то, какая учётная запись владеет итоговыми файлами и в какую корзину попадает удалённый элемент.

Примечание

Если получатель общего ресурса удаляет элемент, принадлежащий другому пользователю, Nextcloud перемещает элемент в корзину владельца. Копия также создаётся в корзине удаляющего пользователя (в большинстве случаев; копия создаётся по возможности и не гарантируется).

Как приложение «Удалённые файлы» управляет местом в хранилище

Приложение «Удалённые файлы» управляет содержимым корзины с помощью двух связанных правил:

  • Ограничение хранилища определяет, сколько места может занимать корзина.

  • Политика хранения определяет, когда удалённые элементы могут быть удалены безвозвратно.

Ограничение размера корзины

Для учётных записей с квотой на хранилище ограничение корзины по умолчанию составляет до 50 % оставшегося пространства квоты. Оно рассчитывается с учётом активных файлов учётной записи и не является 50 % от общей квоты.

Например, если квота составляет 10 ГБ, а активные файлы занимают 8 ГБ, ограничение корзины по умолчанию рассчитывается от оставшихся 2 ГБ.

Для учётных записей без квоты на хранилище ограничение по умолчанию рассчитывается исходя из доступного пространства файловой системы. Администратор может переопределить любое из значений по умолчанию, задав общий размер корзины или размер корзины для отдельной учётной записи.

Когда действующее ограничение корзины превышено, Nextcloud удаляет подходящие удалённые элементы, начиная с самых старых, пока ограничение снова не будет соблюдено.

Хранение и окончательное удаление

По умолчанию удалённые файлы хранятся не менее 30 дней. После этого подходящие элементы могут быть окончательно удалены, когда потребуется место; не обязательно, что это произойдёт сразу по истечении 30 дней.

Администратор может настроить другие минимальный и максимальный сроки хранения. В зависимости от конфигурации элементы могут быть окончательно удалены по достижении максимального возраста, даже если место в хранилище сейчас не требуется. Автоматическое истечение срока также можно отключить.

Если в правилах задан минимальный срок хранения, элемент становится доступен для очистки для освобождения места только после его истечения. Правила без минимального срока хранения могут допускать очистку для освобождения места независимо от возраста элемента. Элементы, превысившие заданный максимальный срок хранения, могут быть окончательно удалены независимо от того, требуется ли сейчас место.

Соответствующий параметр конфигурации — trashbin_retention_obligation. Подробнее о доступных значениях и их взаимодействии с квотами и размерами корзины см. в разделе Удалённые файлы руководства администратора.

Примечание

Приложение «Удалённые файлы» может окончательно удалить элемент до истечения максимального срока хранения, если действующее ограничение корзины превышено и минимальный срок хранения элемента истёк.
