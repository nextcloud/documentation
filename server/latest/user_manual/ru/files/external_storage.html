Использование внешнего хранилища

Приложение «Внешнее хранилище» позволяет серверу Nextcloud подключаться к удалённым файловым системам — таким как Amazon S3, серверы SFTP, общие ресурсы SMB/CIFS или серверы WebDAV — и показывать их как папки в приложении «Файлы». Администраторы определяют, какие модули доступны и какие подключения предоставлены вам.

Если администратор включил внешние хранилища, управляемые пользователем, можно также добавить собственные подключения в разделе «Личные параметры».

Доступ к внешним хранилищам

Подключения внешних хранилищ показываются как обычные папки в приложении «Файлы». В них можно просматривать, загружать, скачивать и удалять файлы так же, как в любой другой папке. Возможность общего доступа зависит от того, включил ли её администратор для каждого отдельного подключения.

Цветной индикатор рядом с именем папки показывает состояние подключения:

  • Зелёный — хранилище подключено и готово к работе.

  • Жёлтый — не удалось подключиться к хранилищу; Nextcloud повторит попытку автоматически.

  • Красный — хранилище недоступно. Если проблема не исчезает, обратитесь к администратору.

Если подключение недоступно, Nextcloud на десять минут помечает его как отключённое, после чего повторяет попытку. Чтобы запустить проверку вручную, нажмите на индикатор состояния.

Примечание

Некоторые подключения внешних хранилищ могут быть доступны только для чтения. В таком подключении нельзя загружать и удалять файлы.

Общий доступ к файлам во внешнем хранилище

Общий доступ к файлам из внешнего хранилища работает так же, как и к любым другим файлам и папкам: используйте значок общего доступа в приложении «Файлы». Администратор должен явно включить общий доступ для каждого подключения, поэтому значка может не быть у некоторых подключений.

Примечание

Шифрование на стороне сервера недоступно для внешних подключений к другим серверам Nextcloud.

Добавление собственного внешнего хранилища

Если администратор включил внешние хранилища, управляемые пользователем, можно подключить собственные хранилища в разделе Личные параметры → Внешнее хранилище.

Чтобы добавить новое подключение:

  1. Нажмите на значок профиля и выберите Личные параметры.

  2. В левой боковой панели выберите Внешнее хранилище.

  3. Выберите модуль в раскрывающемся списке Добавить хранилище.

  4. Заполните обязательные поля для модуля (адрес сервера, путь, учётные данные и т. д.).

  5. Выберите способ аутентификации в раскрывающемся списке Способ аутентификации.

Обязательные поля отмечены красной рамкой. Как только все обязательные поля заполнены, подключение сохраняется автоматически.

Зелёная точка рядом с подключением подтверждает успешное подключение. Красный или жёлтый значок означает, что Nextcloud не удалось подключиться — проверьте учётные данные и параметры сети.

Чтобы удалить подключение, откройте меню из трёх точек рядом с ним и выберите Удалить.

Примечание

Подключения, добавленные в личных параметрах, видны только вашей учётной записи.

Поддерживаемые модули

Следующие модули могут быть доступны в зависимости от того, что включил администратор:

  • Amazon S3 — контейнеры Amazon Simple Storage Service и хранилища, совместимые с S3.

  • FTP — серверы FTP и FTPS.

  • Nextcloud / ownCloud — другой сервер Nextcloud или ownCloud по WebDAV.

  • OpenStack Object Storage — контейнеры OpenStack Swift.

  • SFTP — серверы SSH File Transfer Protocol.

  • SMB / CIFS — общие файловые ресурсы Windows и серверы Samba.

  • WebDAV — любой сервер, совместимый с WebDAV.

Сведения о настройке отдельных модулей см. в разделе Настройка внешнего хранилища (графический интерфейс) руководства администратора.

Обнаружение изменений файлов

Файлы, добавленные или изменённые через Nextcloud, отражаются сразу. Файлы, добавленные или изменённые напрямую во внешнем хранилище, минуя Nextcloud, могут не появиться до следующего фонового сканирования.

Если файлы, добавленные извне, не появляются, попросите администратора выполнить occ files:scan или настроить периодическое фоновое сканирование для подключения.
