Отправка сообщений

Использование Markdown

Сообщения можно оформлять с помощью синтаксиса Markdown. Поддерживаются следующие элементы:

Заголовки и разделители

# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6

Heading
===
Normal text
***
Normal text

Оформление внутри строки

**bold text** __bold text__
*italicized text* _italicized text_
`inline code` ``inline code``
```
.code-block {
  display: pre;
}
```

Списки

1. Ordered list
2. Ordered list

* Unordered list
- Unordered list
+ Unordered list

Цитаты

> blockquote
second line of blockquote

Списки задач

- [ ] task to be done
- [x] completed task

Таблицы

Column A | Column B
-- | --
Data A | Data B

Вставка эмодзи

Эмодзи можно добавлять с помощью окна выбора слева от поля ввода текста.

Умный подборщик

Умный подборщик упрощает вставку в обсуждения ссылок, файлов и другого содержимого. Достаточно выбрать тип содержимого (файлы, обсуждения, карточки, GIF-анимации и т. д.). Чтобы открыть подборщик, можно также ввести / в поле ввода чата.

Приложения-интеграции могут добавлять в умный подборщик новые типы содержимого, например задачи GitHub и GitLab, GIF-анимации Giphy и другие. Какие интеграции доступны на вашем сервере, узнайте у администратора.

Ответы на сообщения и другие действия

Ответить на сообщение можно стрелкой, которая появляется при наведении на него курсора.

В меню ... можно также ответить лично — откроется обсуждение один на один.

Здесь же можно создать прямую ссылку на сообщение или пометить его непрочитанным, чтобы при следующем входе в чат прокрутка вернулась к нему. Если сообщение — файл, его можно открыть в приложении «Файлы».

Беззвучные сообщения

Если не хочется тревожить никого посреди ночи, в чате есть беззвучный режим. Пока он включён, другие участники не получают уведомлений о ваших сообщениях.

Планирование сообщений

Если сообщение нужно отправить не сразу, а в определённое время, его можно запланировать: выберите дату и время в быстрых действиях рядом с полем ввода.

Все запланированные сообщения находятся за значком часов рядом с полем ввода. Там их можно изменить, перенести или удалить.

Сводка чата

Если включён Помощник, для обсуждения можно создать сводку, когда в нём больше 100 непрочитанных сообщений. Для этого нажмите кнопку над первым непрочитанным сообщением.
