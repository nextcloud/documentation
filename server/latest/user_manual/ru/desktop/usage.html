Использование клиента

Клиент Nextcloud для ПК работает в фоне. Открыть его настройки можно из области уведомлений в Windows и Linux или из строки меню в macOS.

Добавить учётную запись

Чтобы подключить ещё одну учётную запись Nextcloud, откройте диалоговое окно настроек и нажмите Добавить учётную запись в боковой панели. Введите адрес, по которому открывается сервер Nextcloud в браузере, затем нажмите Войти.

Если в сети требуется прокси-сервер, перед входом нажмите Настройки прокси-сервера. Выберите системный прокси-сервер или укажите настройки прокси вручную, затем нажмите Готово.

Если защищённое подключение не удаётся установить, проверьте адрес сервера и обратитесь к администратору сервера. Мастер может предложить подключиться без TLS или использовать сертификат клиента. Выбирайте Использовать клиентский сертификат, только если сервер его требует.

Если запрашивается сертификат клиента, выберите файл PKCS#12, предоставленный администратором, введите его пароль и нажмите Подключиться.

Мастер предложит перейти в браузер. Если браузер не открывается автоматически, нажмите Открыть. Войдите и предоставьте клиенту для ПК доступ, когда появится запрос. Затем вернитесь в мастер.

Выберите способ синхронизации файлов. При классической синхронизации выберите Синхронизировать всё или Выбрать, что синхронизировать. Чтобы изменить место хранения файлов, нажмите Выбрать рядом с Локальная папка синхронизации, затем нажмите Готово.

Можно выбрать Поставщик файлов, чтобы скачивать файлы по запросу. Чтобы завершить добавление учётной записи, нажмите Готово. В macOS подробности об интеграции с Finder см. в Использование File Provider в macOS.

Перед завершением классической синхронизации нажмите Дополнительно, если требуется подтверждение перед синхронизацией больших папок или внешнего хранилища. Задайте нужные параметры в Дополнительных параметрах, затем нажмите Готово, чтобы вернуться в мастер.

Диалоговое окно настроек

Выберите учётную запись в боковой панели, чтобы увидеть состояние синхронизации, локальную папку, использование хранилища и настройки подключения. Чтобы настроить ещё одну папку классической синхронизации для этой учётной записи, нажмите Добавить папку для синхронизации. Выйти из учётной записи или удалить её можно на той же странице.

В разделе Основные выберите, запускать ли клиент при запуске системы, использовать монохромные значки и показывать уведомления. В macOS также можно включить «Поставщик файлов» для всех учётных записей. Эта настройка заменяет классические папки синхронизации и их интеграцию с Finder.

В разделе Дополнительно задайте пороги подтверждения для больших папок и внешнего хранилища. Здесь же можно изменить интервал опроса сервера, выбрать, попадают ли удалённые файлы в корзину, отредактировать игнорируемые файлы или создать архив отладки.

Чтобы исключить файлы или папки из синхронизации, нажмите Список исключений синхронизации… в разделе Дополнительно. Добавьте шаблон для каждого элемента, который нужно игнорировать. Звёздочка (*) соответствует любому числу символов, вопросительный знак (?) — одному символу, а завершающая косая черта (/) ограничивает шаблон папками. Выбирайте Разрешить удаление только для игнорируемых элементов, которые клиент может удалить, если они мешают удалению папки. Чтобы сохранить, нажмите OK.

В разделе Сведения можно узнать версию клиента для ПК и открыть документацию по использованию или правовую информацию.

Значок в области уведомлений

Клиент для ПК показывает значок состояния в области уведомлений в Windows и Linux или в строке меню в macOS. Для одних и тех же состояний синхронизации доступны цветные значки состояния, а также цветные или монохромные значки в области уведомлений. Монохромные значки можно выбрать в разделе Основные диалогового окна настроек.

Откройте значок в области уведомлений или в строке меню, чтобы увидеть клиент и доступные действия, например приостановку или возобновление синхронизации.

Значки наложения в файловом менеджере

Для классических папок синхронизации клиент для ПК добавляет к файлам в файловом менеджере значки наложения. Зелёная галочка означает, что файл актуален. Значок предупреждения может означать, что файл игнорируется; красный крестик указывает на ошибку синхронизации. Синий значок указывает на файл, ожидающий синхронизации или синхронизируемый в данный момент. Когда клиент не в сети, значки наложения для текущего состояния синхронизации папки не показываются.

Значок наложения папки отражает ошибки синхронизации в её содержимом. Игнорируемые файлы не изменяют состояние родительской папки. В macOS «Поставщик файлов» использует стандартные индикаторы состояния Finder, описанные в Использование File Provider в macOS.

Общий доступ

Клиент для ПК встраивает действия общего доступа в Finder в macOS и в Проводник Windows. В Linux установите пакет интеграции для файлового менеджера, например nautilus-nextcloud или dolphin-nextcloud.

В файловом менеджере щёлкните правой кнопкой мыши по файлу, в контекстном меню откройте Nextcloud и нажмите Параметры общего доступа, чтобы открыть диалог «Поделиться».

Чтобы поделиться файлом с людьми или группами, используйте Поиск получателей. Существующие общие ресурсы и ссылки общего доступа показываются под полем поиска. Чтобы скопировать внутреннюю ссылку или ссылку общего доступа, используйте кнопку копирования. Чтобы изменить общий ресурс, используйте меню с тремя точками, а чтобы удалить его — кнопку X.

При редактировании общего ресурса выберите разрешение получателя в раскрывающемся списке. Также можно добавить примечание для получателей. Изменения применяются сразу.

Чтобы задать срок действия или защитить общий ресурс паролем, откройте Настройки общего доступа кнопкой с шестерёнкой. Изменения применяются сразу.
