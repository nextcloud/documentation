Использование File Provider в macOS

В macOS наш клиент также может органично встраивать файлы Nextcloud в систему как расширение поставщика файлов. Для любой вновь настроенной учётной записи Nextcloud интеграция включена по умолчанию.

Поддерживаемые возможности

  • Доступность файлов и целых папок офлайн

  • Освобождение места на локальном диске за счёт вытеснения локальных копий без удаления самих элементов

  • Интеллектуальное автоматическое удаление локальных данных

  • Предпросмотр в Finder файлов, которые ещё не скачаны

  • Поддержка форматов, специфичных для Apple, например пакетов Pages, Numbers или Keynote

  • Поддержка блокировки файлов на стороне сервера (если её поддерживает сервер, к которому выполнено подключение)

  • Поддержка функции «Редактировать локально»

  • Предоставление общего доступа другим пользователям

  • Серверные действия, встроенные прямо в контекстное меню Finder

  • Автоматическое обнаружение изменений на сервере

Настройка

Параметры расширения File Provider можно менять для каждой учётной записи отдельно в окне настроек клиента Nextcloud для ПК.

Здесь можно включить или отключить интеграцию с Finder.

Если отключить расширение File Provider при наличии несинхронизированных изменений, macOS сохранит несинхронизированные элементы в папке, которая автоматически откроется после отключения интеграции.

Интеграция с Finder

В macOS удалённое хранилище, например учётная запись Nextcloud, показывается как отдельное место на боковой панели Finder. Фактическое расположение содержимого на диске определяет macOS.

Примечание

Чтобы быстрее обнаруживать изменения на стороне сервера, рекомендуется включить на сервере Nextcloud приложение notify_push. Оно будет сообщать клиенту для ПК об изменениях на сервере сразу после их появления, сокращая время до их появления в Finder. Иначе клиенту придётся опрашивать сервер, из-за чего между изменением на сервере и его появлением на устройстве возникнет большая задержка.

Индикаторы состояния синхронизации

Как и для классических папок синхронизации, Finder показывает индикаторы состояния рядом с элементами. В отличие от особых индикаторов в классических папках синхронизации, эти стандартные индикаторы предоставляет macOS, чтобы во всех приложениях облачного хранилища, которыми пользуется человек, внешний вид был единым.

  • Облако со стрелкой вниз: элемент и вложенные в него элементы ещё не скачаны. Их можно скачать при наличии сетевого подключения.

  • Контур облака: элемент в своём текущем локальном состоянии ещё не полностью загружен.

  • Зачёркнутое облако: элемент исключён из синхронизации.

  • Круговая диаграмма: элемент сейчас загружается или скачивается, ход выполнения показан наглядно.

  • Заполненный кружок с булавкой: элемент доступен офлайн и будет храниться локально.

  • Нет значка: элемент доступен офлайн и актуален.

Действия в контекстном меню

Расширение File Provider также добавляет в контекстное меню Finder особые функции Nextcloud.

Хранить загруженным

Файлы и папки можно отметить как «Хранить загруженным», чтобы они постоянно были доступны офлайн. Если это выбрано для папок, то применяется и ко всему их содержимому. Это особенно полезно пользователям с ограниченным доступом к сети или без него: важные файлы всегда доступны, и не нужно беспокоиться о подключении. macOS не освобождает место на локальном диске, вытесняя элементы, отмеченные как «Хранить загруженным», даже если к ним давно не обращались.

Это можно отменить, выбрав «Разрешить автоматическое освобождение места» для тех же элементов.

Чтобы всё в учётной записи всегда было доступно локально, можно выбрать «Всегда хранить загруженным» в корне расположения на боковой панели Finder.

Блокировка

Если сервер поддерживает блокировку файлов, клиент позволяет блокировать и разблокировать файлы вручную в Finder.

Общий доступ

Если сервер поддерживает общий доступ и для элемента он разрешён, из контекстного меню Finder можно создавать новые общие ресурсы и управлять существующими, как в веб-интерфейсе Nextcloud.

Действия с файлами

Если на сервере установлены приложения, добавляющие действия с файлами для выбранных типов файлов, эти действия тоже будут доступны в контекстном меню Finder. Так серверными функциями вашего сервера Nextcloud можно пользоваться прямо из Finder.

Известные проблемы

Конфликт расширений macOS

Из-за технических ограничений macOS, наложенных Apple, интеграция с Finder для классических папок синхронизации не может работать одновременно с включённым расширением File Provider. Это значит, что пока включено расширение File Provider, значки-метки на элементах и пункты контекстного меню для классических папок синхронизации будут недоступны.

Файлы псевдонимов

При первом открытии псевдонима macOS, хранящегося в Nextcloud, на устройстве, где он ещё не был скачан, файл может открыться в текстовом редакторе как двоичный документ, а не перейти к своей цели. Это происходит потому, что macOS решает, как открыть файл, до его загрузки, а у файлов-псевдонимов на сервере нет узнаваемого расширения или сведений о типе: определить их можно только по содержимому. После того как файл один раз открыт или скачан, Nextcloud Desktop запоминает, что это псевдоним, и сохраняет эту информацию локально, поэтому все последующие открытия работают правильно. Чтобы вообще избежать проблемы, перед первым открытием щёлкните файл псевдонима в Finder правой кнопкой мыши и выберите Хранить загруженным.

Редактировать локально

Действие Редактировать локально, предлагаемое веб-интерфейсом Nextcloud, не может открывать файлы, управляемые расширением File Provider. Оно может только показать их в Finder.

Это ограничение самой macOS, а не ошибка клиента. В целях защиты macOS разрешает открывать конкретный файл только определённым приложениям и не позволяет приложению выдать себе это разрешение. Часть клиента, которой разрешено управлять этими файлами, не может запускать другие приложения, а часть, которая могла бы запустить редактор, не может открыть файл.

Предоставление полного доступа к диску не помогает, так как за это отвечает другая часть системы безопасности macOS.

Решение проблем

Ведение журнала уровня отладки

Записи журнала уровня отладки для расширения File Provider по умолчанию отключены. Если нужно сообщить о проблеме с File Provider, их включение поможет получить более подробные сведения о том, что происходит внутри. Чтобы включить их, выполните следующую команду в Терминале:

defaults write com.nextcloud.desktopclient.FileProviderExt debugLoggingEnabled -bool YES

Изменение вступает в силу в течение нескольких секунд; перезапускать расширение или Mac не требуется. После решения исследуемой проблемы рекомендуется восстановить значение по умолчанию, удалив явно заданное значение:

defaults delete com.nextcloud.desktopclient.FileProviderExt debugLoggingEnabled
