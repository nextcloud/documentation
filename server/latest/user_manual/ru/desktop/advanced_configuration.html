Расширенная настройка

Клиент для ПК можно настроить с помощью параметров командной строки, файла nextcloud.cfg и переменных среды. Всё, что доступно в окне Настройки приложения, лучше менять там; на этой странице описаны дополнительные параметры и переопределения. Об отдельной программе для однократного запуска синхронизации см. Клиент командной строки.

Значения по умолчанию, приведённые ниже, относятся к стандартному клиенту Nextcloud. В клиентах с фирменным оформлением, а также из-за возможностей сервера и политик операционной системы некоторые значения по умолчанию могут отличаться. Параметры механизма синхронизации применяются к классической синхронизации, включая виртуальные файлы Windows. Расширение File Provider в macOS само управляет передачей файлов; эти параметры не настраивают его механизм передачи. См. Использование File Provider в macOS.

Параметры командной строки

Запустите клиент для ПК командой nextcloud [options]. Чтобы увидеть параметры в установленной версии, выполните nextcloud --help. Параметры со значением принимают как --option value, так и --option=value.

Перед применением параметров запуска или переменных среды закройте работающий клиент. При запуске ещё одного экземпляра команды могут быть переданы уже работающему процессу вместо запуска нового процесса с указанными переменными среды.

Общие параметры

Параметр

По умолчанию

Описание

--help, -h

Не запрошено

Показать доступные параметры командной строки и выйти.

--version, -v

Не запрошено

Показать сведения о версии и выйти.

--quit, -q

Не запрошено

Завершить работу запущенного клиента для ПК.

--confdir <directory>

Стандартное расположение

Использовать другой каталог конфигурации. Стандартные расположения описаны в Файл конфигурации.

--background

Не задано

Запустить без открытия главного диалогового окна.

--set-language <language>

Из language

Сохранить язык интерфейса и выйти. Например, de — немецкий. Пустое значение восстанавливает язык операционной системы. Чтобы применить, запустите клиент снова.

--overrideserverurl <url>

Не задано

Сохранить overrideServerUrl для следующей настройки учётной записи и выйти. Чтобы открыть мастер настройки, запустите клиент снова.

--overridelocaldir <path>

Не задано

Сохранить overrideLocalDir для следующей настройки учётной записи и выйти.

--forcelegacyconfigimport

Не задано

Принудительно импортировать доступную конфигурацию старого клиента. Доступно только в сборках с поддержкой переноса учётных записей.

--reverse

Обычное направление

Изменить направление компоновки интерфейса на обратное для этого запуска.

Параметры журналирования

Параметр

По умолчанию

Описание

--logwindow, -l

Не задано

Открыть окно вывода журнала.

--logfile <filename>

Не задано

Записывать журналы в этот файл. Чтобы выводить в стандартный поток вывода, используйте -. Имеет приоритет над --logdir.

--logdir <directory>

Из logDir

Записывать файлы журнала с ротацией в этот каталог.

--logexpire <hours>

Из logExpire

Задаёт срок хранения журналов с ротацией. Положительное значение переопределяет logExpire; ноль или отрицательное значение — использовать параметр из конфигурации.

--logflush

Из logFlush

Сбрасывать журнал после каждой записи, чтобы последние сообщения были доступны сразу.

--logdebug

Из logDebug

Включает отладочные сообщения в категориях журнала Nextcloud. При этом включаются не все отладочные категории Qt.

--debug

Не задано

Также включает отладочный журнал. При сборе диагностических журналов предпочтительнее --logdebug.

Например, сбор отладочного вывода в файл в Linux:

nextcloud --logdebug --logflush --logfile "$HOME/nextcloud-debug.log"

Постоянные параметры ведения журнала описаны в разделе Раздел [General].

Параметры настройки учётной записи

Эти параметры создают и сохраняют учётную запись, после чего завершают работу. Чтобы использовать учётную запись, снова запустите клиент для ПК.

Параметр

По умолчанию

Описание

--userid <user>

Обязательно

ID пользователя для создаваемой учётной записи.

--serverurl <url>

Обязательно

Базовый URL сервера Nextcloud, например https://cloud.example.com.

--apppassword <password>

Не задано

Пароль приложения для учётной записи. Если не указан, учётная запись сохраняется, а войти в неё нужно будет позже в клиенте для ПК.

--localdirpath <path>

Предлагаемая папка

Локальная папка синхронизации. Если не указана, используется папка, предложенная мастером настройки. Существующая папка должна быть пустой. Игнорируется, если включён режим File Provider в macOS.

--remotedirpath <path>

/

Удалённая папка для нового подключения классической синхронизации. Применяется при создании локальной папки синхронизации.

--isvfsenabled <0|1>

0

Укажите 1, чтобы запросить виртуальные файлы для новой папки классической синхронизации, если это поддерживается, или 0, чтобы скачивать файлы. Режим File Provider в macOS при этом не включается.

Например, создайте учётную запись, а затем войдите в неё в клиенте для ПК:

nextcloud --userid carla --serverurl https://cloud.example.com --localdirpath "$HOME/Nextcloud"

Файл конфигурации

Клиент хранит свои настройки в файле nextcloud.cfg в формате INI. Перед изменением файла закройте клиент и создайте его резервную копию, затем снова запустите клиент. Изменения, сделанные в окне Настройки приложения, могут перезаписать соответствующие значения в файле.

Стандартные расположения:

  • Linux: $HOME/.config/Nextcloud/nextcloud.cfg. Если задана переменная XDG_CONFIG_HOME, используйте $XDG_CONFIG_HOME/Nextcloud/nextcloud.cfg.

  • Windows: %APPDATA%\Nextcloud\nextcloud.cfg.

  • macOS, клиент 33.0.0 и более поздних версий: $HOME/Library/Containers/com.nextcloud.desktopclient/Data/Library/Preferences/Nextcloud/nextcloud.cfg.

  • Более старые клиенты macOS: $HOME/Library/Preferences/Nextcloud/nextcloud.cfg.

--confdir переопределяет каталог конфигурации. Клиенты с фирменным оформлением могут использовать другой каталог и имя файла. В Citrix и других средах с перемещаемыми профилями сохраняйте конфигурацию пользователя между сеансами, чтобы настройка учётной записи не сбрасывалась.

В таблицах указан раздел INI для каждого параметра. Например:

[Nextcloud]
remotePollInterval=30000

[General]
logDebug=true
logExpire=48

Идентификаторы учётных записей, учётные данные, состояние папок синхронизации, геометрия окна, кеши, маркеры миграции и состояние средства обновления управляются клиентом. Чтобы изменить эти значения, используйте мастер настройки и окно Настройки.

Приоритет зависит от параметра. Перечисленные ниже переопределения с помощью переменных среды применяются только к соответствующим параметрам. Для skipUpdateCheck и autoUpdateCheck значение в [General] имеет приоритет над [Nextcloud]. В Windows политики администратора могут переопределять эти параметры обновления, а также параметры размера папки и внешнего хранилища. Подробнее о политиках обновления см. Как отключить автоматическое обновление в Windows.

Раздел [Nextcloud]

Параметр

По умолчанию

Описание

remotePollInterval

30000 мс

Интервал опроса сервера на предмет изменений. Значения меньше 5000 мс приводятся к 30000 мс. Уведомления с сервера могут снизить потребность в опросе.

forceSyncInterval

7200000 мс

Запускать синхронизацию по истечении этого времени после последней синхронизации (2 часа). Значения меньше remotePollInterval увеличиваются до этого интервала.

fullLocalDiscoveryInterval

3600000 мс

По истечении этого интервала (1 час) следующая подходящая синхронизация полностью сканирует локальную файловую систему. Чтобы отключить периодическое полное сканирование, укажите -1. Переопределяется переменной OWNCLOUD_FULL_LOCAL_DISCOVERY_INTERVAL.

notificationRefreshInterval

60000 мс

Интервал опроса уведомлений сервера. Значения меньше 60000 мс увеличиваются до 60000 мс.

skipUpdateCheck

false

Отключает проверку обновлений и скрывает интерфейс обновления.

autoUpdateCheck

true

Включает автоматическую проверку обновлений, если skipUpdateCheck имеет значение false.

updateCheckInterval

36000000 мс

Интервал автоматической проверки обновлений (по умолчанию 10 часов). Значения меньше 300000 мс (5 минут) увеличиваются до этого минимума.

Раздел [General]

Синхронизация и передачи

Параметр

По умолчанию

Описание

chunkSize

104857600 байт

Начальный размер фрагмента при загрузке (100 МиБ). Клиент может изменять его во время загрузки. Возможности сервера могут его заменить; OWNCLOUD_CHUNK_SIZE переопределяет итоговое значение.

minChunkSize

5242880 байт

Минимальный настраиваемый размер фрагмента при загрузке (5 МиБ). Механизм синхронизации изначально ограничивает его диапазоном от 5 МБ до 5 ГБ. Переопределяется переменной OWNCLOUD_MIN_CHUNK_SIZE.

maxChunkSize

104857600 байт

Максимальный настраиваемый размер фрагмента при загрузке (100 МиБ). Максимум, заданный сервером, имеет приоритет. OWNCLOUD_MAX_CHUNK_SIZE переопределяет итоговое значение.

timeout

300 секунд

Время ожидания бездействия сети по умолчанию. Активность сбрасывает таймер, а отдельные запросы могут использовать другое время ожидания. Ненулевое значение OWNCLOUD_TIMEOUT переопределяет его.

promptDeleteAllFiles

false

Запрашивать подтверждение, когда все файлы определены как удалённые или когда число удалённых файлов превышает deleteFilesThreshold. Применяется к классической синхронизации в клиенте для ПК; nextcloudcmd этот запрос не показывает.

deleteFilesThreshold

100 файлов

Число удалённых файлов, при превышении которого promptDeleteAllFiles запрашивает подтверждение. Не действует, если этот параметр не включён.

moveToTrash

false

Перемещать файлы, удалённые на сервере, в локальную корзину вместо безвозвратного удаления, если локальная файловая система это поддерживает.

newBigFolderSizeLimit

500 МБ

Размер, при превышении которого новая удалённая папка требует подтверждения перед скачиванием. Используется, когда useNewBigFolderSizeLimit имеет значение true; отрицательное значение отключает ограничение. Не применяется к папкам с виртуальными файлами.

useNewBigFolderSizeLimit

true

Включить ограничение размера папки для запроса подтверждения.

confirmExternalStorage

true

Запрашивать подтверждение перед синхронизацией новых обнаруженных папок внешнего хранилища.

notifyExistingFoldersOverLimit

false

Уведомлять, когда существующая синхронизируемая папка превышает действующее ограничение размера. Требуется, чтобы это ограничение было включено, а виртуальные файлы отключены.

stopSyncingExistingFoldersOverLimit

Из notifyExistingFoldersOverLimit

Также прекращать синхронизацию таких папок, пока не будет выбрано продолжать их синхронизацию. Требуется включить notifyExistingFoldersOverLimit и ограничение размера папки.

Для классической синхронизации на ПК клиент применяет параметры фрагментов из файла конфигурации, затем возможности сервера, затем переопределения из переменных среды. После этого минимальное и максимальное значения корректируются с учётом начального размера фрагмента. Параметр конфигурации targetChunkUploadDuration механизмом синхронизации не используется; вместо него применяйте OWNCLOUD_TARGET_CHUNK_UPLOAD_DURATION. forceLoginV2 клиентом больше не читается.

По умолчанию

Описание

showExperimentalOptions

false

Показывать экспериментальные параметры в интерфейсе. Сам по себе этот параметр не включает экспериментальные возможности.

Показывать главное диалоговое окно как обычное окно, даже когда доступен значок в области уведомлений.

optionalServerNotifications

true

Показывать дополнительные уведомления сервера. Также применяются отдельные параметры уведомлений, приведённые ниже.

showChatNotifications

true

Показывать уведомления чата, когда включены дополнительные уведомления сервера.

showCallNotifications

true

Показывать уведомления о вызовах, когда включены дополнительные уведомления сервера.

showQuotaWarningNotifications

true

Показывать предупреждения о квоте, когда включены дополнительные уведомления сервера.

showInExplorerNavigationPane

Зависит от платформы

Показывать папки синхронизации в панели навигации Проводника Windows. По умолчанию — true в Windows 10 и более поздних версиях и false на других платформах.

launchOnSystemStartup

true

Хранить параметр автозапуска. Изменяйте его в окне Настройки, чтобы обновлялась и регистрация автозапуска в операционной системе.

language

Пусто

Код языка интерфейса, например de. Пустое значение — использовать язык операционной системы.

updateChannel

Зависит от сборки и сервера

Выбор поддерживаемого канала обновлений. Недопустимые значения игнорируются. В клиентах с фирменным оформлением и при наличии подписки на сервере выбор может быть ограничен. См. Каналы обновлений.

showConfigBackupWarning

false

Показывать уведомление со списком резервных копий конфигурации, созданных при запуске.
Журналирование

Параметр

По умолчанию

Описание

logToTemporaryLogDir

false

Использовать временный каталог журналов, если вывод журналов ещё не направлен в файл или стандартный поток вывода. Также включает отладочное журналирование и устанавливает срок хранения журналов в 4 часа.

logDir

<config path>/logs

Каталог для файлов журнала с ротацией. Переопределяется параметром --logdir; --logfile вместо этого выбирает файл или стандартный поток вывода.

logDebug

false

Включить отладочное журналирование Nextcloud. Параметр --logdebug также включает его.

logExpire

24 часа

Срок хранения ротируемых журналов. Значение 0 отключает удаление по возрасту. Положительное значение --logexpire переопределяет этот параметр.

logFlush

false

Сбрасывать журнал после каждой записи. --logflush также включает сброс.

В сборках для разработки и отладки можно включить отладочный журнал и немедленный сброс независимо от этих значений по умолчанию.

Значения по умолчанию при настройке учётной записи

Параметр

По умолчанию

Описание

overrideServerUrl

Пусто

Принудительно задать адрес сервера при следующей настройке учётной записи и автоматически начать вход. Очищается после успешного завершения работы мастера настройки. Можно также задать с помощью --overrideserverurl.

overrideLocalDir

Пусто

Предлагаемая локальная папка для настройки учётной записи. Очищается после успешного завершения работы мастера настройки. Можно также задать с помощью --overridelocaldir.

isVfsEnabled

false

Параметр виртуальных файлов, используемый вместе с overrideServerUrl при настройке. Не преобразует существующие папки синхронизации и не включает режим File Provider в macOS.

Сетевые параметры учётной записи

По возможности используйте сетевые параметры учётной записи в приложении. Приведённые ниже значения относятся к существующей группе учётной записи в разделе [Accounts]. В INI-файле они указываются с префиксом ID учётной записи, например 0\networkProxyType=0 для учётной записи 0. Используйте ID учётной записи, уже присутствующий в файле. Пароли прокси хранятся в системном хранилище ключей.

Параметр

По умолчанию

Описание

networkProxyType

0, если отсутствует

0 — системный прокси; 1 — прокси SOCKS5; 2 — без прокси; 3 — прокси HTTP. При настройке или переносе учётной записи может быть сохранено другое значение.

networkProxyHostName

Пусто

Переменные среды

Задайте переменные среды перед запуском клиента. Переменная, заданная в терминале, действует на процессы, запущенные из этого терминала; уже работающий клиент или клиент, запущенный из среды рабочего стола, не наследует её автоматически. Например, чтобы временно изменить время ожидания бездействия сети в Linux:

OWNCLOUD_TIMEOUT=600 nextcloud

Клиент Nextcloud по-прежнему использует исторический префикс OWNCLOUD_. Следуйте формату значений, указанному в каждом описании: одни переключатели требуют 0 или 1, другие реагируют на любое непустое значение, включая 0. Default описывает поведение, когда переменная не задана.

Параметры передачи

Переопределения размера фрагмента и числа параллельных заданий применяются после значений конфигурации и возможностей сервера в классической синхронизации клиента для ПК. nextcloudcmd также читает эти переменные, но исходит из значений по умолчанию своего механизма синхронизации, а не из конфигурации фрагментов клиента для ПК.

Параметр

По умолчанию

Описание

OWNCLOUD_CHUNK_SIZE

Итоговый размер фрагмента

Начальный размер фрагмента в байтах. Синхронизация клиента для ПК исходит из chunkSize или размера, предоставленного сервером. В nextcloudcmd по умолчанию используется 104857600 байт (100 МиБ).

OWNCLOUD_MIN_CHUNK_SIZE

Итоговый минимум

Минимальный размер фрагмента в байтах. Синхронизация клиента для ПК исходит из minChunkSize; в nextcloudcmd по умолчанию используется 5000000 байт (5 МБ).

OWNCLOUD_MAX_CHUNK_SIZE

Итоговый максимум

Максимальный размер фрагмента в байтах. Синхронизация клиента для ПК исходит из maxChunkSize или максимума, предоставленного сервером; в nextcloudcmd по умолчанию используется 5000000000 байт (5 ГБ).

OWNCLOUD_TARGET_CHUNK_UPLOAD_DURATION

60000 мс

Целевая длительность для динамического выбора размера фрагмента (1 минута). Чтобы отключить динамический выбор размера, укажите 0. Одноимённый параметр в файле конфигурации не действует.

OWNCLOUD_MAX_PARALLEL

Зависит от сервера и протокола

Положительное максимальное число параллельных заданий синхронизации. Клиент для ПК использует значение, предоставленное сервером, если оно доступно; иначе используется 20 для HTTP/2 или 6 для HTTP/1. По умолчанию nextcloudcmd использует 6. Это не число одновременных передач файлов.

OWNCLOUD_TIMEOUT

timeout или 300 секунд

Время ожидания бездействия сети. Ненулевое целое число переопределяет timeout в клиенте для ПК. По умолчанию nextcloudcmd использует 300 секунд. Нулевое или недопустимое значение заменяется обычным значением по умолчанию.

OWNCLOUD_HTTP2_ENABLED

Отключено

Установите 1, чтобы разрешить HTTP/2 для запросов HTTPS. Другие значения отключают его. Фактическое использование по-прежнему зависит от сервера и сетевого подключения.

OWNCLOUD_CHUNKING_NG

Возможность сервера

Установите 0, чтобы отключить новый протокол загрузки по частям, или 1, чтобы принудительно его включить. Другие значения используют возможность сервера. Принудительно включайте его, только если сервер его поддерживает.

NEXTCLOUD_BULK_UPLOAD

Возможность сервера

Установите 0, чтобы отключить массовую загрузку, или 1, чтобы принудительно её включить. Другие значения используют возможность сервера. Принудительно включайте её, только если сервер её поддерживает.

OWNCLOUD_PARALLEL_CHUNK

Зависит от сервера

Только для старого способа загрузки по частям: 0 или false отключает параллельную загрузку фрагментов. Другие непустые значения включают её, если сервер её не отключает.

OWNCLOUD_LAZYOPS

Отключено

Ненулевое целое число добавляет заголовок OC-LazyOps: true к запросам загрузки. Его действие зависит от поддержки сервера.

Размеры фрагментов должны быть положительными. Клиент корректирует минимум и максимум так, чтобы в этот диапазон входил начальный размер фрагмента. Анализатор переменных среды принимает для трёх переопределений размера фрагмента беззнаковые 32-битные значения в байтах, поэтому не используйте для этих переменных значения выше 4294967295 байт.

Синхронизация и дисковое пространство

Параметр

По умолчанию

Описание

OWNCLOUD_FULL_LOCAL_DISCOVERY_INTERVAL

fullLocalDiscoveryInterval

Только для классической синхронизации на ПК. Переопределяет интервал полного локального сканирования в миллисекундах. Чтобы отключить периодическое полное сканирование, укажите -1.

OWNCLOUD_CRITICAL_FREE_SPACE_BYTES

512000000 байт

Прерывать синхронизацию папки, если оставшееся локальное пространство ниже этого порога (512 МБ). Значение ограничено диапазоном от нуля до OWNCLOUD_FREE_SPACE_BYTES.

OWNCLOUD_FREE_SPACE_BYTES

1000000000 байт

Пропускать или прерывать скачивание, если после него останется меньше указанного объёма свободного локального пространства (1 ГБ). Остальная синхронизация может продолжаться.

OWNCLOUD_BLACKLIST_TIME_MIN

25 секунд

Минимальная задержка повторной попытки для файлов, которые не удалось синхронизировать. Значения меньше 25 увеличиваются до 25.

OWNCLOUD_BLACKLIST_TIME_MAX

86400 секунд

Максимальная задержка повторной попытки для файлов, которые не удалось синхронизировать (1 день). Только положительные значения переопределяют значение по умолчанию.

OWNCLOUD_UPLOAD_CONFLICT_FILES

Возможность сервера

Установите 1, чтобы загружать конфликтные копии, или 0, чтобы запретить их загрузку. Непустое значение переопределяет параметр сервера. См. Конфликты.

Скачивания, пропущенные из-за порога свободного пространства, повторяются при последующих запусках синхронизации. Критический порог останавливает синхронизацию всей папки. Эти ограничения не зависят от квоты хранилища на сервере.

Контрольные суммы

Параметр

По умолчанию

Описание

OWNCLOUD_CONTENT_CHECKSUM_TYPE

Предпочтение сервера, затем SHA1

Переопределяет предпочитаемый алгоритм контрольной суммы при загрузке. Выберите алгоритм, поддерживаемый и клиентом, и сервером.

OWNCLOUD_DISABLE_CHECKSUM_UPLOAD

Не задано

Любое непустое значение отключает отправку контрольных сумм при загрузке. Чтобы вернуть обычную отправку контрольных сумм, сбросьте переменную.

OWNCLOUD_DISABLE_CHECKSUM_COMPUTATIONS

Не задано

Любое непустое значение отключает синхронное вычисление контрольных сумм. Пути загрузки и скачивания, использующие асинхронные вычисления, продолжают работать.

Используйте переопределения контрольных сумм только при диагностике конкретной проблемы совместимости; отключение контрольных сумм сокращает проверки целостности, выполняемые при синхронизации.

Решение проблем

Параметр

По умолчанию

Описание

OWNCLOUD_SQLITE_JOURNAL_MODE

WAL или DELETE

Переопределяет режим базы данных журнала синхронизации. Обычно WAL; DELETE — в файловых системах FAT в Windows и на путях синхронизации macOS в /Volumes/. Изменяйте только при диагностике проблемы совместимости базы данных.

OWNCLOUD_SQLITE_LOCKING_MODE

EXCLUSIVE

Переопределяет режим блокировки SQLite для базы данных журнала синхронизации.

OWNCLOUD_SQLITE_TEMP_STORE

По умолчанию в SQLite

Переопределяет параметр SQLite temp_store для базы данных журнала синхронизации.

OWNCLOUD_CORE_DUMP

Не задано

В системах Unix любое непустое значение запрашивает неограниченный размер дампа памяти для клиента для ПК. Ограничения операционной системы при этом сохраняются.

QT_LOGGING_RULES

Параметры журналирования Qt по умолчанию

Задайте фильтры категорий журналирования, например nextcloud.*.debug=true. Эта переменная Qt также позволяет выбирать отдельные категории.

Учётные данные для nextcloudcmd описаны в разделе Обработка учётных данных. Его переменные NC_USER и NC_PASSWORD не настраивают учётные записи в клиенте для ПК.
