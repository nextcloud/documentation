Начало работы

«Коллективы» — это пространство для совместных заметок и совместной работы в Интернете. Вместе с коллегами можно писать документы и структурировать общие знания. Можно даже встраивать доски задач, интерактивные доски и календари. Приложение «Коллективы» делает ставку на горизонтальные и неиерархические рабочие процессы.

Зачем нужны «Коллективы»?

  • Нужен инструмент для совместной работы, взаимодействия и организации с другими людьми.

  • Хочется, чтобы все общие знания были в одном месте.

  • Хочется иметь быстрый и удобный обзор страниц и вложенных страниц.

  • Хочется поделиться частью знаний с внешними людьми.

  • Nextcloud уже используется.

Первые шаги

Создайте первый коллектив с двумя страницами и ссылкой с одной на другую. Предполагается, что «Коллективы» открыты в браузере на ПК (то есть не на мобильном устройстве).

  1. Выберите приложение «Коллективы» в меню приложений сверху:

  2. Нажмите «Создать коллектив».

  3. Введите название My first collective и выберите эмодзи (или оставьте предложенный).

  4. Выберите «Создать без участников». Как добавлять других участников, расскажем позже.

  5. В списке страниц слева нажмите кнопку ➕ рядом с главной страницей. Поздравляем, первая страница в коллективе создана. 🎉

  6. Чтобы задать название страницы, введите My first page.

  7. Теперь нажмите Enter — курсор переместится в содержимое страницы (пока пустое).

  8. Введите ## My first heading, чтобы вставить заголовок второго уровня. Или откройте меню заголовков на панели инструментов редактора, выберите «Заголовок 2» и введите My first heading. Оказывается, форматировать текст можно несколькими способами 🎉

  9. Чтобы создать вложенную страницу «My first page», нажмите кнопку ➕ рядом с «My first page» на боковой панели страниц. Кнопка появляется, только когда указатель мыши наведён на запись в списке страниц.

  10. Задайте вложенной странице заголовок, введя «My subpage».

  11. Чтобы добавить ссылку на первую страницу, откройте меню ссылок 🔗 на панели инструментов редактора и выберите «Ссылка на страницу». Откроется диалоговое окно выбора страницы. Введите first в поле поиска, и появится «My first page». Нажмите на неё, и она добавится на вложенную страницу в виде предварительного просмотра ссылки.

Поздравляем, вы освоили две важные основы работы с приложением «Коллективы»: создание страниц и ссылок между ними, а также форматирование содержимого страницы.
