Помощник ИИ

Помощник ИИ Nextcloud предоставляет доступ к инструментам на основе ИИ прямо из веб-интерфейса. Можно выполнять такие задачи, как обобщение текста, генерация изображений и распознавание речи, обмениваться сообщениями с подключённой языковой моделью и вставлять созданное ИИ содержимое в документы и сообщения с помощью умного подборщика.

Примечание

Для работы помощника ИИ администратор должен установить и настроить хотя бы одно приложение с ИИ-модулем. Подробнее см. в документации по администрированию помощника ИИ.

Личные параметры

Параметры помощника находятся на странице Личные параметры в разделе Искусственный интеллект. Там можно убрать пункт помощника из верхнего меню, включить или отключить умные подборщики ИИ и изменить название папки, в которую помощник сохраняет результаты.

Место сохранения созданного содержимого

Создаваемое помощником содержимое, например изображения и результат распознавания речи, сохраняется в папку в приложении «Файлы». Она называется Assistant, если администратор не задал для сервера другое имя.

Своё имя для неё можно задать в поле Папка данных в личных параметрах помощника. Оставьте поле пустым, чтобы сохранить имя, заданное администратором; подсказка в поле показывает это имя.

Примечание

Изменение имени не переименовывает и не перемещает уже существующую папку. Оно применяется при следующем создании папки, поэтому всё, созданное до изменения, остаётся на месте.

Выполнение задачи

Чтобы открыть помощника, нажмите значок помощника на панели навигации справа вверху.

Выберите тип задачи в верхней части панели помощника, заполните форму входных данных и нажмите кнопку отправки в правом нижнем углу.

Задача будет выполнена сразу, если это возможно, или запланирована на более позднее время.

Уведомления

Если задача была запланирована, можно запросить уведомление о её завершении. Чтобы увидеть результат задачи, нажмите кнопку Просмотреть результаты в уведомлении.

История задач

На левой панели помощника показывается список истории задач, отфильтрованный по выбранному типу задачи. Из этого списка можно перезапустить, удалить или отменить предыдущие задачи.

Чат с ИИ

Вкладка Чат с ИИ в помощнике позволяет вести диалог с подключённым ИИ. Введите сообщение в текстовое поле внизу и нажмите Enter, чтобы отправить. Чтобы начать отдельное обсуждение, нажмите Новое обсуждение.

У каждого обсуждения свой контекст. Включите переключатель Запомнить это в обсуждении, чтобы добавить его в долговременную память ИИ — тогда его контекст будет доступен в любом будущем обсуждении. Отключите переключатель, чтобы удалить обсуждение из памяти.

В разделе Помощник ИИ личных параметров можно просмотреть все запомненные обсуждения.

Умные подборщики

Приложение «Помощник» предоставляет три умных подборщика, доступных в «Конференциях», в редакторе «Текст» и в любом другом месте, где доступно редактирование форматированного текста. Введите /, а затем ai, чтобы увидеть отфильтрованный список поставщиков.

Контекстный агент

Если администратор установит приложение Контекстный агент, помощник ИИ автоматически получит возможность взаимодействовать с приложениями Nextcloud. Дополнительная настройка не требуется: инструменты агента становятся доступны в том же интерфейсе Чат с ИИ, описанном выше.

Если контекстный агент включён, можно попросить помощника выполнять действия в Nextcloud, вводя инструкции на естественном языке в чате. Для выполнения запросов помощник в фоновом режиме использует «инструменты».

Примечание

Доступные инструменты зависят от того, какие приложения установлены на сервере Nextcloud и какие группы инструментов включил администратор. Некоторые примеры ниже требуют определённых приложений, таких как «Карточки», «Конференции» или «Почта».

Примеры запросов

Ниже приведены примеры того, что можно попросить помощника сделать. Объедините несколько инструкций в одном сообщении — агент автоматически выстроит цепочку нужных инструментов.

Инструменты искусственного интеллекта

  • Задать вопрос чату по контексту (требуется Чат по контексту)

    • Пример запроса: «Каков процесс оформления больничного в компании?»

  • Расшифровать медиафайл (требуется включённый тип задачи «Расшифровать аудио»)

    • Пример запроса: «Можешь расшифровать следующий файл? https://mycloud.com/f/9825679» (можно выбрать с помощью умного подборщика).

  • Сгенерировать документы (требуется Nextcloud Office)

    • Пример запроса: «Можешь сгенерировать набор слайдов для моей презентации о кошках?»

    • Пример запроса: «Можешь сгенерировать электронную таблицу с правдоподобными числами по странам и их населению?»

    • Пример запроса: «Можешь сгенерировать PDF с планом того, что стоит посмотреть в Берлине?»

  • Сгенерировать изображения (требуется включённый тип задачи «Генерация изображений»)

    • Пример запроса: «Можешь сгенерировать изображение — мультяшный рисунок римского солдата, печатающего что-то на ноутбуке?»

Инструменты для календаря

  • Показать календари пользователя

    • Пример запроса: «Покажи мои календари»

  • Запланировать событие в календаре пользователя

    • Пример запроса: «Запланируй событие с Andrew завтра в полдень».

  • Найти свободное время в календарях пользователей

    • Пример запроса: «Найди свободный интервал на 1 час для встречи со мной и Marco на следующей неделе».

Инструменты для задач

  • Создать задачу

    • Пример запроса: «Создай задачу по покупке продуктов со сроком выполнения завтра».

  • Показать список задач

    • Пример запроса: «Покажи мои незавершённые задачи»

  • Завершить задачу

    • Пример запроса: «Отметь задачу по покупке продуктов как выполненную».

  • Обновить сведения о задаче

    • Пример запроса: «Измени приоритет задачи по покупке продуктов на самый высокий».

    • Пример запроса: «Измени срок выполнения моей задачи по рабочему отчёту на начало следующей недели».

  • Удалить задачу

    • Пример запроса: «Удали задачу по покупке продуктов из моих задач».

    • Пример запроса: «Кто поставил реакцию на последнее сообщение Andrew в нашем обсуждении?»

  • Создать опрос в обсуждении

    • Пример запроса: «Создай опрос в обсуждении „Team standup“ с вопросом „Какой день подходит для выездного мероприятия?“ и вариантами: понедельник, вторник, среда»

  • Получить вопрос, варианты ответа и текущие результаты опроса в обсуждении

    • Пример запроса: «Покажи текущие результаты опроса о выездном мероприятии в обсуждении „Team standup“»

  • Проголосовать в опросе в обсуждении

    • Пример запроса: «Проголосуй за вторник в опросе о выездном мероприятии в обсуждении „Team standup“»

  • Закрыть опрос в обсуждении

    • Пример запроса: «Закрой опрос о выездном мероприятии в обсуждении „Team standup“»

  • Отправить элемент из приложения «Файлы» в обсуждение

    • Пример запроса: «Отправь файл „Q3 plan.pdf“ в моё обсуждение с Andrew»

  • Показать элементы заданного типа (например, файлы, местоположения, опросы), которыми поделились в обсуждении

    • Пример запроса: «Перечисли файлы, которыми поделились в моём обсуждении с Andrew»

  • Получить обзор элементов всех типов, которыми поделились в обсуждении

    • Пример запроса: «Покажи, чем поделились в моём обсуждении с Andrew»

Инструменты приложения «Почта» (требуется Почта)

  • Отправить письмо через приложение «Почта»

    • Пример запроса: «Отправь тестовое письмо с моей учётной записи carry@company.com на Andrew@company.com»

  • Показать все подключённые учётные записи почты

    • Пример запроса: «Покажи мои учётные записи почты»

  • Показать все папки почты учётной записи

    • Пример запроса: «Покажи папки моей учётной записи carry@company.com»

  • Показать письма в папке почты

    • Пример запроса: «Покажи последние 5 писем из входящих моей учётной записи carry@company.com»

Прочие инструменты

  • Получить координаты адреса из Open Street Maps Nomatim

    • Пример запроса: «Какие координаты у Берлина, Германия?»

  • Получить URL карты местоположения с помощью Open Street Maps

    • Пример запроса: «Покажи карту Нью-Йорка»

  • Получить текущую погоду в местоположении

    • Пример запроса: «Какая погода в Берлине?»

  • Найти видео на YouTube

    • Пример запроса: «Покажи видео запуска Nextcloud Hub 10 на YouTube».

  • Искать в DuckDuckGo

    • Пример запроса: «Покажи результаты поиска по быстрым рецептам пасты»

  • Найти маршруты общественного транспорта

    • Пример запроса: «Как добраться от главного вокзала Вюрцбурга до главного вокзала Берлина?»

  • Показать все проекты в OpenProject (требуется интеграция с OpenProject)

    • Пример запроса: «Перечисли все мои проекты в OpenProject»

  • Показать всех доступных исполнителей проекта в OpenProject (требуется интеграция с OpenProject)

    • Пример запроса: «Перечисли всех доступных исполнителей проекта „Product launch“ в OpenProject»

  • Создать пакет работ в указанном проекте OpenProject (нужно приложение Интеграция с OpenProject)

    • Пример запроса: «Создай в OpenProject пакет работ „Опубликовать видео о выпуске“ в проекте „Запуск продукта“»

Объединение инструментов

Агент может также объединять эти инструменты для выполнения таких задач:

  • «Какая погода там, где живёт Andrew?»

    • Использует контакты, чтобы найти адрес Andrew, а затем проверяет погоду

  • «Какая погода там, где я живу?»

    • Находит адрес текущего пользователя, а затем проверяет погоду

  • «Отправь письмо с carry@company.com пользователю Andrew»

    • Использует контакты, чтобы найти адрес эл. почты Andrew, а затем отправляет письмо

  • «Какие из моих файлов от Anna?»

    • Находит идентификатор пользователя Anna и ищет принадлежащие ей файлы

  • «Отправь содержимое моего файла draft.md пользователю Andrew в „Конференциях“»

    • Получает содержимое файла и отправляет его Andrew в обсуждении один на один в приложении «Конференции»

Навыки

Навыки позволяют дать контекстному агенту многоразовые инструкции, которым он следует, когда они уместны. Навык — это небольшой файл Markdown с описанием процедуры, набора правил или знаний в конкретной предметной области. После сохранения навыка агент автоматически подхватывает его и применяет в дальнейших обсуждениях, и повторять одно и то же не приходится.

Примечание

Для навыков требуются приложение «Контекстный агент» версии 2.8.0 или более поздней и приложение «Помощник» версии 3.5.0 или более поздней.
Можно спросить у администратора, выполнены ли эти требования, или напрямую у агента — умеет ли он использовать навыки.

Где хранятся навыки

Личные навыки хранятся в приложении «Файлы» Nextcloud в папке Context Agent/Skills/ внутри папки данных Помощника, то есть при имени папки по умолчанию — Assistant/Context Agent/Skills/.

Каждый навык — это вложенная папка с файлом SKILL.md. Файл SKILL.md начинается с блока метаданных YAML, в котором задаются имя и описание навыка, а далее идёт содержимое навыка в формате Markdown:

---
name: weekly-report-format
description: Formatting rules for my weekly status reports
---

When I ask you to write a weekly report, use the following structure:
1. Summary (2-3 sentences)
2. Completed tasks (bullet list)
3. Blockers
4. Plan for next week

Например, навык с именем «weekly-report-format» будет храниться по пути Assistant/Context Agent/Skills/weekly-report-format/SKILL.md.

Типичная структура папки навыков выглядит так:

Assistant/
└── Context Agent/
    └── Skills/
        ├── email-tone/
        │   └── SKILL.md
        ├── weekly-report-format/
        │   └── SKILL.md
        └── meeting-notes/
            └── SKILL.md

Создание навыка

Создать навык можно двумя способами:

  • Вручную: создайте вложенную папку в Assistant/Context Agent/Skills/ в приложении «Файлы», затем добавьте файл SKILL.md с метаданными и содержимым, показанными выше.

  • Через чат: попросите агента создать навык. Например:

    • «Создай навык с именем „email-tone“, который напоминает всегда писать письма в дружелюбном и профессиональном тоне».

    • «Сохрани навык для обобщения заметок о встречах с задачами и ответственными».

    Агент автоматически создаст папку и файл SKILL.md.

Просмотр и использование навыков

Чтобы узнать, какие навыки доступны, спросите агента:

  • «Перечисли мои навыки».

Явно вызывать навык не нужно. Агент читает описания всех доступных навыков и применяет подходящие с учётом контекста обсуждения.

Навыки, предоставляемые администратором

Администратор может настроить глобальную папку навыков, которая предоставляет навыки всем пользователям сервера. Такие глобальные навыки показываются вместе с личными навыками.

Если имя глобального навыка совпадает с именем одного из личных навыков, приоритет имеет личный вариант.

Использование Nextcloud в качестве сервера MCP

Приложение «Контекстный агент» открывает доступ к Nextcloud как к серверу протокола контекста модели (MCP). Это значит, что сервер Nextcloud можно подключить к внешним инструментам и агентам ИИ, таким как Pi Agent, Claude Code, Hermes, OpenCode или любой другой клиент, совместимый с MCP, и позволить им использовать те же инструменты, что доступны в чате помощника.

Конечная точка сервера MCP:

https://your-nextcloud-domain.com/index.php/apps/app_api/proxy/context_agent/mcp/

Для аутентификации используется пароль приложения. Создать его можно в разделе «Личные параметры -> Безопасность -> Активные устройства и сеансы».

Подключение клиентов MCP

Любой клиент, совместимый с MCP и поддерживающий транспорт streamable_http, может подключиться к серверу MCP Nextcloud. Укажите в клиенте URL конечной точки, показанный выше, и передайте пароль приложения в заголовке Authorization: Bearer <app-password>.

После подключения внешний клиент может использовать те же инструменты контекстного агента: управлять файлами, календарями, задачами, контактами, обсуждениями в «Конференциях» и многим другим напрямую извне Nextcloud.
