Dezinstalare

Poți dezinstala în siguranță clientul pentru desktop cu instrumentele integrate în sistemul de operare.

Instrucțiuni generale

Pe orice sistem de operare:

  1. Asigură-te că închizi clientul pentru desktop înainte de a-l elimina.

  2. Dezinstalează clientul pentru desktop.

  3. Ține cont că dezinstalarea clientului pentru desktop nu elimină fișierul cu configurația utilizatorului și nici datele sincronizate.

    Pentru eliminarea datelor (dosarele de sincronizare), ia în considerare funcția de pe server ștergere la distanță. Funcția este disponibilă pentru toți clienții.

Mai jos găsești instrucțiunile pentru fiecare platformă.

Windows

Clientul pentru desktop poate fi eliminat în două moduri:

  1. Din Adăugare sau eliminare programe.

  2. Poți folosi opțiunile din linia de comandă ale msiexec:

msiexec /uninstall Nextcloud-x.y.z-x64.msi /quiet``

  1. Fișierul cu configurația utilizatorului se află în %APPDATA%\Nextcloud\nextcloud.cfg.

macOS

Pe lângă ștergerea clientului pentru desktop din dosarul Aplicații, s-ar putea să trebuiască să elimini și toate datele asociate, mai ales dacă folosești fișiere virtuale.

  1. Pentru a dezinstala doar aplicația, o poți face din Launchpad sau Finder.

  2. Pentru eliminarea completă a tuturor datelor asociate, poți folosi comenzile următoare:

rm -rf "$HOME/Library/Application Scripts/com.nextcloud.desktopclient"*
rm -f  "$HOME/Library/Application Support/CrashReporter/Nextcloud_"*
rm -rf "$HOME/Library/Application Support/Nextcloud"
rm -rf "$HOME/Library/Caches/Nextcloud"
rm -rf "$HOME/Library/Containers/com.nextcloud.desktopclient"*
rm -rf "$HOME/Library/Group Containers/NKUJUXUJ3B.com.nextcloud.desktopclient"
rm -rf "$HOME/Library/Group Containers/com.nextcloud.desktopclient"
rm -f  "$HOME/Library/LaunchAgents/com.nextcloud.desktopclient.plist"
rm -rf "$HOME/Library/Preferences/Nextcloud"
rm -f  "$HOME/Library/Preferences/com.nextcloud.desktopclient.plist"

  1. Începând cu versiunea 33.0.0, configurația utilizatorului se află în $HOME/Library/Containers/com.nextcloud.desktopclient/Data/Library/Preferences/Nextcloud/nextcloud.cfg. În versiunile mai vechi se află în $HOME/Library/Preferences/Nextcloud/nextcloud.cfg.

Linux

Depinde de modul în care ai instalat clientul pentru desktop:

  1. Dacă folosești AppImage-ul Nextcloud, poți șterge pur și simplu fișierul AppImage.

  2. Dacă ai instalat clientul pentru desktop cu managerul de pachete, îl poți folosi și pentru dezinstalare. De exemplu, pe Ubuntu poți folosi comanda următoare:

sudo apt remove nextcloud-desktop

  1. Fișierul cu configurația utilizatorului se află în $HOME/.config/Nextcloud/nextcloud.cfg.
