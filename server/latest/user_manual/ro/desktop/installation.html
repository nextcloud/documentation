Instalare

Descărcare

Poți descărca cea mai nouă versiune a clientului de sincronizare Nextcloud pentru desktop de pe Nextcloud download page. Clienții sunt disponibili pentru Linux, macOS și Microsoft Windows.

Pe pagina de descărcare găsești și linkuri către arhivele cu codul sursă și către versiunile mai vechi.

Versiuni de server acceptate

Fiecare versiune a clientului pentru desktop acceptă ultimele trei versiuni majore stabile ale serverului Nextcloud existente la data lansării. Vezi Nextcloud Server release schedule pentru versiunile majore acceptate.

Cerințe de sistem

  • Windows 10+ (doar pe 64 de biți)

  • macOS 12.0+ (doar pe 64 de biți)

  • Linux (Ubuntu 24.04, openSUSE 15.5, Alma 8 sau altele) (doar pe 64 de biți)

    Pentru distribuțiile Linux, acceptăm versiunile LTS actuale, dacă este posibil din punct de vedere tehnic. Sistemele BSD le acceptăm dacă este posibil din punct de vedere tehnic, dar nu le testăm.

Notă

Nu oferim suport pentru Citrix.

  • Vom face tot posibilul să-i sfătuim pe utilizatorii Citrix din perspectiva clientului pentru desktop.

  • Vom remedia problemele care pot fi reproduse și pe sistemele standard acceptate.

  • Tot restul nu intră în aria noastră de suport.

Instalarea pe macOS și Windows

Instalarea pe macOS și Windows se face ca pentru orice altă aplicație: descarcă programul, dă dublu clic pe el pentru a porni instalarea și urmează expertul de instalare. După instalare și configurare, clientul pentru desktop se actualizează automat; vezi Actualizarea automată pentru mai multe informații.

Pentru opțiunile de implementare destinate administratorilor, precum configurarea avansată a MSI pe Windows, configurarea neinteractivă a conturilor și preconfigurarea expertului din linia de comandă, vezi capitolul despre implementarea și configurarea clientului pentru desktop din manualul pentru administratori.

Instalarea pe Linux

Pentru Linux, Nextcloud oferă oficial clientul pentru desktop ca AppImage pe Nextcloud download page.

Unele distribuții Linux oferă clientul Nextcloud pentru desktop și prin managerele lor de pachete. Aceste pachete sunt întreținute de distribuție sau de comunitate, nu de Nextcloud. Dacă preferi instalarea prin managerul de pachete, consultă documentația distribuției.

Pe Linux trebuie să ai activat și un manager de parole, precum GNOME Keyring sau KWallet, pentru ca clientul pentru desktop să se poată autentifica automat.

Configurarea inițială

După instalare se deschide expertul de configurare. Introdu adresa pe care o folosești în browser pentru a accesa serverul Nextcloud, apoi dă clic pe Autentificare.

Pentru restul pașilor din expert, inclusiv autorizarea din browser și opțiunile de sincronizare, vezi Adăugarea unui cont.
