Folosirea macOS File Provider

Pe macOS, clientul nostru poate integra fișierele Nextcloud direct în sistem, ca extensie File Provider. Orice cont Nextcloud configurat de acum înainte are integrarea activată implicit.

Funcții acceptate

  • Păstrarea fișierelor sau a dosarelor întregi disponibile offline

  • Eliberarea spațiului pe disc prin eliminarea copiilor locale, fără ștergerea elementelor

  • Eliminarea inteligentă și automată a datelor locale

  • Previzualizări în Finder pentru fișierele care nu au fost încă descărcate

  • Suport pentru formatele specifice Apple, de exemplu pachetele Pages, Numbers sau Keynote

  • Suport pentru blocarea fișierelor pe server (dacă serverul conectat o permite)

  • Suport pentru „Deschide local”

  • Partajarea cu alți utilizatori

  • Acțiuni de pe server integrate direct în meniul contextual din Finder

  • Detectarea automată a modificărilor de pe server

Configurare

Setările extensiei File Provider pot fi ajustate pentru fiecare cont, din fereastra de setări a clientului Nextcloud pentru desktop.

Aici poți activa sau dezactiva integrarea cu Finder.

Dacă dezactivezi extensia File Provider când există încă modificări nesincronizate, macOS salvează elementele nesincronizate într-un dosar care este afișat automat după dezactivarea integrării.

Integrarea cu Finder

Pe macOS, o stocare la distanță, cum ar fi un cont de fișiere Nextcloud, apare ca o locație dedicată în bara laterală din Finder. Locația reală a conținutului pe disc este stabilită de macOS.

Notă

Pentru o detectare mai rapidă a modificărilor de pe server, îți recomandăm să activezi aplicația notify_push pe serverul Nextcloud. Aceasta notifică clientul pentru desktop despre modificările de pe server imediat ce au loc, reducând timpul până la apariția lor în Finder. Altfel, clientul trebuie să interogheze serverul, ceea ce mărește întârzierea dintre o modificare pe server și apariția ei locală.

Indicatorii stării de sincronizare

La fel ca la dosarele de sincronizare clasică, Finder afișează indicatori de stare lângă elemente. Spre deosebire de indicatorii proprii ai dosarelor de sincronizare clasică, acești indicatori standard sunt furnizați de macOS, pentru un aspect unitar în toate aplicațiile de stocare în cloud pe care le poate folosi un utilizator.

  • Nor cu săgeată în jos: elementul și conținutul lui nu au fost încă descărcate. Pot fi descărcate, dacă există conexiune la rețea.

  • Nor conturat: starea locală curentă a elementului nu a fost încă încărcată complet.

  • Nor tăiat: elementul este exclus de la sincronizare.

  • Diagramă circulară: elementul se încarcă sau se descarcă, iar progresul este afișat.

  • Cerc plin cu o pioneză: elementul este disponibil offline și va fi păstrat local.

  • Nicio pictogramă: elementul este disponibil offline și actualizat.

Acțiuni din meniul contextual

Extensia File Provider oferă și funcții Nextcloud speciale prin meniul contextual din Finder.

Păstrarea fișierelor descărcate (Keep Downloaded)

Fișierele și dosarele pot fi marcate pentru a rămâne descărcate și disponibile offline permanent. Dacă alegi această opțiune pentru un dosar, ea se aplică și întregului lui conținut. Este utilă mai ales pentru utilizatorii cu acces limitat sau fără acces la rețea, care își pot accesa oricând fișierele importante, fără grija conexiunii. macOS nu va elibera spațiu pe disc eliminând elementele marcate pentru păstrare, chiar dacă nu au fost accesate de mult timp.

Poți anula acest lucru selectând opțiunea de eliberare automată a spațiului („Allow automatic freeing up space”) pentru aceleași elemente.

Pentru ca tot conținutul unui cont să fie mereu disponibil local, poți selecta opțiunea „Always keep downloaded” pe rădăcina locației din bara laterală din Finder.

Blocarea

Dacă serverul permite blocarea fișierelor, clientul oferă blocarea și deblocarea manuală a fișierelor în Finder.

Partajare

Dacă serverul permite partajarea și elementul poate fi partajat, poți crea partajări noi sau gestiona partajările existente direct din meniul contextual din Finder, ca în interfața web Nextcloud.

Acțiuni pentru fișiere

Dacă pe server sunt instalate aplicații care oferă acțiuni pentru tipurile de fișiere selectate, aceste acțiuni sunt disponibile și în meniul contextual din Finder. Astfel poți folosi funcțiile de pe server ale instanței Nextcloud direct din Finder.

Probleme cunoscute

Conflictul dintre extensiile macOS

Din cauza limitărilor tehnice impuse de Apple în macOS, integrarea cu Finder pentru dosarele de sincronizare clasică nu poate funcționa în paralel cu o extensie File Provider activată. Prin urmare, cât timp extensia File Provider este activată, indicatorii de stare și opțiunile din meniul contextual nu sunt disponibile pentru dosarele de sincronizare clasică.

Fișiere alias

Când deschizi pentru prima dată un fișier alias macOS stocat în Nextcloud, pe un dispozitiv pe care nu a fost încă descărcat, fișierul se poate deschide ca document binar într-un editor de text, în loc să ducă la ținta lui. Se întâmplă pentru că macOS decide cum deschide un fișier înainte de a-l descărca, iar fișierele alias nu au pe server o extensie sau informații de tip recognoscibile — singura modalitate de a le identifica este citirea conținutului. După ce fișierul a fost deschis sau descărcat o dată, Nextcloud Desktop află că este un alias și reține informația local, așa că toate deschiderile ulterioare funcționează corect. Pentru a evita complet problema, dă clic dreapta pe fișierul alias în Finder și alege Keep Downloaded înainte de a-l deschide prima dată.

Deschiderea locală

Acțiunea Deschide local din interfața web Nextcloud nu poate deschide fișierele gestionate de extensia File Provider. Le poate doar afișa în Finder.

Aceasta este o restricție a macOS, nu o eroare a clientului. Pentru protecția ta, macOS permite doar anumitor aplicații să deschidă un fișier și nu permite unei aplicații să-și acorde singură această permisiune. Partea clientului care are voie să gestioneze aceste fișiere nu are voie să pornească alte aplicații, iar partea care ar putea porni editorul nu are voie să deschidă fișierul.

Acordarea accesului complet la disc (Full Disk Access) nu ajută, deoarece de acest lucru se ocupă altă componentă a sistemului de securitate macOS.

Depanare

Jurnalizarea la nivel de depanare

Intrările de jurnal la nivel de depanare pentru extensia File Provider sunt dezactivate implicit. Dacă vrei să raportezi o problemă cu File Provider, poate fi util să le activezi, pentru informații mai detaliate despre ce se întâmplă în fundal. Pentru a le activa, rulează în Terminal comanda următoare:

defaults write com.nextcloud.desktopclient.FileProviderExt debugLoggingEnabled -bool YES

Modificarea intră în vigoare în câteva secunde; nu este necesară repornirea extensiei sau a Mac-ului. După ce ai rezolvat problema investigată, îți recomandăm să restabilești valoarea implicită ștergând valoarea setată explicit:

defaults delete com.nextcloud.desktopclient.FileProviderExt debugLoggingEnabled
