Șabloane de conversație

Șabloanele de conversație le permit administratorilor să definească modele pentru conversațiile noi, cu setări preconfigurate precum permisiunile, regulile pentru sala de așteptare și tipul conversației.

Șabloane disponibile

În funcție de configurația instanței, este posibil să vezi șabloane la crearea unei conversații noi. Fiecare șablon aplică un set de valori implicite potrivit unei anumite situații.

Cameră vocală

O cameră de apel permanentă („Cameră vocală”) este un șablon de conversație optimizat pentru întâlniri neobligatorii, disponibile oricând. Oricine intră în conversație se alătură direct apelului, ceea ce face comunicarea mai ușoară. Mesajele dintr-o cameră vocală expiră după un anumit timp, ca totul să rămână simplu și spontan.

Webinar

Moderatorii pot configura un șablon care impune sala de așteptare, astfel încât participanții să aștepte un moderator înainte de a intra. Când o conversație folosește un șablon cu sală de așteptare obligatorie:

  • participanții văd o sală de așteptare când intră;

  • un moderator trebuie să-i lase să intre în conversație sau să dezactiveze sala de așteptare;

  • este util pentru webinarii, interviuri sau întâlniri controlate.

Prezentare

Șablonul Prezentare este util pentru întâlnirile interne la care se așteaptă mai mulți ascultători decât vorbitori. Permisiunile participanților sunt optimizate pentru cea mai bună performanță și moderare, astfel încât prezentatorii să poată vorbi neîntrerupt.
