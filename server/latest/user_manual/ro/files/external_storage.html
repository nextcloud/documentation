Folosirea stocării externe

Aplicația de stocare externă permite serverului Nextcloud să se conecteze la sisteme de fișiere la distanță — precum Amazon S3, servere SFTP, partajări SMB/CIFS sau servere WebDAV — și să le afișeze ca dosare în Fișiere. Echipa de administrare stabilește ce backenduri sunt disponibile și ce montări sunt partajate cu tine.

Dacă administratorul a activat stocarea externă gestionată de utilizatori, poți adăuga și propriile conexiuni în Setări personale.

Accesarea stocării externe

Montările de stocare externă apar ca dosare obișnuite în Fișiere. Poți răsfoi, încărca, descărca și șterge fișiere în ele ca în orice alt dosar. Partajarea este disponibilă doar dacă administratorul a activat-o pentru montarea respectivă.

Un indicator colorat de lângă numele dosarului arată starea conexiunii:

  • Verde — stocarea este conectată și gata de folosire.

  • Galben — stocarea nu a putut fi contactată; Nextcloud va reîncerca automat.

  • Roșu — stocarea nu este disponibilă. Dacă problema persistă, contactează administratorul.

Când o montare nu este disponibilă, Nextcloud o marchează ca offline timp de zece minute înainte de a reîncerca. Poți porni manual o nouă verificare dând clic pe indicatorul de stare.

Notă

Unele montări de stocare externă pot fi doar pentru citire. Pe o astfel de montare nu poți încărca sau șterge fișiere.

Partajarea fișierelor din stocarea externă

Partajarea dintr-o montare de stocare externă funcționează la fel ca partajarea oricărui alt fișier sau dosar — folosește pictograma de partajare din Fișiere. Administratorul trebuie să activeze explicit partajarea pentru fiecare montare, așa că pictograma de partajare poate lipsi la unele montări.

Notă

Criptarea pe server nu este disponibilă pentru montările externe care indică spre alte instanțe Nextcloud.

Adăugarea propriei stocări externe

Dacă administratorul a activat stocarea externă gestionată de utilizatori, îți poți conecta propriile servicii de stocare în Setări personale → Stocare externă.

Pentru a adăuga o montare nouă:

  1. Dă clic pe pictograma de profil și selectează Setări personale.

  2. Selectează Stocare externă din bara laterală stângă.

  3. Alege un backend din lista derulantă Adaugă o stocare.

  4. Completează câmpurile obligatorii pentru backend (adresa serverului, calea, datele de autentificare etc.).

  5. Selectează o metodă de autentificare din lista derulantă Autentificare.

Câmpurile obligatorii sunt marcate cu chenar roșu. După ce sunt completate toate, montarea este salvată automat.

Un punct verde lângă montare confirmă că s-a conectat cu succes. O pictogramă roșie sau galbenă înseamnă că Nextcloud nu s-a putut conecta — verifică datele de autentificare și setările de rețea.

Pentru a elimina o montare, deschide meniul cu trei puncte de lângă ea și selectează Șterge.

Notă

Montările adăugate în Setări personale sunt vizibile doar în contul tău.

Backenduri acceptate

În funcție de ce a activat administratorul, pot fi disponibile următoarele backenduri:

  • Amazon S3 — bucketuri Amazon Simple Storage Service și stocare compatibilă cu S3.

  • FTP — servere FTP și FTPS.

  • Nextcloud / ownCloud — altă instanță Nextcloud sau ownCloud, prin WebDAV.

  • Stocare de obiecte OpenStack — bucketuri OpenStack Swift.

  • SFTP — servere SSH File Transfer Protocol.

  • SMB / CIFS — partajări de fișiere Windows și servere Samba.

  • WebDAV — orice server compatibil cu WebDAV.

Pentru detaliile de configurare ale fiecărui backend, vezi Configurarea stocării externe (GUI) în manualul pentru administratori.

Detectarea modificărilor fișierelor

Fișierele pe care le adaugi sau le modifici prin Nextcloud apar imediat. Fișierele adăugate sau modificate direct pe stocarea externă — fără Nextcloud — s-ar putea să nu apară până la următoarea scanare în fundal.

Dacă fișierele adăugate din exterior nu apar, cere-i administratorului să ruleze occ files:scan sau să configureze o scanare periodică în fundal pentru montare.
